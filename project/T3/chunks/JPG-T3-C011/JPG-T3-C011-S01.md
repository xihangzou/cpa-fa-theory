### 1. 包括利益とは

#### (1) 包括利益の定義

「包括利益」とは、ある企業の特定期間の財務諸表において認識された純資産の変動額のうち、当該企業の純資産に対する持分所有者との直接的な取引によらない部分をいう。

当該企業の純資産に対する持分所有者には、当該企業の株主のほか、当該企業が発行する新株予約権の所有者が含まれる。連結財務諸表においては、当該企業の子会社の非支配株主も含まれる。

包括利益は、期首純資産から期末純資産への変動のうち、持分所有者との直接的な取引による増減を除いた部分である。除かれる直接取引には、親会社株主との新株発行・自己株式の取得、非支配株主との子会社増資、新株予約権者との新株予約権の発行などによる増減がある。

#### 補足　概念フレームワーク等における包括利益の定義

本会計基準、概念フレームワーク及びIFRSのいずれも、資本取引以外による純資産の変動として包括利益を定義しており、その意味内容は基本的には同様である。

定義において「ある企業の特定期間の財務諸表において認識された」と表現されているのは、包括利益を構成する純資産の変動額が、財務諸表において認識されたものに限られることを明確にするためである。

#### (2) 包括利益から除かれる項目

次の取引は企業の成果とは無関係の取引であり、包括利益の構成要素とはならない。

1. 企業の株主との直接的な取引
2. 企業の発行する新株予約権の所有者との直接的な取引
3. 連結財務諸表上における、企業の子会社の非支配株主との直接的な取引

会計方針の変更及び誤謬の訂正に関する累積的影響額に係る期首利益剰余金の修正額は、前期以前に帰属する純資産の変動額を当期に表示しているにすぎないため、当期の包括利益には含まれない。

子会社が連結子会社及び関連会社のいずれにも該当しなくなった場合の利益剰余金減少高（又は増加高）も、これに準じて取り扱い、包括利益には含めない。

持分比率が80％から10％となるように子会社株式を一部売却した場合（評価・換算差額等やのれんは生じていないものとする）は、個別財務諸表上計上した売却損益の修正として処理する。連結上の売却原価は取得時の子会社の資本（親会社の投資額）に70％を乗じた部分であり、残る10％は連結財務諸表上の有価証券の帳簿価額として表示する。修正額は連結株主資本等変動計算書の利益剰余金の修正項目として表示する。

### 2. その他の包括利益（OCI）とは

「その他の包括利益」とは、包括利益のうち当期純利益に含まれない部分をいう。連結財務諸表におけるその他の包括利益には、親会社株主に係る部分と非支配株主に係る部分が含まれる。

#### 連結財務諸表におけるその他の包括利益

その他の包括利益は、包括利益から当期純利益を控除したものである。この関係は個別財務諸表でも同様である。

具体的には、当期純利益にその他の包括利益の内訳項目を加減して包括利益を表示する。例えば、当期純利益1,000に対し、その他有価証券評価差額金200及び繰延ヘッジ損益120がある場合、その他の包括利益合計は320、包括利益は1,320となる。その他の包括利益は親会社株主に係る部分と非支配株主に係る部分から構成される。

この計算は、定義に従って純資産の変動額から算定する過程とは異なり、当期純利益からの調整計算として表示している。しかし、この表示方法の方が有用であり、国際的な会計基準でも同様の方式が採用されている。

#### 連結財務諸表における包括利益の計算の表示方法

次の2つの方法が考えられる。

1. 親会社株主に帰属する当期純利益に親会社株主に係るその他の包括利益を加減して親会社株主に係る包括利益を計算し、これに非支配株主に係る包括利益を加減する方法。
2. 当期純利益に、親会社株主に係る部分と非支配株主に係る部分の合計であるその他の包括利益を加減する方法（現行）。

##### ①の表示例

| 項目 | 金額 |
|---|---:|
| 親会社株主に帰属する当期純利益 | 520 |
| 親会社株主に係るその他の包括利益：その他有価証券評価差額金 | 60 |
| 親会社株主に係るその他の包括利益：繰延ヘッジ損益 | 36 |
| 親会社株主に係るその他の包括利益合計 | 96 |
| 親会社株主に係る包括利益 | 616 |
| 非支配株主に帰属する当期純利益 | 200 |
| 非支配株主に係るその他の包括利益：その他有価証券評価差額金 | 40 |
| 非支配株主に係るその他の包括利益：繰延ヘッジ損益 | 24 |
| 非支配株主に係るその他の包括利益合計 | 64 |
| 非支配株主に係る包括利益 | 264 |

##### ②の表示例

| 項目 | 金額 |
|---|---:|
| 当期純利益 | 720 |
| その他有価証券評価差額金 | 100 |
| 繰延ヘッジ損益 | 60 |
| その他の包括利益合計 | 160 |
| 包括利益 | 880 |

#### (1) ①の表示方法の論拠

①の方法は、親会社株主に帰属する当期純利益から調整計算を行うため、連結損益計算書上の親会社株主に帰属する当期純利益の計算との連携が明確であり、連結株主資本等変動計算書や連結貸借対照表の数値とも関連付けやすい点を論拠とする。

現行制度上の方法を2計算書方式で表示すると、連結損益計算書は当期純利益720から非支配株主に帰属する当期純利益200を控除して親会社株主に帰属する当期純利益520を計算する一方、連結包括利益計算書は当期純利益720から開始するため、2つの計算書の金額が不一致となり、連携が不明瞭になる。①の方法なら、損益計算書の末尾と包括利益計算書の先頭がともに親会社株主に帰属する当期純利益となる。

また、①の方法では、連結株主資本等変動計算書のその他有価証券評価差額金及び繰延ヘッジ損益の当期変動額（それぞれ60及び36）と、連結包括利益計算書の内訳が一致し、連結貸借対照表の各項目との関連も明確になる。

#### (2) ②の表示方法の論拠

②の方法は、①の方法に比べて調整項目が少ないため包括利益に至る過程が明瞭であり、その他の包括利益の内訳表示について国際的な会計基準とのコンバージェンスを図ることができる点を論拠とする。

比較検討の結果、本会計基準では②の方法を採用している。①の方法は情報量が多いというメリットがあるが、その他の包括利益の内訳情報は連結株主資本等変動計算書からも入手できるため、包括利益への調整の形で表示する必要性は低いとされる。

### 3. 包括利益を表示する目的

包括利益を表示する目的は、期中に認識された取引及び経済的事象（資本取引を除く）により生じた純資産の変動を報告するとともに、その他の包括利益の内訳項目をより明瞭に開示することである。

また、当期純利益に関する情報と併せて利用することにより、企業活動の成果についての情報の全体的な有用性を高めることも目的としている。

包括利益情報の開示により、次のことが期待される。

1. 投資家が企業全体の事業活動について、未実現利益も含めてどれだけ純資産が変動したかを検討するのに役立つ。
2. 純資産と包括利益とのクリーン・サープラス関係を明示することを通じて、財務諸表の理解可能性と諸外国の財務諸表との比較可能性を高める。
3. 国際的な会計基準とのコンバージェンスに資する。

その他有価証券評価差額金が純資産の部に直接入ると、当期の損益と純資産の変動額が一致せず、財務諸表が不明瞭になる。包括利益計算書を作成・開示すれば両者の金額が一致し、投資者にとって理解しやすい財務諸表となる。

#### 補足　クリーン・サープラス（連携）関係

貸借対照表と損益計算書（包括利益計算書を含む）のクリーン・サープラス関係には、次の2つがある。

1. 純利益と株主資本のクリーン・サープラス関係
2. 包括利益と純資産のクリーン・サープラス関係

「貸借対照表の純資産の部の表示に関する会計基準」では、前者の関係を重視している。

#### 補足　包括利益の優位性

包括利益は純利益と比較して、経営者による利益調整を抑制し、その結果、利益情報の透明性を高めることができると主張される。

X社株式の時価情報が取得原価1,200千円、X1年度末1,500千円、X2年度末1,600千円であり、X1年度期首に取得し、X1年度又はX2年度末に売却するかを検討しているとする。X1年度とX2年度にはX社株式以外の取引はない。

純利益を前提とすると、X1年度に売却すれば売却益300千円、X2年度に売却すれば売却益400千円を計上でき、経営者は売却時期を選択して利益を調整できる。一方、包括利益を前提とすれば、X1年度に売却しなくても評価差額300千円がその他の包括利益として計上される。

したがって、純利益は売却時期の選択による利益調整が可能であるが、包括利益は売却しなくても保有損益が成果として認識されるため、その影響を受けにくく、利益の透明性が高い。

#### 補足　本会計基準における包括利益の位置付け

包括利益の表示の導入は、包括利益を企業活動に関する最も重要な指標として位置付けることを意味するものではない。当期純利益に関する情報と併せて利用することで、企業活動の成果についての情報の全体的な有用性を高めることを目的とする。

本会計基準は、市場関係者から広く認められている当期純利益に関する情報の有用性を前提としており、包括利益の表示によってその重要性を低めることを意図していない。また、当期純利益の計算方法を変更するものではなく、当期純利益は従来どおり他の会計基準の定めに従って計算する。
