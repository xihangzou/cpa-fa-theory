### 1. 会計基準整備の必要性

平成15年に「企業結合に係る会計基準（以下、平成15年会計基準）」が公表された。しかし、この会計基準で規定された取扱いと国際的な会計基準の取扱いには依然として異なる点があった。そのため、平成15年会計基準を改正する必要性が生じ、平成20年に「企業結合に関する会計基準」が公表されるに至った。

経緯は、次のとおりである。

1. 従来：企業結合の会計基準がなかった。
2. 平成15年：「企業結合に係る会計基準」を公表した。
3. 基準の整備の必要性と国際的調和化の必要性を受け、平成20年：「企業結合に関する会計基準」を公表した。

### 2. 本会計基準の対象とする取引

企業結合とは、ある企業又はある企業を構成する事業と、他の企業又は他の企業を構成する事業とが1つの報告単位に統合されることをいう。

ここでいう報告単位とは、財務諸表（個別又は連結財務諸表）の作成単位であり、具体的には個々の企業又は企業集団を指す。複数の取引が1つの企業結合を構成している場合には、それらを一体として取り扱う。

企業結合の組合せは、例えば次のとおりであり、いずれの組合せも企業結合に該当する。

- A社とB社の企業結合
- A社の事業XとB社を構成する事業Yとの企業結合
- A社の事業XとB社の事業Yとの企業結合

企業結合に該当する取引には、共同支配企業の形成及び共通支配下の取引も含め、本会計基準を適用する。また、企業結合には、連結会計基準にいう他の企業の支配の獲得も含まれる。連結会計基準は、基本的に現金を対価として他の企業を支配する取引を前提としているため、現金を対価とする子会社株式の取得のうち連結会計基準に定めのない企業結合に関する事項にも本会計基準が適用される。

本会計基準の適用対象となる取引は、次のように整理できる。

| 区分 | 内容・例 |
|---|---|
| 独立企業間の企業結合 | 吸収合併、株式交換等 |
| 共同支配企業の形成 | 合弁企業の設立等 |
| 共通支配下の取引 | 親会社に支配されているS社とA社との企業結合等 |
| 現金を対価とする子会社株式の取得（連結会計基準に規定のないもの） | 原則として連結会計基準で規定されるが、規定のないものには本会計基準を適用する |

### 3. 用語の定義

企業結合に関する用語は、次のように定義される。

| 用語 | 定義 |
|---|---|
| 結合当事企業 | 企業結合に係る企業 |
| 結合企業 | 結合当事企業のうち、他の企業又は他の企業を構成する事業を受け入れて対価を支払う企業 |
| 被結合企業 | 結合企業の記述における当該他の企業（対価が支払われた側の企業） |
| 結合後企業 | 企業結合によって統合された1つの報告単位となる企業 |
| 取得企業 | ある企業又は企業を構成する事業を取得する企業 |
| 被取得企業 | 当該取得される企業 |
| 企業結合日 | 被取得企業若しくは取得した事業に対する支配が取得企業に移転した日、又は結合当事企業の事業のすべて若しくは事実上すべてが統合された日 |
| 企業結合年度 | 企業結合日の属する事業年度 |
