# 第35章 連結財務諸表に関する会計基準
## 第5節 子会社株式の追加取得及び一部売却等

### 1. 新規連結・段階取得と追加取得・一部売却の考え方の違い

| 取引 | 取引の性質 | 差額の処理 |
|---|---|---|
| 新規連結・段階取得 | 取引前には親会社と子会社との間に支配従属関係がない。子会社ではない会社の株主から株式を購入するため、外部取引・損益取引 | のれん又は負ののれん発生益として認識し、損益に影響させる |
| 追加取得・一部売却 | 取引前から支配従属関係があり、相手は企業集団内の株主であるため、内部取引・資本取引 | 資本剰余金を変動させる |

非支配株主は親会社説の立場からは外部者であり、連結上の株主は親会社株主だけとなるが、経済的単一体説の立場からは内部者（連結上の株主）となる。現行制度では、追加取得・一部売却について経済的単一体説と整合的な取扱いが採用されている。

### 2. 追加取得・一部売却の会計処理

| 追加取得 | 一部売却 |
|---|---|
| 追加取得した株式に対応する持分を非支配株主持分から減額し、追加取得により増加した親会社の持分（追加取得持分）を追加投資額と相殺する。 | 子会社株式を一部売却した場合（親会社と子会社の支配関係が継続している場合）は、売却した株式に対応する持分を親会社の持分から減額し、非支配株主持分を増額する。 |
| 追加取得持分及び減額する非支配株主持分は、追加取得日における非支配株主持分の額により計算する。 | 売却持分及び増額する非支配株主持分は、売却時点の非支配株主持分の額により計算する。 |
| 追加取得持分と追加投資額との差額は資本剰余金とする。 | 売却による親会社の持分の減少額と売却価額との差額は資本剰余金とする。 |

### 設例　追加取得持分と追加投資額

追加取得持分は「（子会社の資本の簿価＋評価差額）×追加取得割合」で表され、追加投資額は追加取得した子会社株式の金額である。

1. X1年3月31日にP社はS社株式の60％を21,000で取得した。
2. S社のX1年3月31日の貸借対照表は次のとおりである。

| 借方 | 金額 | 貸方 | 金額 |
|---|---:|---|---:|
| 諸資産 | 50,000 | 諸負債 | 20,000 |
|  |  | 資本金 | 30,000 |

3. X1年3月31日時点の諸資産の評価額は55,000（評価差額5,000）である。
4. 翌期のS社の当期純利益は5,000であり、X2年3月31日（翌期末）の貸借対照表は、諸資産55,000、諸負債20,000、資本金30,000、利益剰余金5,000である。
5. X2年3月31日にP社はS社株式の10％を4,500で追加取得した。

X1年3月31日の連結財務諸表上の処理は次のとおりである。

| 処理 | 借方 | 金額 | 貸方 | 金額 |
|---|---|---:|---|---:|
| 資産と負債の時価評価 | 諸資産 | 5,000 | 評価差額（資本） | 5,000 |
| 投資と資本の相殺消去 | 資本金 | 30,000 | 子会社株式 | 21,000 |
|  | 評価差額（資本） | 5,000 | 非支配株主持分 | 14,000 |

X2年3月31日の連結財務諸表上、子会社の利益の按分は、非支配株主に帰属する当期純利益2,000／非支配株主持分2,000となる。

追加取得の消去仕訳は、非支配株主持分4,000（（X2年度末の資本35,000＋評価差額5,000）×10％）、子会社株式4,500、差額500を用いて次のようになる。

| 借方 | 金額 | 貸方 | 金額 |
|---|---:|---|---:|
| 非支配株主持分（注1） | 4,000 | 子会社株式（注2） | 4,500 |
| 資本剰余金 | 500 |  |  |

注1：追加取得持分（＝減額する非支配株主持分）は、X2年度末の資本35,000と評価差額5,000の合計に10％を乗じた4,000である。X2年度末の非支配株主持分16,000（14,000＋2,000）を基礎として、10％／40％を乗じても4,000となる。

注2：追加投資額を示す。この追加投資額と追加取得持分との差額が資本剰余金となる。

### 設例　売却持分と売却価額

売却持分は「（子会社の資本の簿価＋評価差額）×売却割合」で表され、売却価額は一部売却した子会社株式の売価である。

1. X1年3月31日にP社はS社株式の80％を29,000で取得した。
2. S社のX1年3月31日の貸借対照表は、諸資産50,000、諸負債20,000、資本金30,000である。
3. X1年3月31日時点の諸資産の評価額は55,000（評価差額5,000）である。
4. 翌期のS社の当期純利益は5,000であり、X2年3月31日（翌期末）の貸借対照表は、諸資産55,000、諸負債20,000、資本金30,000、利益剰余金5,000である。
5. X2年3月31日にP社はS社株式の10％（原価29,000×10％／80％＝3,625）を4,200で一部売却した（P社の個別上、575の子会社株式売却益が計上されている）。
6. のれんは定額法により5年間で償却する。

X1年3月31日の連結財務諸表上の仕訳は、評価差額5,000、資本金30,000、子会社株式29,000、非支配株主持分7,000、のれん1,000を用いる。X2年3月31日には、非支配株主に帰属する当期純利益1,000／非支配株主持分1,000、のれん償却額200／のれん200を計上する。

一部売却の消去仕訳は次のとおりである。

| 借方 | 金額 | 貸方 | 金額 |
|---|---:|---|---:|
| 子会社株式（注2） | 3,625 | 非支配株主持分（注1） | 4,000 |
| 子会社株式売却益 | 375 |  |  |

個別上の売却益の振替は、子会社株式売却益200／資本剰余金200である。

注1：売却持分（＝増額する非支配株主持分）は、（X2年度末の資本35,000＋評価差額5,000）×10％＝4,000である。売却時点の親会社持分32,000（支配獲得時の子会社資本30,000＋評価差額5,000＋子会社利益5,000の80％）を基礎として32,000×10％／80％としても4,000となる。

注2：売却原価を示す。売却持分4,000と売却価額4,200との差額200は資本剰余金となる。個別上の簿価3,625と連結上の売却持分4,000との差額375は、個別上の売却益575を連結上の売却益200に修正する。

図の関係は、個別上の簿価3,625から個別上の売却益575を加えた売価4,200、連結上の簿価（売却持分）4,000との差額375を売却損益から修正し、連結上の売却益200を資本剰余金へ振り替えるというものである。

### 3. 一部売却のその他の論点

#### (1) 子会社株式の売却差額と連結基礎概念の関連

子会社株式を一部売却した場合、連結財務諸表上、子会社株式に係る売却差額が生じる。親会社説に立つか経済的単一体説に立つかにより結論が異なる。

| 考え方 | 取引の捉え方 | 処理 |
|---|---|---|
| 親会社説 | 一部売却は親会社と企業集団の外部者である非支配株主（連結上の株主ではない者）との取引 | 企業集団の資本主との直接的な取引ではないため損益取引とし、売却差額を損益として処理 |
| 経済的単一体説 | 一部売却は親会社と企業集団の内部者である非支配株主（連結上の株主）との取引 | 企業集団の資本主との直接的な取引であるため資本取引とし、資本剰余金を変動 |

#### (2) 一部売却と関連する法人税等

子会社株式の一部売却における関連する法人税等（子会社への投資に係る税効果の調整を含む）は、資本剰余金から控除する。

設例：P社はX1年期首にS社株式100％を1,000で取得した。P社とS社の会計期間は4月1日から3月31日である。S社はX1年度に税引後利益160を計上した。P社はX1年度末にS社株式20％をX2年期首に300で売却する意思決定を行い、個別上100（300－1,000×20％）の株式売却益と、これに伴う法人税等40が計上されている。

X1年度の連結上は、取得後利益160のうち売却割合20％に対応する32について投資に係る一時差異を調整する。税率40％なので、法人税等調整額・繰延税金負債は160×20％×40％＝12.8である。

X2年度の個別上の処理は、現金300／子会社株式200・子会社株式売却益100、法人税・住民税及び事業税40／現金預金40である。連結上では、前期の繰延税金負債12.8を取り崩し、子会社株式200／非支配株主持分232・子会社株式売却益32を計上する。売却持分は（取得原価1,000＋税引後利益160）×20％＝232である。

個別上の売却益100のうち連結上の売却益32を除いた68は資本剰余金へ振り替える。これに対応する税効果27.2（68×40％）は、資本剰余金27.2／法人税、住民税及び事業税27.2として取り消す。結果として、連結損益計算書上の株式売却益は0、法人税等は12.8（40－27.2）、法人税等調整額は△12.8となり、差引は0となる。

図の金額関係は、個別上の簿価200、連結上の簿価（売却持分）232、売却価額300であり、個別上の売却益100と連結上の売却益68との差額を資本剰余金へ振り替えるものである。

#### (3) 一部売却におけるのれんの減額

現行制度上、支配獲得時に計上したのれんの未償却額は、子会社株式を一部売却した場合等において減額しない。従来は売却した株式に対応する部分を減額（取崩し）していたが、追加取得時にのれんを追加計上しない現行制度との整合性及び国際的な会計基準とのコンバージェンスの観点から、現行制度では減額しない。
