# 第35章 連結財務諸表に関する会計基準
## 第8節 当期純損益と連結基礎概念

連結損益計算書に計上される当期純利益をどのように捉えるかについては、親会社説と経済的単一体説とで異なる。

### (1) 親会社説の立場（従来）

親会社説では、親会社の株主持分を重視する以上、当期純損益は親会社の株主に帰属するものでなければならない。したがって、非支配株主に帰属する部分は当期純利益の金額に含めるべきではない。従来は基本的に親会社説に立脚していたため、この考え方を採用していた。

### (2) 経済的単一体説の立場（現行）

経済的単一体説では、企業集団すべての持分を重視する以上、当期純損益は親会社の株主に帰属するもののみならず、非支配株主に帰属するものも含めるべきである。国際的な会計基準と同様の表示によって比較可能性を向上させることを重視した結果、現行制度上、当期純利益には非支配株主に帰属する当期純利益も含めて表示している。

| 親会社説（従来の連結会計基準） | 経済的単一体説（現行の連結会計基準） |
|---|---|
| 税金等調整前当期純利益 | 税金等調整前当期純利益 |
| 法人税、住民税及び事業税 | 法人税、住民税及び事業税 |
| 法人税等調整額 | 法人税等調整額 |
| 非支配株主に帰属する当期純利益を控除 | 当期純利益として表示 |
| 当期純利益（親会社株主に帰属する利益） | 当期純利益（企業集団全体の株主に帰属する利益） |
