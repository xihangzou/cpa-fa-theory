# 第40章 連結キャッシュ・フロー計算書等の作成基準

## 第5節 キャッシュ・フロー計算書に関するその他の論点

### 1. 非資金取引

#### (1) 非資金取引の内容と注記

非資金取引とは、キャッシュの流入・流出を伴わない取引をいう。このうち重要な非資金取引については、当該取引の内容を注記することが求められる。

本基準が注記を求める重要な非資金取引とは、キャッシュ・フロー計算書の目的から企業の財政状態には重要な影響を与えるがキャッシュ・フローを伴わない取引のうち、翌会計期間以降のキャッシュ・フローに重要な影響を与える取引をいう。

重要な非資金取引の例は次の4つである。

1. 転換社債型新株予約権付社債の資本への転換
2. ファイナンス・リースによる資産の取得
3. 株式の発行による資産の取得又は合併
4. 現物出資による株式の取得又は資産の交換

転換社債型新株予約権付社債の資本への転換では、負債が減少し資本が増加するため財政状態に重要な影響を与えるが、当期にはキャッシュの動きがない。ただし、翌期以降のキャッシュ・フローには重要な影響を与える。将来の社債利息は減少し、配当金は増加するためである。

重要な非資金取引を注記することで、投資者に将来のキャッシュ・フローを適切に予測できる情報を提供できる。

#### (2) 部分的にキャッシュ・フローを伴う取引

非資金取引の中には、部分的にキャッシュ・フローを伴う取引もある。この場合、キャッシュ・フローを伴う部分についてのみキャッシュ・フロー計算書で報告する。

例えば、合併交付金の支払を伴う合併や営業譲受け（譲渡）のような取引は、キャッシュ・フローを伴う部分のみをキャッシュ・フロー計算書に含め、それ以外の部分は記載しない。

### 2. 純額表示

次のケースでは、キャッシュ・フローを純額で表示する必要がある。

#### (1) 第三者の活動を反映している取引

外注先のための資材の代理購入等、企業が第三者のために行う取引、及び単元未満株式の買取り・処分等のように企業自身の活動というより第三者の活動を反映している取引に係るキャッシュ・フローは、企業の活動を反映していない。これを総額表示すると利用者が企業の活動と誤認するおそれがあるため、純額で表示する。

該当する例は次のとおりである。

1. 従業員からの源泉所得税や社会保険料等の預かり及び納付に係るキャッシュ・フロー
2. 金融機関における預金の受入れと払出しに関するキャッシュ・フロー
3. 債権譲渡後のサービシング契約に基づく売掛金の回収及び回収代金の支払に関するキャッシュ・フロー

#### (2) 重要性の乏しい項目

重要性の乏しい項目に係るキャッシュ・フローについても、純額で表示する。

#### (3) 社債発行費及び株式交付費

社債発行費及び株式交付費に重要性がある場合は、キャッシュ・フロー計算書上、実質手取額によって表示する。社債や新株の発行等による資金調達の実質手取額は、発行価額から社債発行費や株式交付費を控除した額だからである。

発行費・交付費に重要性がない場合は、それぞれのキャッシュ・フローを総額で表示できる。

額面500,000の社債を480,000で発行し、社債発行費5,000を支払った場合は次のように表示する。

|  | 原則：重要性あり（実質手取額） | 例外：重要性なし（総額） |
|---|---:|---:|
| 社債の発行による収入 | 475,000 | 480,000 |
| 社債の発行による支出 | — | △5,000 |

### 3. 資金の範囲、重要な非資金取引以外の注記事項

連結キャッシュ・フロー計算書（個別も同様）には、次の事項を注記しなければならない。ただし、2から4までの事項は、各号に掲げる資産及び負債の金額の重要性が乏しい場合には注記を省略できる。

1. 現金及び現金同等物の期末残高と、連結貸借対照表に掲記されている科目の金額との関係
2. 株式の取得により新たに連結子会社となった会社がある場合の、当該会社の資産及び負債の主な内訳
3. 株式の売却により連結子会社でなくなった会社がある場合の、当該会社の資産及び負債の主な内訳
4. 現金及び現金同等物を対価とする事業の譲受け若しくは譲渡又は合併等を行った場合の、当該事業の譲受け若しくは譲渡又は合併等により増加又は減少した資産及び負債の主な内訳
5. 重要な非資金取引

#### 参考　現金及び現金同等物の期末残高と貸借対照表科目との関係

現金及び現金同等物という科目は、連結財務諸表等規則等では貸借対照表科目として掲記されていない。そのため、現金及び現金同等物の期末残高と、連結貸借対照表に掲記されている科目との関係を注記する。

|---|---:|
| 現金及び預金勘定（B/S上の科目） | 1,472 |
| 預入期間が3か月を超える定期預金 | △100 |
| 取得日から3か月以内に償還期限の到来する短期投資（有価証券） | 125 |
| 現金及び現金同等物（C/F計算書上の科目） | 1,497 |
