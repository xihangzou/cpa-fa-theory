# 第36章 持分法に関する会計基準
## 第2節 持分法の適用範囲

### 1. 非連結子会社となる会社

子会社であるが、連結の範囲に含まれない、すなわち非連結子会社となる会社は、「連結財務諸表に関する会計基準」の章において示されているため、そちらを参照する。

### 2. 関連会社となる会社

#### (1) 関連会社の判定に関する基本的な考え方

関連会社の範囲の判断基準は、従来と現行では考え方が異なる。

|  | 内容 |
|---|---|
| 持株基準（従来） | 連結会社が子会社以外の他の会社の議決権の20%以上を所有し、かつ、人事、資金、技術、取引等の関係を通じて、財務及び営業又は事業の方針決定に対して重要な影響を与えることができる場合に、当該他の会社を関連会社とする。 |
| 影響力基準（現行） | 親会社及び子会社が、子会社以外の他の会社の財務及び営業又は事業の方針決定に対して重要な影響を与えることができるかどうかに基づいて関連会社を判定する。 |

従来は、財務及び営業の方針決定に対して重要な影響を与えられる場合でも、議決権の所有割合が20%未満であれば関連会社に該当せず、持分法が適用されない結果、情報の有用性を損なうおそれがあった。そこで現行基準は影響力基準を採用しており、20%未満の所有でも関連会社に該当することがある。

#### (2) 具体的な関連会社の判定

本会計基準における関連会社及び重要な影響の判定は、次のとおりである。

1. 関連会社とは、企業が出資、人事、資金、技術、取引等の関係を通じて、子会社以外の他の企業の財務及び営業又は事業の方針決定に対して重要な影響を与えることができる場合における当該他の企業をいう。
2. 「子会社以外の他の企業等の財務及び営業又は事業の方針の決定に対して重要な影響を与えることができる場合」とは、次に掲げる場合をいう。
   1. 子会社以外の他の企業の議決権の100分の20以上を自己の計算において所有している場合。
   2. 子会社以外の他の企業の議決権の100分の15以上、100分の20未満を自己の計算において所有している場合であって、次のいずれかの要件に該当する場合。
      1. 役員若しくは業務を執行する社員若しくは使用人であるもの、又はこれらであったもので、自己が当該企業の財務及び営業又は事業の方針の決定に関して影響を与えることができるものが、当該企業の代表取締役、取締役又はこれらに準ずる役職に就任していること。
      2. 当該企業に対して重要な融資を行っていること。
      3. 当該企業に対して重要な技術を提供していること。
      4. 当該企業との間に重要な販売、仕入その他の営業上又は事業上の取引があること。
      5. その他、当該企業の財務及び営業又は事業の方針の決定に対して重要な影響を与えることができることが推測される事実が存在すること。
   3. 自己の計算において所有している議決権と、自己と出資、人事、資金、技術、取引等において緊密な関係があることにより自己の意思と同一の内容の議決権を行使すると認められる者及び自己の意思と同一の内容の議決権を行使することに同意している者が所有している議決権とを合わせた場合に、子会社以外の他の企業の議決権の100分の20以上を占めており、かつ、上記2の①から⑤までのいずれかの要件に該当する場合。
3. 財務上又は営業上若しくは事業上の関係からみて、他の企業等の財務及び営業又は事業の方針の決定に対して重要な影響を与えることができないことが明らかであると認められる場合には、上記の要件を満たしても関連会社に該当しない。更生会社、破産会社その他これらに準ずる企業であって、かつ、その企業の財務及び営業又は事業の方針の決定に対して重要な影響を与えることができないと認められる企業も、関連会社に該当しない。

#### 関連会社の判定フロー

子会社以外の会社等について、次の順に判定する。

1. 他の企業の財務及び営業又は事業の方針の決定に対して重要な影響を与えることができないことが明らかか。該当すれば関連会社ではない。
2. 更生会社、破産会社その他これらに準ずる企業であって、重要な影響を与えることができないと認められるか。該当すれば関連会社ではない。
3. 議決権の20%以上を自己の計算において所有しているか。該当すれば関連会社に該当する。
4. 議決権の15%以上20%未満を自己の計算において所有しているか。該当する場合、上記2の①から⑤のいずれかを満たせば関連会社に該当する。
5. 自己の計算による議決権と緊密者又は同意者の議決権を合わせて20%以上を占めるか。該当する場合、上記2の①から⑤のいずれかを満たせば関連会社に該当する。

簡潔にまとめると、他の会社の議決権の20%以上を保有する場合は関連会社となる。15%以上20%未満を保有する場合は上記の①から⑤のいずれかを満たせば関連会社となり、15%未満（0%保有を含む）の場合でも、緊密者又は同意者の議決権と合わせて20%以上を保有し、上記の①から⑤のいずれかを満たせば関連会社となる。

### 3. 持分法適用の範囲

1. 非連結子会社及び関連会社に対する投資については、原則として持分法を適用する。
2. 関連会社及び非連結子会社のうち、次に該当する会社に対する投資については、持分法を適用しないものとする。
   1. 財務及び営業又は事業の方針の決定に対する影響が一時的であると認められる関連会社。
   2. 持分法を適用することにより、連結財務諸表提出会社の利害関係人の判断を著しく誤らせるおそれがあると認められる非連結子会社及び関連会社。
3. 持分法の適用により連結財務諸表に重要な影響を与えない場合には、持分法適用会社としないことができる。

原則は持分法を適用することであり、上記の持分法除外規定又は重要性に基づく持分法除外容認規定が例外となる。重要な子会社について、連結せずに持分法を適用することは認められていない。

#### 補足　非連結子会社とされた理由と持分法の適用の関係

| 連結から外れた理由 | 持分法を適用するか否か |
|---|---|
| 支配が一時的な会社 | 適用する。 |
| 連結すると利害関係者の判断を誤らせる会社 | 適用しない。 |
| 重要性が乏しい会社 | 持分法適用の観点からも重要性が乏しい場合には、適用しないことができる。 |

### 4. 関連会社の判定及び持分法適用の範囲のまとめ

まず、20%以上の保有又は20%未満でも重要な影響を与えられることにより関連会社に該当するかを判定する。ただし、財務等の方針決定に対して重要な影響を与えられないことが明らかな会社、又は更生・破産会社であって重要な影響を与えられないと認められる会社は関連会社ではない。

関連会社又は非連結子会社に該当した後、持分法除外規定又は持分法除外容認規定に該当するかを判定し、原則としてすべての関連会社及び非連結子会社を持分法適用の範囲に含める。

#### 持分法の具体的な適用範囲

関連会社である持分法適用会社が子会社又は関連会社を有する場合、その子会社又は関連会社は持分法の適用範囲に含まれない。一方、非連結子会社である持分法適用会社の子会社又は関連会社は、持分法の適用範囲に含まれる。

持分法適用会社に持分法を適用する際、当該持分法適用会社の子会社又は関連会社への投資について持分法を適用して認識した損益又は剰余金が連結財務諸表に重要な影響を与える場合には、当該損益を当該持分法適用会社の損益に含めて計算する。

例として、親会社又は投資会社が関連会社Aを30%保有し、Aが関連会社Bを20%保有している場合、Bには親会社又は投資会社の持分法を適用しないが、Aの利益にはBの利益の20%を含めて計算する。Bの利益が100、A自身の利益が200であれば、Aの利益は220となり、親会社又は投資会社はその30%である66を持分法による投資損益として認識する。

親会社又は投資会社が非連結子会社Dを保有し、Dが関連会社E及び子会社Fを有する場合には、D、E及びFが持分法の適用範囲に含まれる。持分法を適用するA社、D社、E社及びF社との取引では未実現損益の消去等を行うが、B社及びC社には持分法を適用しないため、これらの会社との取引では未実現損益の消去等を行わない。
