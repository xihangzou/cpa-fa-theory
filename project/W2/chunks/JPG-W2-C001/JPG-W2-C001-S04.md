# 第21章 棚卸資産の評価に関する会計基準
## 4. 棚卸資産の数量計算

### 問題17（重要度C）

問題文：継続記録法によれば、期中における在庫量を把握することができるとともに、実地棚卸を行わずとも棚卸減耗を把握できるため、この点で棚卸計算法より優れている。

判定：誤り

解説：継続記録法は帳簿記録のみで棚卸資産の増減を把握する方法である。よって、実地棚卸を行わないと棚卸減耗を把握することができない。

追加でチェック：

- 継続記録法と実地棚卸の併用が、最も理想的な棚卸資産の数量計算の方法といえる。
- 継続記録法により算定された期末帳簿棚卸数量と実地棚卸数量との差額によって、棚卸減耗が算定される。

### 問題18（重要度C）

問題文：棚卸計算法は、期中には受入記録及び払出記録を行わず、期末に実地棚卸を行うことで、期末棚卸数量を算定する方法であるため、継続記録法に比べ簡便的な方法といえる。

判定：誤り

解説：棚卸計算法は、期中には払出記録を行わないものの、受入記録は行う。

追加でチェック：棚卸計算法を用いた場合、棚卸減耗を別個把握することはできず、払出数量の中に棚卸減耗分が混入する。

### 問題19（重要度C）

問題文：棚卸減耗費は、製造原価、売上原価又は販売費の区分に計上しなければならない。

判定：誤り

出典：「連続意見書 第四」第一六

解説：棚卸減耗費は、原価性の有無にしたがい、原価性のあるものは製造原価、売上原価又は販売費の区分に計上し、原価性のないものは営業外費用又は特別損失の区分に計上する。
