# 第1章 財務会計における基礎概念等
## 第6節 指定国際会計基準と修正国際基準

### 1. 国際的な会計基準に関する主な用語

短答：B

| 用語 | 内容 |
|---|---|
| IFRS | 国際財務報告基準（International Financial Reporting Standards） |
| IASB | 国際会計基準審議会（International Accounting Standards Board） |
| FASB | 米国財務会計基準審議会（Financial Accounting Standards Board） |
| ASBJ | 企業会計基準委員会（Accounting Standards Board of Japan） |
| コンバージェンス（収束） | IFRSをそのまま適用するのではなく、我が国の会計基準をIFRSに近づけること（IFRSと完全に同一の会計基準にするのではなく、実質的に統一化すること）。 |
| アドプション（採用） | IFRSをそのまま適用すること。 |
| エンドースメント | IASBにより公表された会計基準等について、わが国で受け入れ可能か否かを判断したうえで、必要に応じて、一部の会計基準等について「削除又は修正」して採択すること。 |

近年、企業の経済活動のグローバル化及び金融・資本市場のボーダレス化が進展してきており、各国の企業が作成する財務諸表が国際的に比較可能なものとなるよう、会計基準の国際的なコンバージェンスが推進されている。

国際的な動向を受け、わが国においてもASBJにより、会計基準のコンバージェンスの努力が継続して行われている。

### 2. 指定国際会計基準と修正国際基準

EUが域内の上場企業にIFRSの適用を義務づけて以来、IFRSのアドプション（適用）は世界に広がりつつあり、わが国においても、IFRSの任意適用を認めている。

#### (1) 指定国際会計基準の任意適用

指定国際会計基準特定会社は、連結財務諸表の作成にあたって指定国際会計基準の任意適用が認められる。

以下の2要件を充たす株式会社が対象となる。

1. 有価証券届出書又は有価証券報告書において、財務諸表の適正性を確保するための特段の取組みに係る記載を行っている。
2. 指定国際会計基準に関する十分な知識を有する役員又は使用人を置いており、当該基準に基づいて財務諸表を適正に作成することができる体制を整備している。

#### (2) 修正国際基準の任意適用

修正国際基準特定会社は、連結財務諸表の作成にあたって修正国際基準の任意適用が認められる。

以下の2要件を充たす株式会社が対象となる。

1. 有価証券届出書又は有価証券報告書において、連結財務諸表の適正性を確保するための特段の取組みに係る記載を行っている。
2. 修正国際基準に関する十分な知識を有する役員又は使用人を置いており、当該基準に基づいて連結財務諸表を適正に作成することができる体制を整備している。

ASBJは、2012年12月31日現在でIASBより公表されている会計基準等を対象にエンドースメント手続を行い、修正国際基準を公表した。

エンドースメント手続において、多くの「削除又は修正」が行われた場合、修正国際基準がIFRSから派生したものとして受け止められない可能性があること等から、「削除又は修正」を最小限とすることが適切と考えられている。

IFRSで定められている以下の項目については、わが国における会計基準に係る基本的な考え方と相違が大きいため、IASBにより公表されている会計基準等の規定に「削除又は修正」を行う。

1. のれんの非償却
2. その他の包括利益に計上した後に、純損益に組替調整（リサイクリング処理）しない会計処理（ノンリサイクリング処理）

#### 指定国際会計基準・修正国際基準の適用パターン

|  | 指定国際会計基準 | 修正国際基準 |
|---|---|---|
| 連結財務諸表 | 日本基準に代えて、指定国際会計基準 | 日本基準に代えて、修正国際基準 |
| 個別財務諸表 | 日本基準のほか、指定国際会計基準 | 日本基準 |

#### 指定国際会計基準及び修正国際基準に関する留意点

|  | 指定国際会計基準 | 修正国際基準 |
|---|---|---|
| 主体 | 任意適用できる指定国際会計基準は金融庁長官が定める | ASBJが、個々の会計基準等を「削除又は修正」するか否かを判断する部分を担う |
| IFRSとの関係 | IASBが制定したすべての基準がそのまま指定国際会計基準とされている（ピュアIFRS） | IASBにより公表されている会計基準等の規定に「削除又は修正」を行っている（エンドースメントIFRS） |

なお、会社法上の連結計算書類についても、指定国際会計基準又は修正国際基準の任意適用が認められている。

### 3. 米国基準の任意適用

短答：C

米国証券取引委員会に連結財務諸表を登録しているなど一定の要件を満たす会社は、米国基準に準拠した連結財務諸表（米国式連結財務諸表）を有価証券報告書に記載して提出することが認められている。

会社法上の連結計算書類についても、米国基準によって作成することが認められている。

#### 連結財務諸表作成会社における適用パターン

連結財務諸表は、日本基準、指定国際会計基準、修正国際基準又は米国基準を任意適用できる。個別財務諸表は日本基準による。

市場において、日本基準、指定国際会計基準、修正国際基準、米国基準の4つの会計基準が乱立すると、投資家に混乱を生じさせる可能性があることが懸念されている。
