# 第1章 財務会計における基礎概念等
## 第2節 会社法会計と金融商品取引法会計

### 1. 会社法会計と金融商品取引法会計（制度会計）

短答：B

| 項目 | 会社法会計 | 金融商品取引法会計 |
|---|---|---|
| 目的 | 経営者、株主、債権者といった利害関係者間の利害調整（利害調整機能） | 投資意思決定に有用な情報を開示（情報提供機能） |
| 対象とする利害関係者 | 現在債権者、現在株主 | 投資者 |
| 計算の重点 | 分配可能額の計算（株主と債権者の利害調整） | 適正な期間損益計算 |
| 従うべき法令 | 会社法、会社計算規則など | 連結財務諸表規則、財務諸表等規則など |

企業内容開示制度（ディスクロージャー制度）を通じ、投資者への情報提供が行われる。

### 2. 会社法会計における開示書類

| 計算書類 | 連結計算書類 | その他 |
|---|---|---|
| 貸借対照表 | 連結貸借対照表 | 事業報告 |
| 損益計算書 | 連結損益計算書 | 附属明細書 |
| 株主資本等変動計算書 | 連結株主資本等変動計算書 |  |
| 個別注記表 | 連結注記表 |  |

連結包括利益計算書の作成は義務付けられていない。

### 3. 金融商品取引法会計における開示書類

| 財務諸表 | 連結財務諸表（中心となる情報） |
|---|---|
| 貸借対照表 | 連結貸借対照表 |
| 損益計算書 | 連結損益計算書 |
| 株主資本等変動計算書 | 連結損益及び包括利益計算書（一計算書方式の場合） |
| キャッシュ・フロー計算書 | 連結包括利益計算書 |
| 附属明細表 | 連結株主資本等変動計算書 |
|  | 連結キャッシュ・フロー計算書 |
|  | 連結附属明細表 |

連結財務諸表を開示する場合、単体開示の簡素化が認められている。

その他、金融商品取引法は四半期財務諸表の開示を求めている。
