### 1. 会計基準設定の目的

本会計基準は、主としてストック・オプション取引の会計処理及び開示を明らかにすることを目的としている。

ストック・オプション取引の基本的なイメージは、企業が従業員に無償で新株予約権を付与し、従業員が労働サービスを提供する関係である。従業員の労働サービスによって業績が向上し、例えば行使価格500円のところ株価が700円に上昇した場合、従業員は500円を払い込んで700円の株式を取得でき、200円の利益を得る。

企業にとっては、従業員に無償で新株予約権を付与することで従業員のやる気を引き出し、より多くの労働サービスの提供を受けられる。ストック・オプションは、労働の対価、すなわち従業員に対する報酬としての性格を有する。

従来は、無償であることを理由に、ストック・オプションを付与しても会計処理を行わなかった。一方、現行の取扱いでは、ストック・オプションの付与により企業はより多くの労働を消費するため費用計上すべきであり、取引が多く行われてきたことから会計基準を整備する必要がある。このため新基準が整備された。

| 従来 | 現行の取扱い |
|---|---|
| 付与により従業員からより多くの労働を獲得できるが、無償であることを理由に会計処理を行わなかった。仕訳なし。 | 企業はより多くの労働を消費するため費用計上する。取引の会計処理を明らかにする。仕訳例は（借）費用 XXX／（貸）新株予約権 XXX。 |

### 2. 会計基準に関する用語の定義

| 用語 | 定義 |
|---|---|
| 自社株式オプション | 自社の株式を原資産とするコール・オプション。企業が財貨又はサービスを取得する対価として自社株式オプションを取引の相手方に付与し、その結果、自社株式オプション保有者の権利行使に応じて自社の株式を交付する義務を負う場合を扱う。 |
| ストック・オプション | 自社株式オプションのうち、特に企業が従業員等に報酬として付与するもの。権利行使により対象株式を取得できる本来の権利の獲得（権利の確定）に条件が付されているものが多く、条件には勤務条件や業績条件がある。 |
| 従業員等 | 企業と雇用関係にある使用人のほか、企業の取締役、会計参与、監査役及び執行役並びにこれに準ずる者。 |
| 報酬 | 企業が従業員等から受けた労働や業務執行等のサービスの対価として、従業員等に給付されるもの。 |
| 行使価格 | ストック・オプションの権利行使にあたり、払い込むべきものとして定められたストック・オプションの単位当たりの金額。 |
| 付与日 | ストック・オプションが付与された日。会社法における募集新株予約権の割当日がこれにあたる。 |
| 権利確定日 | 権利の確定した日。権利確定日が明らかでない場合、原則として、ストック・オプションを付与された従業員等が権利を行使できる期間（権利行使期間）の開始日の前日を権利確定日とみなす。 |
| 権利行使日 | ストック・オプションを付与された者が権利を行使したことにより、行使価格に基づく金額が払い込まれた日。 |
| 対象勤務期間 | ストック・オプションと報酬関係にあるサービスの提供期間であり、付与日から権利確定日までの期間。 |
| 勤務条件 | 条件付きのストック・オプションにおいて、従業員等の一定期間の勤務や業務執行に基づく条件。 |
| 業績条件 | 条件付きのストック・オプションにおいて、一定の業績（株価を含む）の達成又は不達成に基づく条件。 |
| 公正な評価額 | 一般に市場で形成されている取引価格、気配値又は指標その他の相場（市場価格）に基づく価額。市場価格がない場合でも、自社の株式の市場価格に基づき合理的に算定された価額を入手できるときは、その価額を公正な評価額と認める。また、単位当たりの公正な評価額を公正な評価単価という。 |
| 失効 | 付与されたストック・オプションの権利が行使されないことが確定すること。権利確定条件が達成されなかったことによる権利不確定による失効と、権利行使期間中に行使されなかったことによる権利不行使による失効がある。 |
| 公開企業 | 株式を証券取引所に上場している企業、又はその株式が組織された店頭市場に登録されている企業。海外の証券取引所・店頭市場も含む。組織された店頭市場とは、株価を公表するシステムが存在する店頭市場をいう。 |
| 未公開企業 | 公開企業以外の企業。 |
| 条件変更 | 付与したストック・オプションに係る条件を事後的に変更し、ストック・オプションの公正な評価単価、ストック・オプション数又は合理的な費用の計上期間のいずれか1つ以上を意図して変動させること。 |

自社株式オプションのうち、企業が従業員に報酬として付与するという要件が付加されたものがストック・オプションである。

### 3. ストック・オプション取引のタイムテーブル

一連の取引は次のように進む。

| 時点・期間 | 内容 |
|---|---|
| 付与日 | 従業員にストック・オプションが付与される。 |
| 付与日から権利確定日まで（第1期・第2期） | 従業員は権利を得るため労働サービスを提供する。権利確定条件が達成されない場合は権利不確定による失効となる。 |
| 権利確定日 | ストック・オプションの権利が確定し、この日から権利を行使できる。権利確定日が明らかでない場合は、原則として権利行使期間の開始日の前日を権利確定日とみなす。 |
| 権利行使期間 | 権利を行使できる期間。期間を過ぎると権利行使できず、権利不行使による失効となる。 |
| 権利行使日 | 権利を行使し、従業員が株式の対価を企業に払い込む。 |
