# 第23章 固定資産の減損に係る会計基準

## 第11節 減損会計をめぐる2つのモデル

海外の減損会計基準には大別して2つのモデルがある。一つはFASBが公表しているFAS44「長期性資産の減損または処分に関する会計」におけるモデルであり、もう一つは国際会計基準委員会が公表したIAS36号「資産の減損」におけるモデルである。

### 1. アメリカ（FASB）モデル

アメリカモデルの特徴は次のとおりである。

| 項目 | 内容 |
|---|---|
| 減損の認識 | 資産の帳簿価額と割引前将来キャッシュ・フローの総和との比較により行う。「資産の帳簿価額＞割引前将来キャッシュ・フローの総和」のときに減損損失を認識する。 |
| 減損損失の測定 | 減損を認識した場合、帳簿価額を公正価値（時価）まで引き下げる。 |
| 減損損失の戻入れ | 減損損失の戻入れは行わない。 |
| 減損後の減価償却 | 減損会計適用後についても減価償却計算を行う。 |

このモデルでは、減損会計は資産又は資産グループに対する投資から将来損失が生じ、投資が失敗したことから適用されると考える。投資が失敗してもなお当該資産を継続して保有しているのは、企業が以前の資産を市場でいったん売却し、その後採算の取れる投資として同じ資産に対し再投資したと考えられるからである。

よって、このモデルによれば、減損損失の測定においては、資産を新たに購入する際に必要な額である公正価値を基礎とする。また、以前に投資していた資産を売却したと捉える以上、当該資産との関係は途絶え、企業は新たな資産に対して投資したと考えられるため、過去に計上した減損損失の戻入れは行わない。さらに、減損処理後は資産に再投資したとみなすため、新たな資産の減価償却となる以上、減損処理後も当然に減価償却は継続して行う。

#### 数値例

土地を10,000で取得し、投資が失敗したと判明した場合、土地を売却して現金4,000を受け取り、減損損失6,000を計上した後、同じ土地に対して4,000を再投資したと考える。

```text
① 失敗したので売却（清算）
（借）現金 4,000　（貸）土地 10,000
　　　　　　　　 （貸）減損損失 6,000

② 当該土地に対して再投資
（借）土地 4,000　（貸）現金 4,000
```

### 2. IASモデル（IFRSにおける減損会計のモデル）

IASモデルの特徴は次のとおりである。

| 項目 | 内容 |
|---|---|
| 減損の認識 | 資産の回収可能価額が帳簿価額に満たない状態のときには、直ちにその差額の存在をもって減損損失を認識する。 |
| 減損損失の測定 | 減損を認識した場合、帳簿価額を回収可能価額まで引き下げる。 |
| 減損損失の戻入れ | 減損損失の戻入れを行う。 |
| 減損後の減価償却 | 理論的に減損会計適用後は減価償却手続を行わないとも考えられる。 |

このモデルでは、減損会計は資産の取得原価のうち回収不能部分を貸借対照表に計上しないことで、回収可能部分のみを貸借対照表に計上する観点から適用されると考える。よって、このモデルによれば、減損損失の測定においては回収可能価額を基礎とする。

また、減損損失を認識した後に回収可能価額が帳簿価額を上回る状況が生じたなら、貸借対照表には積極的に回収可能価額を示すべきである以上、減損損失の戻入れを行う。ただし、戻入れの上限を減損処理が行われなかった場合の帳簿価額にすることにより、未実現利益の計上を抑え、取得原価主義との整合性を図っている。

さらに、このモデルでは減損処理により回収可能価額を反映するように帳簿価額を修正した以上、その後の貸借対照表価額は回収可能価額を常に算定し当該金額を付し、その増減額をもって資産に対する損益とするべきともいえる。よって、減損処理後の減価償却手続、すなわち計画的・規則的な費用配分は不要という主張も可能である。

#### 数値例

土地を10,000で取得し、回収可能価額が4,000となった場合、減損損失6,000を認識する。その後、回収可能価額が5,000となった場合には、過年度の減損損失のうち1,000を戻し入れる。

回収可能価額が12,000となった場合には、減損処理前の帳簿価額10,000を上限とする。この場合、減損処理後の帳簿価額4,000から8,000を戻し入れるのではなく、6,000を戻し入れ、帳簿価額を10,000とする。

### 補足　IFRSにおけるのれんの減損の戻入れ

IFRSでは他の資産とは異なり、のれんに関して減損会計を適用した場合、減損損失の戻入れは行わない。

のれんの回収可能価額が回復し、減損処理後の帳簿価額を上回ることは、過去に計上した減損損失の戻入れという性質より、新たにのれんが創造されたとみる方が妥当といえる。つまり、のれんの減損損失の戻入れを認めると、実質的に自己創設ののれんを計上していることと同じといえるため、当該処理は認められていない。
