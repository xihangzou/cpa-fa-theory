# 第29章 税効果会計に係る会計基準
## 第5節 税効果会計に関する注記事項

### 1. 税効果会計に関する注記事項

財務諸表及び連結財務諸表には、次の事項を注記しなければならない。

1. 繰延税金資産及び繰延税金負債の発生原因別の主な内訳。
2. 税引前当期純利益又は税金等調整前当期純利益に対する法人税等（法人税等調整額を含む）の比率と法定実効税率との間に重要な差異があるときは、当該差異の原因となった主要な項目別の内訳。
3. 税率の変更により繰延税金資産及び繰延税金負債の金額が修正されたときは、その旨及び修正額。
4. 決算日後に税率の変更があった場合には、その内容及びその影響。

③は当期中に税率の変更があった場合の注記事項であり、④は翌期に税率の変更があった場合の注記事項である。翌期の税率変更は当期の財務諸表上、税率変更を加味することができない。

#### (1) ①の注記について

繰延税金資産及び繰延税金負債の発生原因別の主な内訳を注記する。繰延税金資産の発生原因別の主な内訳を注記するに当たっては、回収可能性がないため繰延税金資産から控除された額も併せて記載する。

##### 設例　繰延税金資産の内訳

| 繰延税金資産 | 金額 |
|---|---:|
| 未払事業税 | 800 |
| 貸倒引当金 | 600 |
| 退職給付引当金 | 1,200 |
| 繰延税金資産小計 | 2,600 |
| 評価性引当額（回収可能性がないため控除された額） | △400 |
| 繰延税金資産合計 | 2,200 |

##### 補足　評価性引当額に係る注記

繰延税金資産の発生原因別の主な内訳として税務上の繰越欠損金を記載している場合で、当該税務上の繰越欠損金の額が重要であるときは、繰延税金資産から控除された額（評価性引当額）を、税務上の繰越欠損金に係る評価性引当額と将来減算一時差異等の合計に係る評価性引当額に区分して記載する。

さらに、繰延税金資産から控除された額（評価性引当額）に重要な変動が生じている場合、当該変動の主な内容を記載する。連結財務諸表を作成している場合、個別財務諸表において記載することを要しない。

##### 設例　税務上の繰越欠損金に係る注記例

当社は、繰延税金資産の発生原因別の主な内訳として税務上の繰越欠損金を記載し、当該税務上の繰越欠損金の額が重要であると判断している。

| 繰延税金資産 | 当連結会計年度 |
|---|---:|
| 税務上の繰越欠損金（金額的重要性が高い） | 10,800 |
| 退職給付に係る負債 | 2,400 |
| 減損損失 | 4,300 |
| 繰延税金資産小計 | 17,500 |
| 税務上の繰越欠損金に係る評価性引当額 | △3,000 |
| 将来減算一時差異等の合計に係る評価性引当額 | △1,500 |
| 評価性引当額小計 | △4,500 |
| 繰延税金資産合計 | 13,000 |

税務上の繰越欠損金を繰延税金資産の発生原因別の主な内訳に記載している場合で、その額が重要であるときは、連結財務諸表を作成している場合を除き、次の事項を記載する。

- 税務上の繰越欠損金の額に税主体ごとの法定実効税率を乗じた額。
- 税務上の繰越欠損金に係る繰延税金資産から控除された額（評価性引当額）。
- 税務上の繰越欠損金に係る繰延税金資産の額。
- 税務上の繰越欠損金に係る重要な繰延税金資産を計上している場合、当該繰延税金資産を回収可能と判断した主な理由。

#### (2) ②の注記（税率差異の注記）について

税引前当期純利益（又は税金等調整前当期純利益）に対する法人税等（法人税等調整額を含む）の比率は、次のように示すことができる。

税効果会計適用後の法人税等の負担率 ＝ （法人税等＋法人税等調整額）÷ 税引前当期純利益（税金等調整前当期純利益）

通常、税効果会計適用後の法人税等の負担率と法定実効税率は一致するが、永久差異などがあると一致しない。この場合には、実際の税金負担率と会計上の税金負担率の乖離を利害関係者に開示するため、差異の原因となった主要な項目別の内訳を注記する。

差異が法定実効税率の5%以下である場合には、注記を省略することができる。

（税効果適用後負担率－法定実効税率）÷法定実効税率 ≦ 5% の場合、注記の省略が可能である。

##### 具体例　②の注記事項

税引前当期純利益2,000、貸倒引当金の損金算入限度超過額200、交際費損金算入限度超過額400（永久差異のため税効果会計の対象外）、法定実効税率30.0%とする。

| 計算 | 金額 |
|---|---:|
| 法人税、住民税及び事業税 | (2,000＋200＋400)×30.0%＝780 |
| 法人税等調整額 | 200×30.0%＝60（貸方） |
| 税効果会計適用後の法人税等の負担率 | (780－60)÷2,000＝36.0% |

交際費は税効果会計の対象とならないため、貸倒引当金の損金算入限度超過額についてのみ法人税等調整額を認識する。法定実効税率30.0%との間に差異が生じるため、次のような注記が必要となる。

| 法定実効税率と税効果会計適用後の法人税等の負担率との差異の原因となった主な項目別の内訳 | 率 |
|---|---:|
| 法定実効税率 | 30.0% |
| （調整）交際費等永久に損金に算入されない項目 | 6.0% |
| 税効果会計適用後の法人税等の負担率 | 36.0% |

交際費等の調整は400×30.0%÷2,000＝6.0%である。注記の省略可否は、（36.0%－30.0%）÷30.0%＞5%となるため、省略不可である。
