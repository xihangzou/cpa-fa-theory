# 第30章 リース取引に関する会計基準
## 第4節 ファイナンス・リース取引の貸手の会計処理

### 4. ファイナンス・リース取引の貸手側の開示

#### (1) 貸借対照表上の表示

リース債権及びリース投資資産の表示区分は、当該企業の取引の性質により次のように決まる。

- 当該企業の主目的たる営業取引により発生したものである場合には、正常営業循環基準の考え方に基づき、流動資産の区分に表示する。
- 当該企業の営業の主目的以外の取引により発生したものである場合には、一年基準の考え方に基づき、流動資産又は固定資産の区分に表示する。

#### (2) 貸手側における注記事項

リース債権及びリース投資資産に係るリース料債権部分について、貸借対照表日後5年以内における1年ごとの回収予定額及び5年超の回収予定額を注記する。重要性が乏しい場合には、当該注記を要しない。

リース投資資産については、将来のリース料を受収する権利（「リース料債権」という）部分と見積残存価額部分の金額（各々、利息相当額控除前）並びに受取利息相当額を注記する。ただし、重要性が乏しい場合には、当該注記を要しない。
