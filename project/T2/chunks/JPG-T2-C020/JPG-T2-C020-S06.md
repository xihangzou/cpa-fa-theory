# 第30章 リース取引に関する会計基準
## 第6節 転リース取引

転リース取引とは、リース物件の所有者から当該物件のリースを受け、さらに同一物件を概ね同一の条件で第三者にリースする取引をいう（いわゆる又貸し）。

### 1. 転リース取引の会計処理

転リース取引において、借手としてのリース取引及び貸手としてのリース取引の双方がファイナンス・リース取引に該当する場合、次のように処理する。

| 貸借対照表 | 損益計算書 |
|---|---|
| リース債権又はリース投資資産とリース債務の双方を計上する。 | 貸手として受け取るリース料総額と借手として支払うリース料総額との差額を手数料収入とし、各期に配分して「転リース差益」等の名称で計上する。 |

リース債権又はリース投資資産とリース債務は、原則として利息相当額控除後の金額で計上する。ただし、利息相当額控除前の全額で計上することもできる。

#### 設例　転リース取引の回収・返済スケジュール

B社の転リース取引の回収・返済スケジュール（実効利子率7.931%、単位：千円）は次のとおりである。

| 回収日（貸手）／返済日（借手） | 前期末元本 | 回収合計（貸手） | 転リース差益（貸手） | 返済合計（借手） | 利息分 | 元本分 | 期末元本 |
|---|---:|---:|---:|---:|---:|---:|---:|
| X2.3.31 | 48,000 | 12,060 | 60 | 12,000 | 3,807 | 8,193 | 39,807 |
| X3.3.31 | 39,807 | 12,060 | 60 | 12,000 | 3,157 | 8,843 | 30,964 |
| （以下省略） |  |  |  |  |  |  |  |

リース取引の開始時：

| 借方 | 金額 | 貸方 | 金額 |
|---|---:|---|---:|
| リース債権 | 48,000 | リース債務 | 48,000 |

リース料の回収時：

| 借方 | 金額 | 貸方 | 金額 |
|---|---:|---|---:|
| 現金預金 | 12,060 | リース債権 | 8,193 |
|  |  | 預り金 | 3,807 |
|  |  | 転リース差益 | 60 |

リース料の支払時：

| 借方 | 金額 | 貸方 | 金額 |
|---|---:|---|---:|
| リース債務 | 8,193 | 現金預金 | 12,000 |
| 預り金 | 3,807 |  |  |

手数料収入60以外は、損益は生じていないといえるため、利息部分は預り金として処理する。
