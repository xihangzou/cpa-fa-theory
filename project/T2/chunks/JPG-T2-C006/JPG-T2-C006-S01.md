### 1. 退職給付の意義とその性格

退職給付とは、一定の期間にわたり労働を提供したこと等の事由に基づいて、退職後に従業員へ支給される給付をいう。

退職給付の性格には、次の3つの考え方がある。

| 考え方 | 内容 |
| --- | --- |
| 賃金後払説（現行の取扱い） | 労働協約等に基づいて従業員が提供した労働の対価として支払われるものであり、労働の提供を受けた後に対価を支払うため、賃金の後払いと捉える。 |
| 功績報償説 | 従業員の勤続に対する功績報償、すなわち長期の勤続に対するお礼として支払われるものと捉える。 |
| 生活保障説 | 従業員の老後の生活保障として支払われるものと捉える。 |

「退職給付に関する会計基準」は、退職給付が賃金の後払いの性格を有すると捉え、「賃金後払説」を採用している。

### 2. 退職給付の分類

退職給付制度は、①退職者への支払方法、②給付を支給する主体、③運用リスクを負う主体という観点から分類できる。

#### ① 退職者に退職給付を支払う方法

| 区分 | 内容 |
| --- | --- |
| 一時金支給 | 退職時に一括で企業から退職金が支払われる方法（退職一時金制度）。 |
| 年金支給 | 退職以後、一定期間にわたり退職金が分割して支払われる方法（企業年金制度）。 |

#### ② 退職給付を支給する主体

| 区分 | 内容 |
| --- | --- |
| 内部引当 | 退職給付の原資が企業内部に積み立てられ、企業が退職者に直接支給する方法。 |
| 外部積立 | 退職給付の原資が企業外部に積み立てられ、外部機関が退職者に支給する方法。 |

#### ③ 運用リスクを負う主体

| 区分 | 内容 |
| --- | --- |
| 確定拠出型 | 掛金を外部に積み立て、事業主である企業が掛金以外の退職給付に係る追加的な拠出義務を負わない制度。企業が毎期拠出する掛金は一定額に確定しているが、従業員が受け取る退職金は確定していないため、掛金の運用リスクは従業員が負う。 |
| 確定給付型 | 従業員が受け取る退職給付額が確定している制度。確定額に満たない場合は企業側に追加的な負担が生じるため、掛金の運用リスクは企業側が負う。 |

### 3. 本会計基準の適用範囲

我が国では、一般に「一時金支給」の場合には「内部引当」を採用し、「年金支給」の場合には「外部積立」を採用している。このため、本会計基準もこの組合せを前提としている。

| 支払方法 | 運用方法 |
| --- | --- |
| 一時金支給 | 内部引当 |
| 年金支給 | 外部積立 |

本会計基準は、退職一時金制度、確定給付型の企業年金制度及び確定拠出型の退職給付制度を対象とする。主な対象は確定給付型の企業年金制度である。

株主総会の決議又は指名委員会等設置会社における報酬委員会の決定が必要となる役員（取締役、会計参与、監査役及び執行役）の退職慰労金は、本会計基準の適用範囲に含めない。これは、役員の退職慰労金は功績報償的な性格が強く、労働の対価としての関係が明確でないためである。

一方、厚生年金基金制度及び確定給付企業年金制度に含まれる役員部分（年金制度に基づき役員に支払われる退職金）は、本会計基準の適用対象となる。

#### 補足：厚生年金基金

厚生年金基金制度は、給付算定式や計算基礎が異なる「加算部分」及び「代行部分」から構成される制度である。

| 部分 | 内容 |
| --- | --- |
| 加算部分 | 最終給与比例制度やポイント制度など、企業が独自に給付設計できる部分。 |
| 代行部分 | 平均標準報酬月額に基づく、一種の平均給与比例制度として給付額が算定される部分。 |

企業会計上は、両部分を区分せず、全体を1つの退職給付制度とみなして同一の会計処理を適用する。

### 4. 本会計基準が適用される財務諸表

本会計基準の適用は、個別財務諸表と連結財務諸表とで異なる。本テキストでは、基本的にまず個別財務諸表を前提とした取扱いを説明し、その後、連結財務諸表のみに適用される規定を説明する。

### 5. 従来と現行の取扱いの相違点

我が国では退職給付について退職一時金制度と企業年金制度が併用されている。従来は、退職一時金制度を退職給与引当金として処理し、企業年金制度は掛金拠出額を支払時の費用として処理していた。現行は、退職一時金制度を退職給付引当金として処理する。

本会計基準は退職給付を労働の対価として支払われる賃金の後払いと捉えるため、退職給付費用は勤務期間を通じた労働の提供に伴って発生する。したがって、支出の事実ではなく、発生した期間に費用として認識する発生主義に基づく。

退職金は退職時に支払われるが、その将来支出の原因は各期において労働の提供を受けたことにある。したがって、入社から退職までの各勤務期間に対応する費用を認識する。
