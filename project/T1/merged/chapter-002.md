### 1. 一般原則の体系

出題ランク：短答 C、論文 D

企業会計原則は、「一般原則」「損益計算書原則」「貸借対照表原則」によって構成される。これらは並列的な関係ではなく、一般原則が損益計算書原則及び貸借対照表原則よりも上位に位置する。

一般原則は、企業会計の全般にかかわる基本的なルール、あるいは損益計算書と貸借対照表の双方に共通するルールを示した規定であり、次の原則から成り立っている。

- 真実性の原則
- 正規の簿記の原則
- 資本取引・損益取引区分の原則
- 明瞭性の原則
- 継続性の原則
- 保守主義の原則
- 単一性の原則
- 重要性の原則（括弧書き）

関係は、一般原則が上位にあり、損益計算書原則及び貸借対照表原則が下位にある。一般原則の中には上記8原則が位置づけられる。

### 2. 一般原則の全体像

出題ランク：短答 C、論文 D

一般原則の全体像は以下のとおりである。

| 位置づけ | 原則 | 内容 |

| 下から支える6原則 | 正規の簿記の原則 | 会計帳簿は正確に作成し、財務諸表は会計帳簿から作成する |
|  | 資本取引・損益取引区分の原則 | 資本と利益は区別する |
|  | 明瞭性の原則 | 財務諸表はわかりやすく、また内容を詳細に開示する |
|  | 継続性の原則 | 処理方法や表示方法は継続的に適用する |
|  | 保守主義の原則 | 慎重な判断に基づいた会計処理を採用する |
|  | 単一性の原則 | 実質一元・形式多元 |

重要性の原則は、会計処理面では正規の簿記の原則等と関連し、表示面では明瞭性の原則と関連する。重要なことは厳密に、重要でないことは簡便に扱う。
## 第2節 真実性の原則

「企業会計原則 第一 一」には、以下のように規定されている。

> 企業会計は、企業の財政状態及び経営成績に関して、真実な報告を提供するものでなければならない。

### 1. 真実性の原則の位置付け

出題ランク：短答 B、論文 C

真実性の原則とは、企業会計は企業の財政状態及び経営成績に関して、真実な報告を提供しなければならないことを要請する原則をいう。

真実性の原則は、企業会計の究極目標を示したものであり、企業会計のすべての原則を統括する企業会計の最高規範である。他の原則は真実性の原則を支えているという関係があり、他の原則が遵守されることで真実な報告が確保される。

### 2. 「真実性」の意味内容

出題ランク：短答 B、論文 C

真実性の原則がいうところの真実とは絶対的な真実でなく、「相対的な真実」を意味する。真実の内容が相対的にならざるを得ない理由は次のとおりである。

| 理由 | 内容 |
|---|---|
| 会計の目的の依存性 | 真実の意味は会計の目的に依存する。会計の目的は時代や場所によって異なるため、真実性の原則の「真実」も相対的に変化する。 |
| 期間損益計算の暫定性 | 継続企業を前提とした期間損益計算では、経営者の見積りや判断が不可避的に介入する。例えば売上債権に対する貸倒引当金の金額は見積計算となるため、これに基づく会計数値は暫定的なものとなる。 |
| 代替的な会計処理の容認 | 同一の会計事実について複数の代替的会計処理が容認されており、いずれを選択するかによって計算結果は異なる。 |

固定資産を購入した場合、事業活動の継続を前提とすれば、資産の取得原価を将来にわたり配分する必要がある。しかし、何年間で配分するかは経営者が個々に見積るため、費用計算には経営者の見積りや判断が介入せざるを得ない。
## 第3節 正規の簿記の原則

「企業会計原則 第一 二」には、以下のように規定されている。

> 企業会計は、すべての取引につき、正規の簿記の原則に従って、正確な会計帳簿を作成しなければならない。

### 1. 「正規の簿記の原則」の意味内容

出題ランク：短答 B、論文 C

正規の簿記の原則とは、第一に会計帳簿を一定の要件（網羅性、検証可能性、秩序性）に従って正確に作成すること、第二に会計帳簿と財務諸表との間において有機的な関連性を保持すべきことを要求している原則である。

#### (1) 会計帳簿の作成要件

出題ランク：短答 B、論文 C

会計帳簿を正確に作成するための要件は次の3点である。

| 要件 | 内容 |
|---|---|
| 記録の網羅性 | 企業内容の開示にあたり、企業の経営成績、財政状態及びキャッシュ・フローの状況に影響を与える全ての取引がもれなく記録される。 |
| 記録の検証可能性 | 会計記録が取引事実を立証しうる証拠資料に基づく。証拠がないのに記録してはならない。例えば領収書に基づく会計記録は、取引事実を立証するのに十分な情報を提供する。 |
| 記録の秩序性 | 仕訳帳と元帳、主要簿と補助簿等の会計記録が体系的で、秩序正しい相互関連性を保っている。 |

記録の秩序性は、仕訳帳の仕訳が総勘定元帳へ転記され、両者が相互に関連する関係として示される。仕訳帳の例は、（借）現金100（貸）売上100、（借）貸付金500（貸）現金500であり、総勘定元帳には前期繰越1,000、貸付金500、売上100等が記録される。

#### (2) 会計帳簿と財務諸表の間との有機的な関連性

出題ランク：短答 B、論文 C

会計帳簿と財務諸表との間の有機的な関連性とは、財務諸表が会計帳簿から誘導的に作成されることを示している。会計帳簿と関係のない情報に基づき、財務諸表を作成することは否定される。

したがって、正規の簿記の原則の下では、会計帳簿及び損益計算書とは無関係に、毎決算期における財産の実地調査により貸借対照表を作成する「棚卸法」は否定される。

取引の発生から、正確な会計帳簿（記録の網羅性・検証可能性・秩序性）、仕訳帳、元帳を経て、財務諸表が作成される。会計帳簿間にも相互関連性があり、会計帳簿と財務諸表にも相互関連性がある。

### 2. 「正規の簿記の原則」と簿外資産・簿外負債の関係

出題ランク：短答 B、論文 C

正規の簿記の原則はすべての取引の正確な記録を要求するため、簿外資産や簿外負債は原則として存在してはならない。しかし、「重要性の原則」の適用によって、簿外資産や簿外負債が認められる場合もある。

消耗品、消耗工具器具備品その他の貯蔵品等のうち、重要性の乏しいものについては、その買入時又は払出時に費用として処理する方法を採用することができる。

利害関係者が企業の経営成績や財政状態を判断する上で重要性の乏しいものについては、厳密な会計処理によらず、他の簡便な会計処理によることも、正規の簿記の原則に従った処理として認められる。

### 補足　貸借対照表完全性の原則と正規の簿記の原則

出題ランク：短答 C、論文 C

貸借対照表完全性の原則とは、貸借対照表日におけるすべての資産、負債及び資本を記載することを要請するものである。企業会計原則は、貸借対照表は企業の財政状態を明らかにするため、貸借対照表日におけるすべての資産、負債及び資本を記載し、株主、債権者その他の利害関係者にこれを正しく表示するものでなければならないとする。ただし、正規の簿記の原則に従って処理された場合に生じた簿外資産及び簿外負債は、貸借対照表の記載外におくことができる。

正規の簿記の原則は、すべての取引を網羅的に正しく記録することを要請するため、貸借対照表完全性の原則と密接に結びついている。正しく会計処理すれば簿外資産・簿外負債は存在せず、すべての資産・負債が貸借対照表に計上される。本来は貸借対照表完全性の原則を厳密に捉えれば簿外資産・簿外負債は認められないが、重要性の原則に従って処理された場合に生じたものは同原則に反しない。

### 3. 「正規の簿記の原則」と複式簿記の関係

出題ランク：短答 C、論文 D

正規の簿記として、必ずしも複式簿記が予定されているわけではなく、単式簿記によることも認められる。ただし、記録の網羅性、検証可能性、秩序性を満たすものとしては、複式簿記が最も適している。

単式簿記のイメージとして現金出納帳を挙げると、4/1のA社への売上10,000を入金、4/2の水道光熱費2,300を出金として記録する。現金の出入りは把握するが、その原因である売上や水道光熱費の変動を必ずしも把握する必要はなく、現金という一面で捉える。単式簿記であっても、財務諸表の作成に必要な帳簿（預金出納帳や固定資産台帳等）をすべて作成すれば、正確な会計帳簿を作成することは可能である。
## 第4節 資本取引・損益取引区分の原則

「企業会計原則 第一 三」には、以下のように規定されている。

> 資本取引と損益取引とを明瞭に区分し、特に資本剰余金と利益剰余金とを混同してはならない。

### 1. 「資本取引・損益取引区分の原則」の意味内容

出題ランク：短答 B、論文 C

この原則は、①資本取引と損益取引の区分、②資本剰余金と利益剰余金の区分の2つを要請する。

### 2. 資本取引と損益取引の区分

#### (1) 資本取引と損益取引の相違

出題ランク：短答 B、論文 B

資本取引とは、純資産を直接的に増減させる取引で、企業活動の成果とは無関係の取引をいう。一方、損益取引とは、企業活動の成果と関連する取引をいう。両者とも結果的に企業の純資産を増減させる。

資本取引の例は、期中に増資を行い株式を30発行する取引（借方現金30、貸方純資産30）と、期中に10の配当を実施する取引（借方純資産10、貸方現金10）である。期首の資産100・負債50・純資産50は、増資後に資産120・負債50・純資産70となるが、企業活動の成果とは無関係である。

損益取引の例は、現金で商品を20仕入れる取引（借方商品20、貸方現金20）と、商品を40で販売する取引（借方現金40、貸方商品20・販売益20）である。期首の資産100・負債50・純資産50は、販売後に資産120・負債50・純資産70となり、販売益20が損益計算書の期間利益20となる。

資本取引は、①純資産を直接増減させる取引であり、②その性質上、企業活動の成果とは無関係である。損益取引は、いったん収益・費用として損益計算書に計上され、①その結果として純資産を間接的に増減させる取引であり、②その性質上、企業活動の成果に関連する。

#### (2) 資本取引と損益取引を区分する理由

出題ランク：短答 B、論文 C

区分が要請される理由は、財務会計の情報提供機能から説明できる。意思決定情報として最も重要視されるのは期間損益であるため、財務会計では期間損益を適正に算定することが重要である。期間損益計算は、一会計期間における企業活動の成果による純資産の増減を計算するものなので、純資産を増減させる取引であっても企業活動の成果とは関係しない資本取引は除き、損益取引のみを構成要素として期間損益を計算しなければならない。

期間損益を適正に算定し、投資者に有用な意思決定情報を提供するため、資本取引と損益取引は区別される。企業会計原則が「新株発行による株式払込剰余金から新株発行費用（株式交付費）を控除することは許されない」と規定するのも、両者を区別すべき旨を示すものである。区分しなければ、株式発行の貸方を収益30として処理でき、利益計算が不適正となる。

### 3. 資本剰余金と利益剰余金の区分

#### (1) 資本剰余金と利益剰余金の意義

出題ランク：短答 B、論文 C

資本剰余金とは、資本取引から生じた元本たる資本のうち資本金以外のものであり、資本準備金とその他資本剰余金に分類される。利益剰余金とは、損益取引から生じた企業内に留保された利益であり、利益準備金とその他利益剰余金に分類される。

#### (2) 資本剰余金と利益剰余金を区分する理由

出題ランク：短答 B、論文 C

貸借対照表の表示上、区分が要請される理由は、財務会計の利害調整機能（株主と債権者）から説明できる。会社財産が配当により株主に分配されることで、利払い不能や債務不履行リスクが過度に高まることは防止する必要がある。

会計上、基本的に元本である払込資本を分配不能、留保利益を分配可能として、それぞれ区分して表示することで、過度に会社財産が流出することを防止し、株主と債権者の利害調整を図る。したがって、払込資本である資本剰余金と留保利益である利益剰余金は混同してはならない。

貸借対照表上、純資産の部に資本剰余金と利益剰余金を区分して表示するからこそ、分配可能部分と分配不能部分を明確にできる。両者を純資産として一括表示すると、どこまでが分配可能か不明瞭となる。

利害調整機能以外にも、分配不能部分を明確にすることで一定の会社財産が企業内に留保され、企業の健全な運営を維持できる。また、払込資本と留保利益を区分することで元本とそれを運用して獲得した成果を明確化し、投資者に有用な情報を提供できる（情報提供機能）。

現行制度上、会社法との調整を図り、資本剰余金のうちその他資本剰余金は分配可能、利益剰余金のうち利益準備金は分配不能として扱われる。

|  | 資本剰余金 | 利益剰余金 |
|---|---|---|
| 会計理論上 | すべて分配不能とするべき | すべて分配可能とするべき |
| 現行制度上 | 資本準備金は分配不能、その他資本剰余金は分配可能 | 利益準備金は分配不能、その他利益剰余金は分配可能 |

会計理論上のあるべき取扱いと現行制度上の取扱いは一致していない。
## 第5節 明瞭性の原則

「企業会計原則 第一 四」には、以下のように規定されている。

> 企業会計は、財務諸表によって、利害関係者に対し必要な会計事実を明瞭に表示し、企業の状況に関する判断を誤らせないようにしなければならない。

### 1. 「明瞭性の原則」の意味内容

出題ランク：短答 B、論文 C

明瞭性の原則とは、企業の状況に関する利害関係者の判断を誤らせないようにするため、①利害関係者の意思決定に重要な影響を及ぼす項目については詳細情報を開示する一方で、②財務諸表の理解や比較を容易にするため財務諸表の形式の統一を要請する原則である（表示方法に関する原則）。

簡潔にいえば、①重要性の高いことは詳細に表示する（詳細性）一方で、②財務諸表を見やすくわかりやすくするように形式の統一化を図る（概観性）という2つの側面を有する。詳細性を重視しすぎて会計的事実を重要性の高低にかかわらずすべて表示すると、財務諸表は見づらくわかりづらくなり、概観性が得られない。詳細性と概観性のバランスをとり、明瞭な表示を要求する原則が明瞭性の原則である。

### 2. 明瞭性の原則の適用例

現行制度における主な適用例は次のとおりである。

#### (1) 損益計算書・貸借対照表の形式（概観性に関する論点）

出題ランク：短答 C、論文 C

損益計算書・貸借対照表の表示方法には、「報告式」と「勘定式」という2つの形式がある。経営者が好きなように表示すると不明瞭になるため、形式を統一する。

- 報告式：はじめに売上高、流動資産を記載し、上から下へ表示する様式。
- 勘定式：紙面を左右に二分し、貸方に収益・負債・純資産項目、借方に費用・資産項目を記載する様式。

#### (2) 附属明細表の作成（詳細性に関する論点）

出題ランク：短答 B、論文 C

附属明細表とは、財務諸表の重要な科目について貸借対照表や損益計算書の記載内容を補足するため、①一定の項目の期末残高の内訳ないし明細、②当該項目の期中における増減状況を表示した書類（財務諸表を構成する書類の一つ）をいう。会社計算規則では「附属明細書」と呼ばれる。四半期財務諸表及び四半期連結財務諸表では開示対象ではない。

| 財務諸表等規則 | 連結財務諸表規則 | 会社計算規則（117条） |
|---|---|---|
| 有価証券明細表、有形固定資産等明細表、社債明細表、借入金等明細表、引当金明細表、資産除去債務明細表 | 社債明細表、借入金等明細表、資産除去債務明細表 | 有形固定資産及び無形固定資産の明細、引当金の明細、販売費及び一般管理費の明細 |

連結財務諸表を作成している場合、個別財務諸表上の「社債明細表」「借入金等明細表」「資産除去債務明細表」は作成を要しない。連結財務諸表規則の3項目は、法的に支払義務を負っている項目を開示する。

引当金明細表の開示例は次のとおりである。

| 区分 | 前期末残高 | 当期増加額 | 当期減少額（目的使用） | 当期減少額（その他） | 期末残高 | 摘要 |
|---|---:|---:|---:|---:|---:|---|
| 貸倒引当金 | 560 | 500 | 480 |  | 580 |  |
| 製品保証引当金 | 750 | 770 | 720 |  | 800 |  |

引当金の期中の増減情報は貸借対照表や損益計算書だけでは十分に把握できないが、投資者の企業分析に必要となる場合があるため、より詳細に開示する。

注記とは、財務諸表利用者が企業の状況についてより適切な判断ができるよう、重要な項目について補足的な説明を記載するものである。貸借対照表や損益計算書では把握できない重要な情報を記載し、附属明細表のような金額の増減とは異なる情報を提供する。

#### (3) 会計方針の注記

##### ① 会計方針の注記とその内容

出題ランク：短答 B、論文 C

会計方針とは、財務諸表の作成にあたって採用した会計処理の原則及び手続をいう。財務諸表には重要な会計方針を注記する。ただし重要性の乏しいものは注記を省略できる。例は次のとおりである。

1. 有価証券の評価基準及び評価方法
2. 棚卸資産の評価基準及び評価方法（先入先出法、平均法など）
3. 固定資産の減価償却の方法（定額法、定率法など）
4. 繰延資産の処理方法
5. 外貨建の資産及び負債の本邦通貨への換算基準
6. 引当金の計上基準
7. 収益及び費用の計上基準

会計基準等の定めが明らかで、当該会計基準等において代替的な会計処理の原則及び手続が認められていない場合には、会計方針に関する注記を省略できる。

有価証券の評価方法には、取得原価を算定するために採用した方法（移動平均法、総平均法等）と、その他有価証券の時価評価における評価差額の取扱いが含まれる。繰延資産の処理方法には、株式交付費・社債発行費等を支出時に全額費用処理する場合が含まれ、繰延資産に計上する場合は償却期間及び償却方法を記載する。外貨建資産・負債の換算基準については、基準に定めのない事項、又は基準の適用が適当でない場合に採用した他の合理的な換算基準等を記載する。引当金の計上基準には各引当金の計上理由、計算の基礎その他の設定根拠を記載する。収益・費用の計上基準にはファイナンス・リース取引等、財務諸表について適正な判断に必要な事項を記載する。

その他、支払利息を資産の取得原価に算入する会計処理の内容等、財務諸表について適正な判断に必要と認められる基本事項も開示対象となる。

##### ② 会計方針の注記の記載場所

出題ランク：短答 B、論文 C

| 制度 | 記載場所 |
|---|---|
| 金融商品取引法会計 | 会計方針はキャッシュ・フロー計算書の次に記載する。連結財務諸表でも同じ。 |
| 会社法会計 | 会計方針は個別注記表に記載する。連結計算書類でも同じ。 |

##### ③ 会計方針の注記の開示目的

出題ランク：短答 B、論文 C

一つの会計事実について複数の会計方針が認められている場合、いずれを採用するかにより財務諸表の数値は異なる。そのため、会計数値の算定方法等の財務諸表作成の基礎を明らかにする必要がある。

重要な会計方針に関する注記の開示目的は、財務諸表を作成するための基礎となる事項を財務諸表利用者が理解できるように、採用した会計処理の原則及び手続の概要を示すことである。特定の会計事象等に関する会計基準等の定めが明らかでない場合にも、重要性があれば会計方針の注記を行う。例えば投資者には減価償却費の算定根拠を知りたいというニーズがある。

#### (4) 後発事象の注記

##### ① 後発事象の注記とその内容

出題ランク：短答 B、論文 C

後発事象とは、貸借対照表日後、財務諸表提出会社の翌事業年度以降の財政状態及び経営成績及びキャッシュ・フローの状況に影響を及ぼすものをいう。重要な後発事象が発生したときは、当該事項を注記しなければならない。

重要な後発事象の例は、火災・出水等による重大な損害の発生、多額の増資又は減資及び多額の社債の発行又は繰上償還、会社の合併・重要な営業の譲渡又は譲受、重要な係争事件の発生又は解決、主要な取引先の倒産である。

貸借対照表日後3か月以内に財務諸表を開示する場合、期末日後に生じた事象で当期の財務諸表に反映されていない事象を後発事象という。当期の財務諸表に反映できるのは当期首から当期末に生じた事象のみである。

##### ② 重要な後発事象の注記の必要性

出題ランク：短答 C、論文 C

後発事象は当期の財務諸表には直接反映されないが、財務諸表利用者の意思決定に大きな影響を及ぼす。重要な後発事象を注記することで、企業の将来の財政状態及び経営成績を理解するための補足情報を提供できる。財務諸表は決算日における情報を示すにとどまり、公表時には適時性を欠くことがあるため、注記により決算日後から財務諸表作成日までのタイムラグを埋める。

### 補足　修正後発事象と開示後発事象

出題ランク：短答 B、論文 C

| 区分 | 内容 | 例 |
|---|---|---|
| 修正後発事象 | 決算日現在において既に存在していた状況証拠が、決算日から当該年度の財務諸表を作成する日までに確実になった場合。当年度の財務諸表を修正する必要がある。 | 得意先に対する売上債権の貸倒引当金を積み増す場合 |
| 開示後発事象 | 決算日後に全く新しい事象が発生した場合。当年度の財務諸表に注記する必要がある。 | 決算日後の災害により機械設備が損害を受けた場合 |

#### (5) その他重要事項の注記

##### ① 追加情報

出題ランク：短答 A、論文 C

追加情報とは、「財務諸表等規則（表示や注記についてのルール）」に定められている注記のほか、利害関係人が会社の財政状態、経営成績、キャッシュ・フローの状況について適正な判断を行うために必要と認められる情報をいう。追加情報については注記しなければならない。

##### ② 継続企業

出題ランク：短答 A、論文 C

貸借対照表日において、継続企業の前提に重要な疑義を生じさせる事象又は状況が存在し、当該事象又は状況を解消し又は改善するための対応をしてもなお、継続企業の前提に関する重要な不確実性が認められるときは、次の事項を注記する。ただし、貸借対照表日後に重要な不確実性が認められなくなった場合は注記しない。

1. 当該事象又は状況が存在する旨及びその内容
2. 当該事象又は状況を解消し、又は改善するための対応策
3. 当該重要な不確実性が認められる旨及びその理由
4. 当該重要な不確実性の影響を財務諸表に反映しているか否かの別

貸借対照表日後にこのような状況が発生した場合は、重要な後発事象に該当する。

### 補足　注記の順序

出題ランク：短答 C、論文 C

会計方針、会計方針の変更及び継続企業の前提に関する注記について、次の規定がある。

1. 会計方針の注記は、キャッシュ・フロー計算書の次に記載しなければならない。
2. 会計方針の変更に関する注記は、会計方針の注記の次に記載しなければならない。
3. 継続企業の前提に関する注記は、上記の規定にかかわらず、キャッシュ・フロー計算書の次に記載しなければならない。

したがって、①のみの場合はキャッシュ・フロー計算書、会計方針の注記、その他の注記の順となる。①及び②がある場合は、キャッシュ・フロー計算書、会計方針の注記、会計方針の変更の注記、その他の注記の順となる。①及び③がある場合は、キャッシュ・フロー計算書、継続企業の前提の注記、会計方針の注記、その他の注記の順となる。
## 第6節 継続性の原則

「企業会計原則 第一 五」には、以下のように規定されている。

> 企業会計は、その処理の原則及び手続を毎期継続して適用し、みだりにこれを変更してはならない。

「みだりに」とは「正当な理由なく」を意味する。

### 1. 「継続性の原則」の意味内容と必要性

出題ランク：短答 B、論文 C

継続性の原則とは、いったん採用した会計方針は、正当な理由により変更を行う場合を除き、財務諸表を作成する各時期を通じて継続して適用しなければならないとする原則である。

多種多様な企業の実態を適正に表示するため、同一の会計事実に対して複数の会計方針が認められ、各企業が実情に応じて選択できる。しかし選択適用を無条件に認めると、恣意的な会計処理によって利益操作を行う可能性がある。よって、企業の利益操作を防止するために継続性の原則が必要となる。

利益操作とは、利益の数値を意図的に変えることである。会計処理を自由に変更できると、利益の数値を好きなように変えられる。例えば、100円、120円、140円の商品を当期に3つ仕入れて2つ販売した場合、これまで総平均法を採用していた企業が先入先出法に変更すると、総平均法では（100円＋120円＋140円）×2/3＝240円（売上原価）であるのに対し、先入先出法では100円＋120円＝220円（売上原価）となり、費用を20円小さくできる。

### 補足　継続性の原則と比較可能性の確保

出題ランク：短答 C、論文 C

継続性の原則の必要性は、利益操作の防止のみならず、会計数値の期間比較可能性の確保からも説明できる。会計処理等を変更すると、前期と当期の財務諸表で適用している会計処理等が異なるため、期間比較可能性が損なわれる。

近年、会計処理等を変更した場合に遡及処理を行い、前期の財務諸表を新たな会計処理等で作成し直す会計基準が公表されたため、継続適用しなくても期間比較可能性を確保できるともいえる。ただし、会計基準等に経過的な取扱いが定められている場合など、遡及処理ができない場合がある。また、任意に変更できると、前期時点で開示された財務諸表と当期の比較情報として開示する前期財務諸表が異なる方法に基づくことになる。この意味で、継続性の原則は期間比較可能性の確保に一定の役割を果たす。

### 2. 継続性の原則の前提

出題ランク：短答 B、論文 C

企業会計上、継続性が問題とされるのは、一つの会計事実に対して二つ以上の、一般に公正妥当と認められる会計方針の選択適用が認められる場合である。複数の会計方針が認められているからこそ選択の問題が生じ、継続性を確保する必要がある。会計処理が一つしか定められていない場合、その会計処理を継続して適用するのは当然である。

継続性の原則の適用範囲となるのは、ある一般に公正妥当と認められる会計方針から、他の一般に公正妥当と認められる会計方針へ変更する場合である。この場合、会計方針の変更に正当な理由があるか検討する。

| 変更 | 取扱い | 例 |
|---|---|---|
| 認められない方法 → 認められない方法 | 企業会計原則違反 | 減価償却の方法を売上高比例法から売上原価比例法へ変更 |
| 認められた方法 → 認められない方法 | 企業会計原則違反 | 減価償却の方法を定額法から売上高比例法へ変更 |
| 認められない方法 → 認められた方法 | 当然の変更 | 減価償却の方法を売上高比例法から定額法へ変更 |
| 認められた方法 → 認められた方法 | 継続性の原則の適用範囲内。正当な理由があるか検討する | 減価償却の方法を定額法から定率法へ変更 |

認められた方法から認められない方法への変更、認められない方法から認められない方法への変更は、そもそも企業会計原則違反で許されない。認められない方法から認められた方法への変更は当然の変更であり、継続性の原則の問題とはならない。

### 3. 会計方針の変更が認められる場合

出題ランク：短答 B、論文 C

会計方針の変更が認められるのは、正当な理由がある場合に限られる。
## 第7節 保守主義の原則

「企業会計原則 第一 六」には、以下のように規定されている。

> 企業の財政に不利な影響を及ぼす可能性がある場合には、これに備えて適当に健全な会計処理をしなければならない。

### 1. 「保守主義の原則」の意味内容と必要性

#### (1) 保守主義の原則の意味内容

出題ランク：短答 B、論文 C

保守主義の原則とは、収益の計上を控えめにする一方、費用（損失）の計上は積極的に行うことで（利益を控えめに計上することで）、配当・課税による社外流出額を少なくし、企業財務の健全化を図ろうとする原則をいう。「安全性の原則」または「慎重性の原則」とも呼ばれる。

損益計算書の観点からは、収益の計上時期をより遅く、金額をより少なくし、費用の計上時期をより早く、金額をより多くすることを意味する。貸借対照表の観点からは、資産の額をより少なく、負債の額をより多く計上することを意味する。

#### (2) 保守主義の原則の必要性

出題ランク：短答 C、論文 C

保守主義の原則による制約がないと、より多くの利益が計上されて配当の原資が大きくなり、配当等による資金流出額も大きくなる。その結果、企業の財務基盤が脆弱になり、企業活動を健全に維持できないおそれがある。

保守主義の原則に基づき会計処理を行うと、利益を控えめに計上して資金流出額を抑えられるため、企業の財務基盤がより強固になり、企業自体の健全な経営、ひいては企業の存続を維持できる。

### 2. 保守主義の原則の適用例

出題ランク：短答 C、論文 C

- 減価償却方法における定率法
- 資本的支出か収益的支出かが不明確な場合における収益的支出処理
- その他有価証券の評価差額の処理方法における部分純資産直入法の適用

### 3. 保守主義の原則を適用する際の留意点

出題ランク：短答 C、論文 C

実際に保守主義の原則を適用するにあたっては、次の点に留意する。

#### ① 一つの会計事実に対して複数の会計処理が認められている場合、最も保守的なものを選択する

複数の会計処理が認められている場合、最も保守的な会計処理を選択する。減価償却であれば、定額法、定率法等の中から費用をより早期に多く計上できるものを選択する。

ただし、保守主義の原則の適用は副次的である。まず企業の経済的実態を最も適切に表現できる会計処理を選択し、その結果、複数の会計処理が候補に挙がった場合に保守主義の原則を適用する。

#### ② 会計上の見積りや判断において最も保守的に行う

継続企業を前提とした期間損益計算では経営者の見積りや判断が不可避的に介入するが、この局面では最も保守的に会計処理する。例えば、売掛金に貸倒引当金を設定する場合、貸倒実績率が1％〜2％と幅をもって予想されるなら、2％として貸倒引当金を設定することが保守主義の原則の適用となる。

### 4. 保守主義の原則と真実性の原則の関係

出題ランク：短答 B、論文 C

企業会計原則は、企業会計は予測される将来の危険に備えて慎重な判断に基づく会計処理を行わなければならないが、過度に保守的な会計処理を行うことにより、企業の財政状態及び経営成績の真実な報告をゆがめてはならないと規定している。

保守主義の原則と真実性の原則は本来相反する。保守主義の適用方法によっては費用が多く収益が少なく計上され、経営者による利益操作に利用されることがあり、真実性を害するおそれがあるためである。しかし、保守的な会計処理は一般に公正妥当と認められた会計処理の中で最も健全なものを選択させる。これを守る限り、保守主義は相対的真実性を害さず、真実性の原則を支える一原則となる。

過度に保守的な会計処理を行うと、財政状態及び経営成績の真実な報告が歪められ、真実性の原則に抵触するため、過度の保守主義は禁止される。例えば、費用を過度に多く、利益を過度に少なく計上して税金を意図的に小さくする利益操作は認められない。

保守主義の原則の適用は、一般に公正妥当と認められる会計基準の範囲内でのみ認められる。例えば、定額法、定率法、級数法、生産高比例法のいずれも経済的実態を適切に表現できる会計基準である場合、その中から最も保守的な方法を選択することが保守主義の原則の適用である。
## 第8節 単一性の原則

「企業会計原則 第一 七」には、以下のように規定されている。

> 株主総会提出のため、信用目的のため、租税目的のため等種々の目的のために異なる形式の財務諸表を作成する必要がある場合、それらの内容は、信頼しうる会計記録に基づいて作成されたものであって、政策の考慮のために事実の真実な表示をゆがめてはならない。

### 1. 単一性の原則

出題ランク：短答 B、論文 C

単一性の原則とは、二重帳簿を禁止し、財務諸表の形式的多元性を認めつつ、実質的一元性を要求する原則である。

財務諸表を提出先により異なる形式で作成する場合（例えば、会社法と金融商品取引法では貸借対照表・損益計算書の形式が異なる）であっても、その記載内容は信頼しうる一組の会計帳簿に基づいていなければならない。これを「実質一元・形式多元」という。

例えば、株主総会に提出する財務諸表や銀行融資などの信用目的で作成する財務諸表では、企業はできるだけ多くの利益を計上したいと望む。一方、税務申告目的の財務諸表では課税所得を圧縮して税金を節約するため、利益を少なく計上する動機を有する。このような矛盾する要請に応えるため二重帳簿を作成せざるを得ないとしても、二重帳簿の作成は認められない。

それぞれの財務諸表は、作成目的が異なっていても会計帳簿から誘導的に作成されるものであり、その実質的内容は同一でなければならない。

流れは、会計事実 → 一組の会計帳簿（実質一元、二重帳簿の禁止） → 誘導法 → 財務諸表（形式多元）である。形式多元の作成目的には、株主総会提出目的、信用目的、税務申告目的、その他の目的がある。
## 第9節 重要性の原則

「企業会計原則注解 注1」には、以下のように規定されている。

> 企業会計は、定められた会計処理の方法に従って正確な計算を行うべきものであるが、企業会計が目的とするところは、企業の財務内容を明らかにし、企業の状況に関する利害関係者の判断を誤らせないようにすることにあるから、重要性の乏しいものについては、本来の厳密な会計処理によらないで他の簡便な方法によることも正規の簿記の原則に従った処理として認められる。重要性の原則は、財務諸表の表示に関しても適用される。

### 1. 重要性の原則の意味内容と位置付け

出題ランク：短答 B、論文 C

会計を行うにあたり、本来ならば定められた会計処理の原則に従って正確な計算を行うべきであるが、企業会計の目的は企業の財務内容を明らかにし、企業の状況に関する利害関係者の判断を誤らせないようにすることにある。

そこで、重要性の原則とは、重要性の乏しいものについては本来の厳密な会計処理によらないで他の簡便的な方法によることも認められるという原則である。

なお、重要性の原則は、財務諸表の表示に関しても適用される。

重要性の原則は、形式上は一般原則には含まれないが、会計の全般に関わる包括的な原則としての性格を有し、実務上は頻繁に適用される原則である。

#### 参考　会計処理と表示

会計処理と表示は、以下のように異なる概念である。

| 区分 | 内容 |
|---|---|
| 会計処理 | ある会計事実に対して、どのように仕訳を行うか、どの方法を適用するか（定額法、定率法など） |
| 表示 | ある会計事実を、財務諸表上どのように見せるか（ある科目を独立の科目で表示するか、その他の科目と一括して表示するかなど） |

### 2. 重要性の原則における2つの側面

出題ランク：短答 C、論文 C

重要性の原則は、以下の2つの側面を有している。

1. 重要性の高いものについては、厳密な会計処理や表示を要求する（強制的に厳密）。
2. 重要性の乏しいものについては、簡便的な会計処理や表示を容認する（原則：厳密、例外：簡便）。

情報提供機能の観点から、投資者の意思決定について重要な影響を与える項目については、本来の厳密な会計処理や表示が要求される。

一方、厳密な会計処理や表示の実行に伴うコストと厳密な財務諸表から得られるベネフィットを比較して、コストがベネフィット（効用、利得）を大きく上回る場合には、厳密な会計処理や表示は無意味であるため、簡便な会計処理や表示が許容される。

この関係は、次のように整理できる。

- 厳密な処理や表示をするのに1億円のコストがかかった（コスト：大）。
- その財務諸表から得られる情報の有用性は低かった（効用：小）。
- この場合、厳密な処理や表示は無意味といえる。

#### 補足　重要性の原則の適用例

重要性の原則の適用例について、「企業会計原則」には以下の規定がある。

##### 重要性の乏しい場合の会計処理例

- 消耗品、消耗工具器具備品その他の貯蔵品等のうち、重要性の乏しいものについては、その購入時又は払出時に費用として処理する方法を採用することができる。
- 前払費用、未収収益、未払費用及び前受収益のうち、重要性の乏しいものについては、経過勘定項目として処理しないことができる。
- 引当金のうち、重要性の乏しいものについては、これを計上しないことができる。
- たな卸資産の取得原価に含められる引取費用、関税、買入事務費、移管費、保管費等の付随費用のうち、重要性の乏しいものについては、取得原価に算入しないことができる。

##### 重要性の乏しい場合の表示例

- 分割返済の定めのある長期の債権又は債務（営業外債権、営業外債務）のうち、期限が一年以内に到来するもので重要性の乏しいものについては、固定資産又は固定負債として表示することができる。

##### 重要性の高い場合の表示例

- 債権（債務も同様）のうち、役員等企業の内部の者に対するものと親会社又は子会社に対するものは、特別の科目を設けて区別して表示し、又は注記の方法によりその内容を明らかにしなければならない。
- 仮払金（仮受金も同様）、未決算等の勘定を貸借対照表に記載するには、その性質を示す適当な科目で表示しなければならない。

### 3. 重要性の判断基準

出題ランク：短答 B、論文 C

重要性の原則において、重要性が高い又は乏しいとは、財務諸表利用者の意思決定に影響を及ぼす程度によって判断する。

#### 重要性の判断に関する基本的な考え方

| 財務諸表利用者の意思決定への影響 | 判断 |
|---|---|
| 大きな影響のあるもの | 「重要性が高い」と判断する。 |
| 大きな影響のないもの | 「重要性が低い」と判断する。 |

また、より具体的な判断基準として、①量的重要性と②質的重要性の2つがある。

| 判断基準 | 内容 |
|---|---|
| 量的重要性（金額の重要性） | ある項目の金額の大きさからその重要性を判断する考え方。ある項目の金額が大きい場合は重要性が高いと判断し、厳密な会計処理や表示が要求される。ある項目の金額が小さい場合は重要性が低いと判断し、簡便的な会計処理や表示が容認される。 |
| 質的重要性（科目の重要性） | ある項目の内容や性質からその重要性を判断する考え方。ある項目の内容や性質が投資者の意思決定に重要な影響を与える場合は重要性が高いと判断し、厳密な会計処理や表示が要求される。ある項目の内容や性質が投資者の意思決定に軽微な影響しか与えない場合は重要性が低いと判断し、簡便的な会計処理や表示が容認される。 |

#### 量的重要性の具体例（表示面）

貸借対照表において、現金10,000、売掛金20,000に加え、前払費用20及び貯蔵品50がある場合、前払費用及び貯蔵品は金額的重要性が乏しいため、厳密に表示するのではなく、簡便的にまとめて「その他の流動資産」70として表示できる。

#### 質的重要性の具体例（表示面）

貸借対照表において、現金10,000、売掛金20,000、仮払金2,000がある場合、金額や用途が定まっていない支払は質的な重要性が高い。このため、仮払金については厳密な表示が求められる。

### 4. 重要性の原則と他の一般原則との関係

出題ランク：短答 B、論文 C

重要性の原則は、会計処理と表示の双方に適用される。ここで、重要性の原則は、会計処理の面では「正規の簿記の原則」と関係し、表示の面では「明瞭性の原則」と関係する。

#### ① 正規の簿記の原則と重要性の原則の関係

出題ランク：短答 B、論文 C

重要性の原則を適用した結果生ずる簿外資産・簿外負債（※）は、「正規の簿記の原則」に従った会計処理として容認される。つまり、重要性の原則に従い、重要性の乏しいものについて簡便的な会計処理を行った場合でも、当該会計処理は正規の簿記の原則の適用として認められる。

この点で正規の簿記の原則と重要性の原則は関係性を有している。

※ 簿外資産、簿外負債：会計帳簿に記載されていない資産、負債のこと。

例として、当期にペン10本を1本当たり100円で購入し、当期にそのうち7本を使った場合を考える。

厳密な会計処理は、次のとおりである。

| 時点 | 借方 | 貸方 |
|---|---|---|
| 購入時 | 消耗品 1,000 | 現金預金 1,000 |
| 決算時 | 消耗品費 700、（同）貯蔵品（B/S）300 | 消耗品 1,000 |

重要性の原則を適用した簡便な会計処理では、購入時に次の仕訳を行い、一括費用化する。

| 時点 | 借方 | 貸方 |
|---|---|---|
| 購入時 | 消耗品費 1,000 | 現金預金 1,000（一括費用化） |

これにより簿外資産が300生じる。

正規の簿記の原則は原則として厳密な処理を求めるが、重要性の原則はその中で例外として簡便な処理を認める関係にある。

#### ② 明瞭性の原則と重要性の原則の関係

出題ランク：短答 C、論文 C

明瞭性の原則は、財務諸表を明瞭に表示して、企業の状況に関する利害関係者の判断を誤らせないことを要請している。ここで、重要性の原則は重要性の高い項目については厳密に表示し、重要性の低い項目については簡便に表示することを許容しているため、明瞭表示を補完している。

この点で明瞭性の原則と重要性の原則は関係性を有している。

※ 仮に重要性の原則がないと、すべての項目を厳密に表示することになるが、このような財務諸表は逆に見づらく、わかりづらくなる。
