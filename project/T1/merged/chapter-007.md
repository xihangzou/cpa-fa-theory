### 1. 流動資産の区分に計上される項目

出題ランク：短答C、論文C

「財務諸表等規則」においては、次に掲げる資産は、流動資産に属するものとしている。

| 項目 | 内容・注記 |
|---|---|
| 1. 現金及び預金 | ただし、1年内に期限の到来しない預金を除く。 |
| 2. 受取手形 | 通常の取引に基づいて発生した手形債権をいう（※）。 |
| 3. 売掛金 | 通常の取引に基づいて発生した営業上の未収金をいう（※）。 |
| 4. 売買目的有価証券及び1年内に満期の到来する有価証券 |  |
| 5. 商品 | 販売の目的をもって所有する土地、建物その他の不動産を含む。 |
| 6. 製品、副産物及び作業くず |  |
| 7. 半製品 | 自製部分品を含む。 |
| 8. 原料及び材料 | 購入部分品を含む。 |
| 9. 仕掛品及び半成工事 |  |
| 10. 消耗品、消耗工具、器具及び備品 | その他の貯蔵品で相当価額以上のものを含む。 |
| 11. 前渡金 | 商品及び原材料の購入のための前渡金をいう。 |
| 12. その他の資産で1年内に現金化できると認められるもの |  |

※ 破産更生債権等で1年内に回収されないことが明らかなものを除く。このような項目は、固定資産の投資その他の資産の区分に計上する。

### 2. 流動資産の表示に関する諸論点

以下、棚卸資産以外の流動資産の各項目の表示についてみていく。

#### (1) 現金

出題ランク：短答B、論文C

現金として計上できる項目は「手許現金」のみならず、「小口現金」「手元にある当座小切手」「送金小切手」「送金為替手形」「預金手形」「郵便為替証書及び振替貯金払出証書」を含む。

なお、「期限の到来した公社債の利札」その他金銭と同一の性質をもつものは、現金に含めて表示することができる。ただし、「未渡小切手」は預金として処理する。

#### (2) 預金

出題ランク：短答C、論文C

預金は、「金融機関に対する預金」「貯金及び掛金」「郵便貯金」「郵便振替貯金」に限る。なお、預金には、契約期間が1年を超える預金（定期預金など）で1年内に期限の到来するものを含む。

#### (3) 受取手形、売掛金等の債権

出題ランク：短答C、論文C

取引先との通常の商取引によって生じた受取手形、売掛金等の債権及び期限が1年以内に到来する債権は、流動資産に属する。

また、受取手形、売掛金その他流動資産に属する債権は、取引先との通常の商取引上の債権（営業債権）とその他の債権（営業外債権）とに区別して表示しなければならない。

#### (4) その他の項目

出題ランク：短答B、論文C

上記以外の流動資産に関して、特に「財務諸表等規則」に記載ある規定を以下、挙げておく。

- その他の流動資産に属する資産のうち、未収収益、短期貸付金、株主、役員若しくは従業員に対する短期債権又はその他の資産で、その金額が資産の総額の100分の5を超えるものについては、当該資産を示す名称を付した科目をもって掲記しなければならない。
- 関係会社との取引に基づいて発生した受取手形及び売掛金の合計額が資産の総額の100分の5を超える場合には、当該受取手形及び売掛金の金額をそれぞれ注記しなければならない。ただし、関係会社に対する受取手形又は売掛金のいずれかの金額が資産の総額の100分の5以下である場合には、これらの合計額のみを注記することができる。
- 親会社株式のうち1年内に処分されると認められるものは、流動資産に親会社株式の科目をもって別に掲記しなければならない。ただし、その金額が僅少である場合には、注記によることができる。この場合、貸借対照表上、有価証券勘定に含めて計上し、親会社株式の金額は注記により開示することになる。

なお、親会社株式のうち上記以外のもの（1年超のもの）は、投資その他の資産に親会社株式の科目をもって別に掲記しなければならない。ただし、その金額が僅少である場合には、注記によることができる。
## 第2節 棚卸資産

### 1. 棚卸資産の定義

出題ランク：短答B、論文C

棚卸資産とは、生産及び販売・管理活動のために消費される資産をいう。「連続意見書」において、棚卸資産の範囲は以下のように規定されている。

貸借対照表に棚卸資産として記載される資産の実体は、次のいずれかに該当する財貨又は用役である。

| 区分 | 内容 |
|---|---|
| (イ) | 通常の営業過程において販売するために保有する財貨又は用役 |
| (ロ) | 販売を目的として現に製造中の財貨又は用役 |
| (ハ) | 販売目的の財貨又は用役を生産するために短期間に消費されるべき財貨 |
| (ニ) | 販売活動及び一般管理活動において短期間に消費されるべき財貨 |

(イ)から(ハ)までは販売目的の資産に該当する。

- (イ)は販売資産であり、商品や製品が例として挙げられる。
- (ロ)は製造中とあることから、仕掛品や半製品が例として挙げられる。
- (ハ)は生産するために消費されるものであるため、原材料や工場用消耗品が例として挙げられる。
- (ニ)は販売活動や一般管理活動において消費されるものであるため、事務用消耗品や荷造用品が例として挙げられる。

図では、(ハ)原材料、(ロ)仕掛品、(イ)商品・製品が、それぞれ購買過程、製造過程、販売過程に対応している。また、(ニ)のうち販売費（荷造用品）は販売過程に、一般管理費（事務用消耗品費）は購買過程から販売過程にわたる一般管理活動に対応して示されている。

棚卸資産は、販売目的の資産（原材料、仕掛品、製品等）のみならず、使用する目的の資産に該当するものもその範囲に含めている。

なお、棚卸資産に関するより具体的な内容は、「棚卸資産の評価に関する会計基準」の章にて取扱う。
