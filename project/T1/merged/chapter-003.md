### 1. 資本循環

短答：C　論文：D

企業は、まず株主からの出資や借入等によって、業務遂行に必要な資本（貨幣）を獲得する（資本の調達）。次に調達した資本を各種の生産手段や労働力の購入に充てる（資本の投下）。これによって生産された生産物を外部に販売して貨幣を回収する（資本の回収）。つまり、企業の経済活動は、①資本の調達→②資本の投下→③資本の回収という一連の資本循環過程に他ならない。

資本循環の流れは、資本と負債から貨幣を調達し、貨幣を商品や土地に投下し、商品を販売して売掛金を経て貨幣を回収する流れとして示される。

ここで、継続企業の前提の下、資本循環過程を一定期間に区切って会計報告する必要があるが、財務会計は「財政状態と経営成績を明らかにする」ことを主要な目的としているため、財務諸表もこの観点から作成される必要がある。以下、貸借対照表・損益計算書を用いて、資本循環過程を具体的に見ていく。

#### ① 資本の調達

X1年期首に株主から300万円の出資を受け、さらに銀行から200万円借り入れて、合計500万円の資金を調達したとすると、この時点での貸借対照表は以下のようになる。

| X1年期首貸借対照表 | 金額（万円） |
|---|---:|
| 現金（資産） | 500 |
| 借入金（負債） | 200 |
| 資本金（資本） | 300 |

#### ② 資本の投下

この企業は商業（商品を仕入れて売ること）を営むとすると、まず商品を仕入れる。ここで、X1年期中に、400万円で商品を仕入れ、100万円で土地を購入した場合、貸借対照表は以下のようになる。

| X1年期中貸借対照表 | 金額（万円） |
|---|---:|
| 商品（資産） | 400 |
| 土地（資産） | 100 |
| 借入金（負債） | 200 |
| 資本金（資本） | 300 |

#### ③ 資本の回収

X1年期末に、400万円の商品うち、250万円分を売価300万円で掛売したとすると、これを経営成績の観点からすると、収益は300万円、費用は250万円となるため、損益計算書は以下のようになる。

| X1年度損益計算書 | 金額（万円） |
|---|---:|
| 売上原価（費用） | 250 |
| 利益 | 50 |
| 売上（収益） | 300 |

また、X1年度末時点の貸借対照表は以下のようになる。

| X1年度末貸借対照表 | 金額（万円） |
|---|---:|
| 売掛金（資産） | 300 |
| 商品（資産） | 150 |
| 土地（資産） | 100 |
| 借入金（負債） | 200 |
| 資本金（資本） | 300 |
| 利益（資本） | 50 |

上記から現行制度上、資本循環を主に損益計算書と貸借対照表という形で描写している。

図では、資本の調達から資本の投下を経て、投下された資本の一部が費用となり、収益と対応して利益を生み、回収済みの投下資本と未回収の投下資本が期末貸借対照表に残る関係が示されている。期末貸借対照表には、売掛金300、商品150、土地100、負債200、資本金300、利益50が対応する。
## 2. 期間利益の算定方法

短答：B　論文：C

期間利益の算定方法は、「財産法」と「損益法」がある。

### (1) 財産法（貸借対照表を用いた利益計算の方法）

|  | 内容 |
|---|---|
| 定義 | 実地調査に基づき決定された期末純資産額と期首純資産額との差額から期間損益を計算する方法 |
| 長所 | 実地調査に基づき利益計算を行うため、実在するものを基礎として期間損益が算定できる。 |
| 短所 | 期首と期末の純資産の差額により利益計算を行うため、利益の発生原因が明らかにされない。 |

財産法では、期首貸借対照表の純資産額300（商品400、土地100、負債200）と、商品250を300で掛売した後の期末貸借対照表の純資産額350（売掛金300、商品150、土地100、負債200）との差額から、期間利益50を計算する。

期末純資産額350－期首純資産額300＝期間利益50

#### 補足　実地調査（実地棚卸）とは

短答：C　論文：D

実地調査とは、実際に資産や負債が存在するかを調査し、それをリストアップすることをいう。また、このような実地調査を通じてリストアップされた資産、負債に対し、個別的に価額を付して記載した明細表のことを「財産目録」という。

実地調査に基づく貸借対照表（財産目録）では、受取手形、棚卸資産、土地など、実際に存在し、識別可能な資産を計上する。また、買掛金など、実際に債務が存在するか調べ、識別可能なもの（法律上の債務）のみを計上する。この財産目録、実地調査に基づく貸借対照表、棚卸法により作成した貸借対照表は、同じ意味と考えてよい。

したがって、帳簿記録なしでも貸借対照表を作成できる。

### (2) 損益法（損益計算書を用いた利益計算の方法）

|  | 内容 |
|---|---|
| 定義 | 帳簿記録に基づき一定会計期間の収益から費用を差し引いて期間損益を計算する方法 |
| 長所 | 帳簿記録を前提とするため、利益の発生原因を明らかにできる。 |
| 短所 | 実地調査を前提としないため、実在するものを基礎とした期間損益は算定できない。 |

損益法では、帳簿記録に基づく期間収益300から期間費用250を差し引き、期間利益50を計算する。

期間収益300－期間費用250＝期間利益50

### (3) 現行制度における取扱い

現行制度上、帳簿記録を基礎に期間損益を計算するため、基本的に「損益法」を基礎としている。しかし、損益法では、帳簿の有高と実地有高に差異が生ずる可能性があるので、期末に実地調査をして記録の不備を補う必要がある。

つまり、現行制度においては損益法を基礎としながらも、実地調査を一部採用し、補完している。

より具体的に財産法と損益法の違いを説明すると、次のようになる。

#### 具体例

1. 商品1個を30で3つ、現金で購入する。

   （借）商品 90　（貸）現金 90

2. そのうち2つを1個50で販売する。

   （借）現金 100　（貸）商品 60

   　　　　　　　　　（貸）売上利益 40

3. 期末に実地調査により商品1つが滅失していた。

財産法では、実在するものを基礎とした損益は計算できるが、利益の内訳は明らかにできない。損益法では、実地調査は行わず、帳簿記録に基づく利益の内訳は明らかにできるが、実在するものを基礎とした損益は計算できない。

| 方法 | 期間利益 | 実在するものを基礎とした損益 | 利益の内訳 |
|---|---:|---|---|
| 財産法 | 10 | ○ | × |
| 損益法 | 40 | × | ○ |

財産法では、期首貸借対照表の現金100、負債50、資本50と、期末に実在する現金110、負債50との差額から期間利益10を計算する。損益法では、損益計算書に販売益40を計上し、実地調査を行わない。

現行制度では、損益法を基礎としつつ実地調査を行う。商品1つの滅失について、次の仕訳を行い、損益計算書と貸借対照表を補完する。

（借）減耗費 30　（貸）商品 30

この場合、損益計算書は減耗費30、販売益40、利益10となり、貸借対照表は現金110、負債50、資本60となる。現行制度（損益法＋実地調査）では、実在するものを基礎とした損益と利益の内訳のいずれも明らかにできる。
## 3. 貸借対照表の作成方法

短答：B　論文：C

貸借対照表の作成方法は、「棚卸法」と「誘導法」がある。

### (1) 棚卸法（財産目録法）

|  | 内容 |
|---|---|
| 定義 | 資産及び負債について実地調査を行って、財産目録を作成し、この資料に基づいて貸借対照表を作成する方法 |
| 特徴 | 資産・負債は、物理的に識別可能な項目及び法律上の債権・債務に限られる（繰延資産や債務性のない引当金の計上は否定される）。 |
|  | 貸借対照表は、必ずしも損益計算書の作成を前提とせずに、独立に作成できる。 |
|  | 棚卸法によって作成された二時点の貸借対照表の比較により期間損益を計算する方法が財産法であるため、棚卸法と財産法は関連性を有する。 |

棚卸法では、期首と期末に実地調査を行って貸借対照表を作成し、二時点の純資産の差額から財産法による期間利益50を計算する。

### (2) 誘導法

|  | 内容 |
|---|---|
| 定義 | 帳簿記録を基礎にして、その帳簿記録から当期の損益計算に算入されなかった項目により、貸借対照表を作成する方法 |
| 特徴 | 繰延資産や債務性のない引当金についても計上される。 |
|  | 貸借対照表の作成の過程で損益計算書の作成も可能となる。 |
|  | 帳簿記録から収益・費用を抜き出して損益計算を実施するのが損益法であり、期間損益計算に無関係の項目を収容して貸借対照表を作成するのが誘導法であるため、誘導法と損益法は関連性を有する。 |

誘導法では、期首貸借対照表を出発点として帳簿記録から、①期間損益に関連するものを抜き出して損益計算書を作成し、②期間損益に組み込まなかった項目を収集して期末貸借対照表を作成する。損益計算書は損益法により、貸借対照表は誘導法により作成される。
## 4. 静態論会計と動態論会計

短答：B　論文：C

貸借対照表の本質をどのように捉えるかという貸借対照表観は、「静態論」と「動態論」の2つがある。

### (1) 静態論の考え方

17〜20世紀初頭の企業会計の主たる目的は債権者の保護にあった。これは、当時の企業は経済的基盤が脆弱で、企業の倒産により債権者が損失を被ることが多かったためである。この状況下において、企業会計に求められていたのは、企業の債務弁済能力（どれだけ債務を返済する力があるか）を表示することであり、貸借対照表はある時点においてどれだけの財産・債務を有しているかという財産計算を行うために作成されると捉えていた。

このように貸借対照表を捉える考え方を「静態論」という。

### (2) 静態論における貸借対照表

静態論における貸借対照表（静的貸借対照表）は、以下の特徴を有している。

| 項目 | 内容 |
|---|---|
| 計上される項目 | 決算日において実地調査を行い、処分可能な資産と企業の負担する債務をすべて計上する。資産は換金能力のあるものに限定し、評価額は売却時価による。負債は法的に支払わなければならない法的確定債務に限定し、評価額は法的弁済額による。 |
| 計上されない項目 | 繰延資産や引当金は貸借対照表に計上できない。 |
| 貸借対照表・損益計算書 | 実地調査に基づき、その時点の財産と債務を認識し、貸借対照表を作成するため、貸借対照表は棚卸法により作成され、期間利益の計算は財産法により行われる。 |
| 重視する点 | 貸借対照表により債務弁済能力を表示すること（財産計算をすること）。 |

通常の貸借対照表では、現金100、建物800（取得原価）、繰延資産100を資産に計上し、借入金600、修繕引当金100、資本金300を負債・資本に計上する。静態論の貸借対照表では、建物を700（売却時価）として計上し、現金100、借入金600、資本金200を示す。

修繕するか否かは企業が決定できる。お金がなければ修繕しなくてもよく、この場合にお金を払う必要はない。修繕引当金は法的確定債務ではないので計上されない。また、繰延資産は財産価値がない（売れない）ので計上されない。企業が今倒産しても200の余剰があることがわかり、債権者は安心する。この200は「解体価値」とも呼ばれ、企業が今倒産したら200の価値があるといえる。

### (3) 動態論の考え方

20世紀に入り、企業の経済的基盤は安定してきたため、企業の倒産ではなく、企業の継続性を前提とするようになった。また、企業の将来性を期待して、企業に投資する資金提供者が増加した。この資金提供者は、企業が将来どれだけ利益を獲得できるかという情報を求めていた。

この状況下において企業会計に求められていたのは、投資者に対して企業の収益力を表示することで投資者を保護することにあるため、期間損益計算が重視されるようになった。

つまり、会計目的が従来の貸借対照表による財産計算から損益計算書による期間損益の表示に移ると、貸借対照表は適正な期間損益を算定するために作成される（損益計算書が「主」、貸借対照表は「従」）。

このように貸借対照表を捉える考え方を「動態論」という。

### (4) 動態論における貸借対照表

動態論における貸借対照表（動的貸借対照表）は、以下の特徴を有している。

| 項目 | 内容 |
|---|---|
| 計上される項目 | 期間損益計算を適正に行うという見地から、貸借対照表に計上するべき資産、負債が決定される。換金能力を有しない繰延資産や債務性のない引当金であっても、期間損益計算を適正に行う上で必要な項目は貸借対照表に計上する。 |
| 貸借対照表・損益計算書 | 帳簿記録に基づき、損益計算書に含まれなかった項目を収集して貸借対照表を作成するため、貸借対照表は誘導法により作成され、期間損益の計算は損益法により行われる。 |
| 重視する点 | 損益計算書により適正な期間損益計算を行うこと。 |
| 貸借対照表の役割 | 収入・支出計算と収益・費用計算との間の期間的なズレから生じる収支の未解決項目を収容し、次期へ繰り越す役割。 |
|  | 当期と次期の損益計算を結び付ける「連結環」としての役割。 |

図の例では、設立時に現金200を資本金として受け入れ、株式交付費15を支出する。期中には商品を90で購入し、商品2つを売価100で販売する。決算時には株式交付費償却5を計上する。損益計算書には株式交付費償却5と販売益40を集計し、利益35を表示する。期末貸借対照表には、現金95、売掛金100（収益・未収入）、商品30（支出・未費用）、株式交付費10（支出・未費用）、資本金200、利益35を計上する。

商品について、支出30であるが費用は0であるように、収入・支出と収益・費用の対応が未完了の項目がある。これらを貸借対照表に収容し、次期以降の収益に対応させるため、繰延資産であっても貸借対照表に計上される。当期の損益に関係するもののみを損益計算書に集計する。

#### 「収支の未解決項目」のイメージ

損益計算では収益の計上時点と費用の計上時点、収支計算では収入時点と支出時点があり、通常、それぞれの時点はずれる。

| 収益・収入の関係 | 項目 |
|---|---|
| 収益：○、収入：× | 売掛金 |
| 収益：×、収入：○ | 前受金 |

このように、収益と収入、または費用と支出のどちらかが完了していない状態を「収支の未解決」と呼ぶ。このような項目を集める場所こそが貸借対照表であると考える。

#### 「連結環」のイメージ

収支の未解決項目の中には、次期の損益計算に関連する項目も存在する。株式交付費15のうち、当期の費用5を当期の損益計算書に計上し、残りの株式交付費10を当期の貸借対照表に繰り越す。次期にはこの10のうち5を費用として次期の損益計算書に計上する。このように、貸借対照表は当期と次期の損益計算を結びつけるものである。

#### 動的貸借対照表の構成要素

動的貸借対照表は収支の未解決項目を収集するものであり、構成要素は次のようになる。

| 資産の部 | 資本・負債の部 |
|---|---|
| 現金 | 資本金 |
| 支出・未収入項目（貸付金等） | 収入・未支出項目（借入金等） |
| 支出・未費用項目（商品・建物等） | 費用・未支出項目（未払費用・引当金等） |
| 収益・未収入項目（未収収益等） | 収入・未収益項目（前受収益等） |

### 静態論会計と動態論会計の相違点

|  | 静態論会計 | 動態論会計 |
|---|---|---|
| 時代背景 | 17〜20世紀初頭にかけて、企業規模は小さく倒産が相次いだ。 | 20世紀初頭から現在にかけて、企業が大規模化し倒産が減る一方で、投資者が出現した。 |
| 会計の目的 | 債権者保護（貸借対照表をより重視）→企業の債務弁済能力を開示する、財産計算を行う。 | 投資者保護（損益計算書をより重視）→適正な期間損益計算を行うことで、企業の収益力を開示する。 |
| 貸借対照表の本質 | 企業の債務弁済能力を表示するもの。 | 収支の未解決項目を収容するもの。 |
| 期間利益の算定方法 | 財産法（実地調査を前提） | 損益法（帳簿記録を前提） |
| 貸借対照表の作成方法 | 棚卸法（実地調査を前提） | 誘導法（帳簿記録を前提） |
| 資産性と負債性 | 資産：換金可能なもの。負債：法的確定債務。 | 適正な期間損益計算のために必要な項目は資産、負債として計上される。 |
| 資産の評価基準 | 売却時価 | 貨幣性資産：回収可能価額。費用性資産：取得原価。 |
