### 1. 企業会計の意義

出題ランク：短答 C、論文 D

企業会計とは、企業の経営活動によって生じる会計事象を認識、測定、記録、報告する手続をいう。

会計の対象とする経済主体は、「営利組織」と「非営利組織」に分けられる。前者は一般に企業と呼ばれるが、この企業を対象とする会計を企業会計（営利会計）という。一方、後者の非営利組織には、個人、国、地方自治体の行政機関及び学校法人・宗教法人などが含まれる。これらの組織で行われる会計が非営利会計である。

### 2. 会計行為とその構成要素

出題ランク：短答 C、論文 D

会計行為とは、認識、測定、記録、報告の各行為のこと（会計の各構成要素のこと）を指す。つまり、会計行為のすべてを一連のものとして捉えると企業会計の概念となる。

ここで、会計行為における各行為の意義は、以下の通りである。

| 行為 | 意義 |
|---|---|
| 認識 | 企業の経済活動・事象のうち、どれが会計的に測定の対象となるかを識別すること。ex) 従業員が空気を吸う→会計の対象外　企業が備品を買う→会計の対象 |
| 測定 | 認識された企業の経済活動・事象について、財務諸表への計上価額を決定すること（金額を決定すること）。ex) 取得原価を用いるか、時価を用いるか |
| 記録 | 認識・測定された企業の経済活動・事象を帳簿等に記載すること |
| 報告 | 認識、測定、記録された企業の経済活動・事象を、一会計期間における経営成績ないし財政状態等の会計情報として利害関係者に伝達すること |

※「報告」まで含めて、会計という点に留意してほしい。

企業会計の流れは、次のように表せる。

企業活動・事象 → 認識（会計行為） → 測定（会計行為） → 記録（会計行為） → 報告（会計行為） → 利害関係者

認識、測定、記録、報告の4つの会計行為を一連のものとして捉えたものが企業会計である。

### 経営成績と財政状態

出題ランク：短答 C、論文 C

「経営成績」とは、どれだけの収益が得られ、その収益を獲得するためにどれだけの費用が費やされ、結果としてどれだけの利益が得られたかをいう。経営成績を明らかにするとは、収益・費用の構成項目と金額及びその差額である利益を明示することであり、これを表示するものが「損益計算書」である。

「財政状態」とは、企業が営業活動を行うために利用される資金の調達源泉（負債・資本）とそれが運用されている状況（資産）をいう。財政状態を明らかにするとは、資産、負債及び資本の構成項目と金額を明示することであり、これを表示するものが「貸借対照表」である。

### 3. 企業会計の領域

出題ランク：短答 C、論文 D

企業会計は、会計情報を提供する相手方によって、「財務会計」と「管理会計」に分類される。

|  | 財務会計 | 管理会計 |
|---|---|---|
| 目的 | 外部の利害関係者に対する情報提供を目的とした会計であり、「外部報告会計」とも呼ばれる | 経営者や企業内部の管理者に対する会計情報の提供を目的とした会計であり、「内部報告会計」とも呼ばれる |
| 効果 | 財務会計により、外部の利害関係者に対して情報を提供することで外部の利害関係者の利害対立を調整するとともに、外部の利害関係者の意思決定に役立てることができる | 管理会計により、経営者等に対して必要な会計情報を提供することで、経営管理上の意思決定に役立てることができる |

※ 財務会計論で学習する内容は、企業会計のうち、「財務会計」の領域がその大半を占める（財務会計論で学習するB/S、P/L→企業外部の投資家等への情報提供を目的に作成するものである）。

図の例：

- ex) 各製品１個当たりの製品原価の情報を提供
- 外部者：こんな詳細な情報は不要
- 内部者：各製品の売価と原価を分析し、利益率の大きいものを積極的に販売していく等の意思決定を行う。

企業内部では、管理会計による内部報告が経営者等に伝えられる。企業外部には、財務会計による外部報告が投資者（外部の利害関係者）に伝えられる。

### 4. 主な利害関係者と利害内容

出題ランク：短答 B、論文 C

利害関係者とは、企業の経営状況について何らかの法的、経済的利害関係を有している人々（企業と何らかの関係のある人々）のことをいう。

ここで、財務会計において、報告の対象である利害関係者の代表例としては「株主」と「債権者」が挙げられる。株主と債権者の立場（地位）の違いは、以下の通りである。

#### 株主の立場の特徴

株主は、会社の純資産に対して資金を提供する。仕訳は次のように表せる。

（借）現金 ××　（貸）資本金 ××

1. 企業が利益を上げれば利益の何％の配当をもらえる（不確実）。
2. 企業が利益を上げれば株価が上がり、それを売却してもうける（不確実）。
3. 企業の経営に口出しできる（配当の額も決められる）。

#### 債権者の立場の特徴

債権者は、会社の負債に対して資金を提供する。また、債権者は純資産に注目する。仕訳は次のように表せる。

（借）現金 ××　（貸）借入金（社債）××

1. 企業の業績に関わらず利息がもらえる（倒産しない限り確実）。
2. 企業の業績に関わらず元本は回収できる（倒産しない限り確実）。
3. 企業の経営に口出しはできない。
4. 担保となるのは会社財産（純資産）である。

企業が倒産した場合、資産150、負債200、純資産△50であれば、資産をすべて売却したとしても負債を返済することができない。このため、債権者の一部は資金を回収することができなくなる。これに対し、資産200、負債150、純資産50という理想的な貸借対照表であれば、債権者にとってある程度純資産がプラスであることが重要である。

以上の立場（地位）の違いから、その利害内容は以下のように異なる。

| 利害関係者 | 企業との利害関係 |
|---|---|
| 株主 | 剰余金の配当、株式の売買及び残余財産の分配において企業と利害関係を有している |
| 債権者 | 利息の徴収、債権の売買及び元本の回収において企業と利害関係を有している |

現在の株主、債権者のみならず、将来の株主、債権者（潜在的な株主、債権者）を一括して、「投資者（投資家）」と呼ぶ。投資者は、現在の株主、現在の債権者、将来の株主及び将来の債権者を含む非常に広い概念である。

### 5. 財務会計の機能（財務諸表を作成するメリット）

財務会計が果たす機能には、利害調整機能と情報提供機能がある。

#### (1) 利害調整機能

出題ランク：短答 B、論文 C

利害調整機能とは、会計情報が企業を巡る利害関係者間の利害対立を調整する機能をいう。この機能には、「①株主と経営者との間の利害調整」、「②株主と債権者との間の利害調整」という2つの機能がある。

#### 所有と経営の分離

財務会計の対象となるのは主に株式会社であるが、株式会社の特徴の一つに「所有と経営の分離」がある。

株式会社における所有者は、株式を保有する「株主」である。少数の株式しか所有しない株主は、通常、企業の経営には無関心で、配当や株価の上昇の方に強い関心を抱く傾向がある。ここで、企業規模が拡大すると、企業組織の管理が複雑化・困難化してくるが、企業経営の意思も能力もない多数の株主が、高度に専門化した企業経営を直接遂行することは、実際上不可能といえる。よって、企業の合理的な経営を確保するために、所有者が専門的能力を有する第三者に経営を委託する「所有と経営の分離」が、制度的に認められている。

株式会社を作るには、次の2つの要素が必要である。

1. 多くの資金
2. 経営できる能力ある人

所有と経営の分離により、お金を出す人と会社を経営する人は別々の人でよいとされる。この制度により会社を作りやすくなる。この制度がないと、お金を多く保有していて、かつ経営ができる人がいないと会社が作れなくなってしまう。

#### ① 株主と経営者との間の利害調整機能

出題ランク：短答 C、論文 C

株式会社は「所有と経営の分離」を前提としており、株主と経営者は資金の委託者と受託者の関係にある。

| 立場 | 役割 |
|---|---|
| 株主 | 自己の所有する資金の管理と運用を委託する者（委託者） |
| 経営者 | 資金の管理・運用の権限委譲を受けて、株主の利益のために行動する者（受託者） |

経営者は受託者である以上、株主から委託された資金を誠実に管理、運用、保全するだけでなく、株主の最大利益に合致するように経営活動を行う責任を負う。この責任は「受託責任」と呼ばれる。

しかし、経営者がこの受託責任を常に誠実に遂行するとは限らないことから、株主と経営者との間で利害が対立する可能性がある。つまり、株主は企業利益が増大し、配当が増加することを望むが、経営者は自己の利益を追求しがち（企業の資産を私物化したり、多くの交際費を自分のために支出する等）であり、経営者のこのような行動は株主の利益を損なう。このような株主と経営者との間の利害調整を図る手段として「財務会計」が必要となる。

具体的には、経営者は委託された資金をどのように運用して、どれだけの利益を獲得したかを財務諸表という形で株主に報告することで、株主は自らの資金の運用が適切に行われているかを判断でき、また正当に経営を行っている経営者にとっても財務諸表を通じて、自ら行った経営の正当性を株主に伝達できるのである。

図で示される利害対立は、経営者が自分のためにお金を使えることが経営者にとって「得」となり、その分、株主にとって配当の原資が減ることが「損」となる関係である。株主は経営者が自分にとって不利益なことをしていないかチェックしたい。一方、適切に任務を果たしている経営者は自らの正当性を示したい。そのための基礎資料が「財務諸表」である。

経営者が株主に対して会計報告を行うことで、最終的に受託責任を果たすことができる。経営者が株主に対して会計報告を行うべき責任を「会計責任（もしくは説明責任）」と呼ぶ。

関係の流れは次のように表せる。

株主（資金の委託者）――出資→ 経営者（資金の受託者）

経営者の責任：

1. 委託された資金を適切に管理、運用、保全する
2. 株主の利益最大化を目指す

経営者が財務諸表を作成し、会計報告を行うことで、受託責任が果たされる。

#### ② 株主と債権者との間の利害調整機能

出題ランク：短答 C、論文 C

株主は経営参加権を有しているのみならず、企業の業績が良好であれば、多くの配当金や株価上昇といった利益を得ることができる。また、自らの責任は出資額を限度とする間接有限責任である。

一方、債権者は経営に参加する権利はなく、企業が倒産すれば元利金が回収できない危険も負担する。

ここで、株主と債権者は、「剰余金の配当」を巡って利害対立が生じる可能性がある。つまり、債権者にとって担保となるのは会社財産のみであり、剰余金の配当による会社財産の流出は、株主にとっては利益となるが、債権者にとっては会社財産の減少を招くため、利払い不能や債務不履行リスクが高まる。

このような株主と債権者との間の利害調整を図る手段として「財務会計」が必要となる。具体的には、両者の利害を調整する手段として、「分配可能額」が法定されているが、この分配可能額の計算基礎として財務諸表の作成は不可欠なのである。

分配可能額により、企業はある一定の限度までしか配当できなくなる以上、過度に配当されることを防ぎ、これにより企業内に一定の会社財産が確保されるため、結果として債権者を保護できるのである。

過度に配当した場合の仕訳は、（借）繰越利益剰余金 ××　（貸）現金 ××である。現行制度上、分配可能額までしか配当できないことになっている。分配可能額の算定のための基礎資料が「財務諸表」である。

数値関係の例では、純資産100のうち、分配不能が80、分配可能（分配可能額）が20である。分配可能額は財務諸表を使って算定する。分配可能額が定められていることで、株主にはある程度分配され、債権者にとってはある程度純資産が残る。

財務諸表を作成 → 分配可能額が算定できる → 株主と債権者の利害調整が図れる

#### (2) 情報提供機能

出題ランク：短答 B、論文 C

情報提供機能とは、会計情報を作成し開示することで、投資者の意思決定に有用な情報を提供する機能をいう。

投資者の立場からは、投資対象の企業に関する情報がない状況下では、投資者は当該企業に対して投資を実行するか否かの正確な判断ができない。この点から「財務会計」が必要となる。企業が公表する財務諸表により、投資者は当該企業の財政状態や経営成績を知ることができ、投資するか否かの意思決定に有用な情報を入手できるのである。
## 第2節 制度会計

### 1. 会計の分類

出題ランク：短答 C、論文 D

会計の分類は、次のように整理できる。

会計の階層関係：

- 会計
  - ミクロ会計
    - 営利会計
      - 企業会計
        - 財務会計
          - 制度会計
            - 会社法会計
            - 金融商品取引法会計
            - 税務会計
          - 非制度会計
        - 管理会計
    - 非営利会計
  - マクロ会計

図で網掛けされた「金融商品取引法会計」は、財務会計論において主に学習する範囲である。

ここで、「財務会計」は、「会社法会計」「金融商品取引法会計」「税務会計」に分類され、これらを総称して「制度会計」と呼ぶ。以下、制度会計についてみていく。

### 2. 制度会計とは

出題ランク：短答 C、論文 D

制度会計とは、法制度（法規制）の枠組みで行われる会計をいう。

本来、会計にはその処理や表示等に関して、自由に選択できるという側面がある。しかし、今日の企業は多数の利害関係者を有し、その社会性・公共性は著しく増大した。このような状況下において、企業会計に合理的な制約を加えないと、会計処理等を行うにあたり、経営者等の恣意性が介入し、利益操作を行う恐れがある以上、利害関係者を保護できなくなる。

よって、法規制に準拠して会計を行うことで、作成される財務諸表等に信頼性を付与し、利害関係者を保護する必要がある（※）。

制度会計は根拠となる法律の違いにより、「会社法会計」「金融商品取引法会計」「税務会計」に分類できる。

※ 何も規制がないと、経営者は恣意的に財務諸表の数値を作ることができてしまうが、この結果、利害関係者が不利益を被る可能性がある。

### 3. 会社法会計

出題ランク：短答 B、論文 C

会社法会計とは、会社法の規制の下で行われる会計をいう。会社法は、企業をめぐる利害関係者の利害の調整を主たる目的として制定されている。よって、財務会計の機能のうち「利害調整機能」、すなわち経営者、株主、債権者の間に存在する利害対立関係の調整は、主として会社法会計を通じて遂行される。

会社法（もしくは会社計算規則）において会社の計算を詳細に規定し、株式会社に対して計算書類（貸借対照表、損益計算書、株主資本等変動計算書、個別注記表）の作成と報告を義務付けている。この計算書類の作成と報告により、株主、債権者は以下の点で保護される。

| 対象 | 保護の内容 |
|---|---|
| 株主 | 株主は株主総会に先立ち、企業の経営成績や財政状態等の報告を受ける。この報告に基づいて、経営者の資金管理の誠実さや資金運用能力を評価し、その結果を議決権（会社経営に参加する権利）行使に反映させることができる。このように会社法により、株主は適切に企業、経営者に対する評価ができ、その結果適切に企業経営に参加できるのである（株主と経営者間の利害調整） |
| 債権者 | 債権者は「分配可能額」を定めることを通じて保護される。会社法により分配不能部分を厳格に定め、その部分に相当する会社財産の流出を禁止している（株主と債権者間の利害調整） |

### 4. 金融商品取引法会計

出題ランク：短答 B、論文 C

金融商品取引法会計とは、金融商品取引法の規制の下で行われる会計をいう。金融商品取引法は有価証券の発行及び金融商品等の取引等を公正にし、有価証券の流通を円滑にするほか、資本市場の機能の十全な発揮による金融商品等の公正な価格形成等を図り、もって国民経済の健全な発展と投資者保護に資することを目的とする。

よって、金融商品取引法は、企業が投資者への情報提供のために作成・開示するべき情報を詳細に規定している（会社法よりも詳細）ことから、財務会計の機能のうち「情報提供機能」は、主として金融商品取引法会計を通じて遂行される。

### 金融商品取引法会計と会社法会計の関係

「会社法会計において規定されている会計処理や表示」と「金融商品取引法会計において規定されている会計処理や表示」との間に相違があれば、企業は2つの異なる会計処理や表示を行う必要があり、企業会計の信頼性が著しく低下する。そのため現在では、基本的に会社法会計と金融商品取引法会計の一元化が図られている。

また、会社法会計では基本的に利害調整という観点から、独自に計算規定を設けているが、それは利害対立が生じる局面を中心に制定されたものであり、必ずしもすべての会計処理や表示について規定しているものではない。

ここで、会社法において「株式会社の会計は、一般に公正妥当と認められる企業会計の慣行に従うものとする」と規定されているため、会社法において規定されていない会計処理や表示があった場合、金融商品取引法会計に規定されている会計処理や表示と同様に取扱われる。

結果として会社法会計と金融商品取引法会計の両会計制度は、基本的に一元化されている。

関係の図は、会社法会計には規定がある部分（会社法、会社計算規則）と規定のない部分があり、金融商品取引法会計の企業会計原則などとの間で調整が図られ、基本的に一元化されていることを示す。会社法会計に規定のない部分は、金融商品取引法会計と同様に取り扱う。

金融商品取引法に基づいて行われる企業の財務情報の公表制度は、「企業内容開示制度」又は「ディスクロージャー制度」と呼ばれる。

また、金融商品取引法は、上場会社等に対して、財務諸表（貸借対照表、損益計算書、キャッシュ・フロー計算書、株主資本等変動計算書、附属明細表）の作成と開示を義務付けている。

さらに、個別財務諸表のほか、連結財務諸表や四半期財務諸表及び四半期連結財務諸表の作成・開示も要求している。

なお、金融商品取引法会計では、「企業会計原則」をはじめとする種々の会計基準が基本的な会計処理及び表示の方法を規定し、「財務諸表等規則」や同ガイドラインが詳細な表示方法や注記事項を規定している。さらに、適用指針等において、上記の基準等で規定しきれないより詳細な会計処理等を規定している。

## 第3節 企業会計原則

### 1. 企業会計原則の意義と性格

出題ランク：短答 B、論文 C

企業会計原則は昭和24年に制定され、貸借対照表や損益計算書を作成する際の理論的な土台を提供するもの（会計の基本原則）である。「企業会計原則」には、以下のような記述がある。

1. 企業会計原則は、企業会計の実務の中に慣習として発達したもののなかから、一般に公正妥当と認められたところを要約したものであって、必ずしも法令によって強制されないでも、すべての企業がその会計を処理するに当たって従わなければならない基準である。
2. 企業会計原則は、公認会計士が、公認会計士法及び金融商品取引法に基づき財務諸表の監査をなす場合において従わなければならない基準となる。
3. 企業会計原則は、将来において、会社法、税法、物価統制令等の企業会計に関係ある諸法令が制定改廃される場合において尊重されなければならないものである。

#### 企業会計原則のポイント

- 企業会計原則は（昔からある原則である以上）、すべての会計事象を網羅しているわけではないため、今日においては、「金融商品に関する会計基準」等の新しい会計基準を設定し、企業会計原則を補足している。
- 企業会計原則に規定されている内容が現在、すべて適用されているわけではない。これは企業会計原則は（昔からある原則であるため）現代の会計の考え方にそぐわない部分も一部あるからである。

### 2. 企業会計原則の必要性

出題ランク：短答 C、論文 C

企業会計に合理的な制約を加えないと、会計処理等を行うにあたって、経営者等の恣意性が介入し、利益操作を行う恐れがある以上、利害関係者を保護することができなくなる。つまり、一定の原則に準拠して会計を行うことで、作成される財務諸表等に信頼性を付与し、利害関係者を保護するため、企業会計原則が必要とされる。

企業会計原則のような社会的な規範として形成された会計原則（すべての会社が従うべき会計のルール）は、一般に「GAAP（generally accepted accounting principles）」や、「一般に公正妥当と認められる企業会計の基準」と呼ばれる。

このGAAPに従って財務諸表を作成するが、GAAPには「企業会計審議会または企業会計基準委員会が公表した会計基準」「企業会計基準委員会が公表した会計基準適用指針及び実務対応報告」などが含まれる。

### 会計原則を設定するアプローチ

出題ランク：短答 C、論文 C

会計原則を設定するアプローチには、「演繹的アプローチ」と「帰納的アプローチ」がある。

|  | 演繹的アプローチ | 帰納的アプローチ |
|---|---|---|
| 定義 | 会計の諸概念や目的を最初に規定し、これらと首尾一貫するように、具体的な会計原則を設定する方法 | 最初に実際に行われている会計処理の諸方法を観察し、その中からより一般的または共通的なものを抽出することによって、具体的な会計原則を設定する方法 |
| 長所 | 事前に規定した会計の諸概念や目的に沿って各会計原則を設定する以上、過去に存在しなかった新種の取引や事象が発生した場合であっても機動的に新たな会計原則を開発できる。<br><br>実務上の必要に応じて個々の領域ごとに会計原則が設定された場合でも、会計原則間の首尾一貫性を保つことができる | このアプローチの下で形成された会計原則は、既に実務で広く普及した一般的なものから構成されるため、遵守されやすいルールとなる |

アプローチによる会計基準構築の流れ：

- 演繹的アプローチ：概念フレームワーク → これを前提として → 会計基準を構築する
- 帰納的アプローチ：実務で行われている処理 → この中から共通的、一般的なものを抽出して → 会計基準を構築する

企業会計原則は「企業会計の実務の中に慣習として発達したものの中から、一般に公正妥当と認められるところを要約したもの」であるから、「帰納的アプローチ」によって形成された会計原則である。

ここで、社会から受け入れられる会計原則を形成するためには、会計原則を理論的に体系づけることが不可欠である。その必要性から生まれたのが、演繹的アプローチによる会計原則の設定である。

この演繹的アプローチには、「財務会計の概念フレームワーク」を設定し、これと首尾一貫する会計原則の構築を目指す試みがある。
## 第4節 会計公準

### 1. 会計公準とは

出題ランク：短答 B、論文 C

会計公準とは、会計が行われるための基礎的前提をいう。会計公準の中で最も有名なものに「ギルマンの3公準」がある。以下ではギルマンの3公準について説明する。

### 会計理論の構造図

出題ランク：短答 B、論文 C

減価償却を例に、会計理論がどのような構造により成り立っているかを示すと、次のようになる。

| 構造 | 左側の会計上の内容 | 右側の位置づけ |
|---|---|---|
| 上部構造 | 定率法・定額法等による減価償却 | 会計処理の手続 |
| 中間構造 | 費用配分の原則 | 原則又は基準 |
| 基礎構造 | 継続企業 | 会計公準（基礎的前提） |

会計理論の下から上への関係は、継続企業（基礎構造）→費用配分の原則（中間構造）→定率法・定額法等による減価償却（上部構造）である。

減価償却手続は定率法や定額法により行われるが、そもそも減価償却手続が行われるのは、「費用配分の原則」すなわち「固定資産の取得原価はそれを利用する各会計年度に費用として配分しなければならない」という会計上の原則や基準による（企業会計原則に規定されている）。

さらに、このような原則や基準が存在するのは、「企業が半永久的に継続する」という基礎的前提である会計公準が根底にあるからである。

（将来に渡り、企業は活動を継続して行うことを前提としているからこそ、取得原価を将来に渡り配分する原則が存在するのである。仮に明日に企業が倒産することを前提とした場合、取得原価を将来に渡り配分する原則の存在を説明することはできない。）

上記から会計公準は、現行の会計処理の手続や諸原則・基準の基礎的な土台となるものといえる。

### 2. ギルマンの3公準

出題ランク：短答 A、論文 C

ギルマンの示した会計公準は、①企業実体の公準（会計単位の公準）、②継続企業の公準（会計期間の公準）、③貨幣的評価の公準（貨幣的測定の公準）という3つの公準に分けられる。

#### (1) 企業実体の公準（会計単位の公準）

出題ランク：短答 A、論文 C

企業実体の公準とは、株主（出資者）とは区別された企業そのものの存在を仮定することにより、会計の行われる範囲を限定した公準である。この公準によれば、企業は株主から独立した存在として扱われ、会計の行われる範囲は企業の経済活動のみとなる。

なお、この会計の行われる範囲は、通常、法的実体に基づいて決められるため、個々の企業の経済活動となる。ただし、経済的実体に基づいて決められる場合もある。この具体例は連結財務諸表であり、この場合、会計の行われる範囲は、企業集団全体の経済活動となる。また、法的実体をさらに細分化して、会計の行われる範囲が決められる場合がある。この具体例は本支店会計や本社工場会計である。

企業実体の公準の内容は、企業と株主を別物と捉え、企業が行った行為のみ会計処理を行うことである。

この公準が存在しない場合、株主が個人的に旅行に行って100万払ったときにも、企業側で次の仕訳が行えてしまう。

（借）旅費100万　（貸）現金100万

#### (2) 継続企業の公準（会計期間の公準）

出題ランク：短答 A、論文 C

継続企業の公準とは、企業は半永久的に経営活動を継続するものと仮定する公準である。

ここで、継続企業を仮定しているからこそ、現行制度において、企業の全存続期間を人為的に定めた一定の会計期間に区切って、毎年一定の時に財務諸表を作成して、その期間の経営成績及びその時点における財政状態を利害関係者に示しているのである。

企業は半永久的に活動を継続する。しかし、どこかのタイミングで区切らないと、半永久的に投資者に対して財政状態や経営成績を開示することができない。そこで、設立後の存続期間を会計期間に区切り、会計期間末に貸借対照表・損益計算書を開示する。

通常、1年を1つの会計期間として、会計期間末に財務諸表を作成している。これにより、その期間の経営成績や財政状態を示すことができるのである。

よって、会計期間を設けて財務諸表を作成しているのは、「継続企業の公準」が背景にある。

#### (3) 貨幣的評価の公準（貨幣的測定の公準）

出題ランク：短答 A、論文 C

貨幣的評価の公準とは、①すべての会計事実を貨幣という統一的な尺度により、測定・記録・報告すべきとする公準であり、また②会計の対象が貨幣により評価可能なものに限られるとする公準である（※）。

同公準により、財務諸表数値の加法性及び財務諸表の（企業間・期間）比較可能性が確保されることになる。

この公準に従う場合、貨幣額で客観的に測定できないものは、たとえそれが企業活動のために重要な役割を果たす要素であっても、会計の計算対象とすることはできない。

※ 例えば、経営者の能力、手腕は貨幣的に評価できないため、貸借対照表に計上できない。
