| 1. 貸借対照表の表示・作成 |  |  |  |  |  |  |

貸借対照表は、「総額主義の原則」、「貸借対照表の区分表示」、「貸借対照表の科目の分類」、「貸借対照表の配列」の規定に基づき作成される（以下の「1」〜「4」）。いずれも、明瞭性の原則の「概観性」と関連する。

貸借対照表の資産の合計金額は、負債と純資産の合計金額に一致しなければならない。

### 1. 総額主義の原則

「企業会計原則」には、以下のように規定されている。

> 資産、負債及び資本は、総額によって記載することを原則とし、資産の項目と負債又は資本の項目とを相殺することによって、その全部又は一部を貸借対照表から除去してはならない。

総額主義は、貸借対照表において債権・債務のバランス及び企業規模を明示することで財政状態を明らかにする必要があるため、規定されている。

例外として、繰延税金資産・繰延税金負債の相殺等が挙げられる。

具体例は次のとおりである。

1. 売掛金と買掛金又は貸付金と借入金を相殺して差額だけを表示すると、債権・債務の関係が隠蔽され、企業規模が明らかにならない。
2. 資産項目と評価勘定項目、例えば売掛金と貸倒引当金を相殺すると、将来の貸倒れの可能性及び期末の法的債権額が示されなくなる。また、有形固定資産の取得原価と減価償却累計額を相殺すると、企業の生産力規模や資金の留保額が示されない。

### 2. 貸借対照表の区分表示

「財務諸表等規則」には、以下のように規定されている。

> 資産、負債及び純資産は、それぞれ資産の部、負債の部及び純資産の部に分類して記載しなければならない。
>
> 資産は、流動資産、固定資産及び繰延資産に分類し、更に、固定資産に属する資産は、有形固定資産、無形固定資産及び投資その他の資産に分類して記載しなければならない。
>
> 負債は、流動負債及び固定負債に分類して記載しなければならない。

貸借対照表において、資産・負債を流動項目と固定項目に区分することで、資金の運用形態と調達源泉の関係をより一層明瞭に表示している。

投資家は企業分析を行う際、次の比率に着目する。

- 「流動資産」と「流動負債」の比率
- 「固定資産」と「固定負債」の比率

ケース1のように流動資産が流動負債を上回る場合、短期的に支払う必要がある負債をすべて流動資産で賄うことができ、安全な企業であると分析できる。ケース2のように流動資産が流動負債を下回る場合、短期的に支払う必要がある負債を流動資産で賄えず、手形が不渡りになる等のおそれがあるため、危険な企業であると分析できる。

このように、流動・固定に分類することにより、財政状態を把握しやすくなる。

### 3. 貸借対照表の科目の分類（流動・固定分類）

「企業会計原則」には、以下のように規定されている。

> 資産、負債及び資本（純資産）の各科目は、一定の基準に従って明瞭に分類しなければならない。

貸借対照表の区分表示を行うためには、資産と負債を流動項目と固定項目とに分類しなければならない。その分類基準には、「正常営業循環基準」と「一年基準」とがある。

#### (1) 正常営業循環基準と一年基準の意義とその内容

正常営業循環基準と一年基準の意義は、次のとおりである。

| 基準 | 内容 |
|---|---|
| 正常営業循環基準 | 企業の主たる営業活動の循環過程にある項目を流動項目に分類する基準。製造業であれば、原材料を仕入れて製品を生産し、それを販売して代金を回収する一連の過程をいう。 |
| 一年基準 | 貸借対照表日の翌日から起算して一年以内に換金化または支払われるか否かにより、流動項目と固定項目とに分類する基準。 |

正常営業循環過程から生じた債権（売掛金など）であっても、「破産更生債権等」に区分された債権は、正常な営業循環過程外にある項目とみなされるため、「一年基準」が適用される。

#### (2) 正常営業循環基準と一年基準の適用

正常営業循環基準と一年基準の適用順序としては、まず「正常営業循環基準」を適用し、この循環過程に含まれない資産・負債に対して「一年基準」を適用する。

資産・負債のうち、正常営業循環過程にある項目は流動項目とする。正常営業循環過程にない項目には一年基準を適用し、貸借対照表日の翌日から起算して一年以内に換金化または支払いが行われるものは流動項目、一年を超えるものは固定項目とする。

したがって、正常営業循環過程にある資産・負債（例えば、商品や売掛金）は流動項目となる。正常営業循環過程にない資産・負債（例えば、土地を購入した際に生じた未払金）には一年基準が適用される。

#### (3) 正常営業循環基準と一年基準の適用がされない項目

正常営業循環基準または一年基準の適用がされない項目として、次の項目が挙げられる。

| 項目 | 取扱い |
|---|---|
| 経過勘定項目 | 前払費用には一年基準が適用されるが、それ以外の未収収益、未払費用及び前受収益に関しては一年基準の適用はなく、たとえ一年を超えるものであっても流動項目とされる。 |
| 繰延資産 | 流動資産や固定資産の区分ではなく、繰延資産の区分に計上する。繰延資産は財産価値がなく、企業の財務安全性とは無関係であるため、正常営業循環基準や一年基準の適用外の項目とされる。 |

#### 補足　棚卸資産と固定資産の表示区分に関する規定

「企業会計原則」においては、次のように規定されている。

> 商品、製品、半製品、原材料、仕掛品等のたな卸資産は、「流動資産」に属するものとし、企業がその営業目的を達成するために所有し、かつ、その加工若しくは売却を予定しない財貨は「固定資産」に属するものとする。
>
> 固定資産のうち、残存耐用年数が一年以下となったものも流動資産とせず、「固定資産」に含ませ、たな卸資産のうち、恒常在庫品として保有するもの、もしくは余剰品として長期間にわたって所有するものも固定資産とせず、「流動資産」に含ませるものとする。

### 4. 貸借対照表の配列

「財務諸表等規則」には、以下のように規定されている。

> 資産及び負債の科目の記載の配列は、流動性配列法によるものとする。

貸借対照表項目の配列には、「流動性配列法」と「固定性配列法」がある。

|  | 流動性配列法 | 固定性配列法 |
|---|---|---|
| 定義 | 貸借対照表項目を流動性の高い順序、すなわち資産は換金性の高い項目の順、負債は返済期限の早い項目の順に配列する方法。資産は流動資産から固定資産、負債は流動負債から固定負債を経て資本の順に配列する。 | 貸借対照表項目を流動性の低い順序で配列する方法。資産は固定資産から流動資産、負債は固定負債から流動負債を経て資本の順に配列する。 |
| 現行の取扱い | 企業が流動資産でどれだけの流動負債を支払う能力があるかを明らかにするのに適しているため、原則として流動性配列法による。 | 固定資産の割合が極めて高い電力会社やガス会社では、例外的に固定性配列法が採用されている。 |

流動性配列法では、流動負債に対して流動資産がどの程度確保されているかという財務流動性を明らかにする。固定性配列法は、固定資産を多額に有する一部の企業のみに認められている。
