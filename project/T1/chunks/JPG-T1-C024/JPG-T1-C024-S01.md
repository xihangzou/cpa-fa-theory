# 第16章 賃貸等不動産の時価等の開示に関する会計基準

## 第1節 本会計基準の具体的な内容

短答式本試験における出題実績では、「1. 本会計基準の具体的な内容」が20Ⅰに4問、22Ⅰに1問出題されている。論文式本試験における出題実績の記載はない。

### 1. 本会計基準の適用範囲と用語の定義

出題ランク：短答C、論文C

#### (1) 本会計基準の適用範囲

本会計基準は、賃貸等不動産を保有する企業に適用する。

また、連結財務諸表において賃貸等不動産の時価等の開示（注記）を行っている場合には、個別財務諸表での開示を要しない。

#### (2) 用語の定義

本会計基準では、「時価」及び「賃貸等不動産」について、次のように定義している。

| 用語 | 定義 |
|---|---|
| 時価 | 公正な評価額。通常、それは観察可能な市場価格に基づく価額をいい、市場価格が観察できない場合には合理的に算定された価額をいう。 |
| 賃貸等不動産 | 棚卸資産に分類されている不動産以外のものであって、賃貸収益又はキャピタル・ゲインの獲得を目的として保有されている不動産（ファイナンス・リース取引の貸手における不動産を除く）。 |

したがって、物品の製造や販売、サービスの提供、経営管理に使用されている場合は賃貸等不動産には含まれない。

賃貸収益目的の例では、会社がテナント賃貸用ビルを保有し、借手のA社から月1億円、借手のB社から月3億円の賃料を受け取っている。このようにテナントを他社に賃貸することによる収益を得る目的で保有している場合、賃貸等不動産に該当し、当該不動産の時価情報を注記する。

キャピタル・ゲイン（売却益）目的の例では、会社が転売することを目的にビルを20億で購入し、時価が上昇して25億になった場合、市場で売却して5億の利益を獲得する。このように時価上昇による売却益を期待して不動産を保有する場合も、賃貸等不動産に該当し、当該不動産の時価情報を注記する。

固定資産に分類されている不動産は、次のように区分される。賃貸収益又はキャピタル・ゲインの獲得を目的として保有されている不動産だけが、時価情報の注記の対象となる。

1. 賃貸収益又はキャピタル・ゲインの獲得を目的として保有されている不動産
2. 物品の製造や販売に使用されている不動産
3. サービスの提供に使用されている不動産
4. 経営管理に使用されている不動産

後者の不動産の例として、生産に使用されている自社の工場、製品の販売に使用される自社の店舗（2の例）、自社が運営しているホテルやゴルフ場（3の例）、本社機能に利用される自社ビル（4の例）が挙げられるが、これらの不動産については時価情報の注記の対象とはならない。

### 2. 本会計基準の適用対象資産と適用対象外資産

出題ランク：短答B、論文C

本会計基準の適用対象資産（時価情報の注記の対象となる資産）及び適用対象外資産（時価情報の注記の対象とはならない資産）は、次のとおりである。

#### (1) 本会計基準の適用対象資産

1. 貸借対照表において投資不動産として区分されている不動産

   理由：当該不動産は市場平均を超える成果を期待して保有されているものではなく、その時点そのものが企業にとっての価値を示している（時価の分だけ成果が得られる）ため、時価情報の注記の対象となる。

2. 将来の使用が見込まれていない遊休不動産

   理由：当該不動産は処分によるキャッシュ・フローしか期待されていないため、処分価額である「時価」が企業にとっての価値を示すため、時価情報の注記の対象となる。

3. 上記「1」「2」以外で賃貸されている不動産

4. 将来において賃貸等不動産として使用される予定で開発中の不動産、継続して賃貸等不動産として使用される予定で再開発中の不動産、及び賃貸を目的として保有されているにもかかわらず一時的に借手が存在しない不動産

   理由：将来、賃貸等不動産とされることが明らかであるため、時価情報の注記の対象となる。

#### (2) 本会計基準の適用対象外資産

本会計基準の適用対象外資産（時価情報の注記の対象とはならない資産）は、次のとおりである。ただし、下記の「2」については、自発的に時価情報を注記することは認められている。

1. 棚卸資産に分類されている不動産（※）

   理由：「棚卸資産の評価に関する会計基準」に従って処理や表示を行うため。

2. 物品の製造や販売、サービスの提供、経営管理に使用されている不動産

   理由：当該不動産から市場平均（時価）を超える成果を生み出すことを期待して使用している以上、市場の平均的な期待で決まる時価情報を注記する必要がない。

3. ファイナンス・リース取引の貸手における不動産

   理由：貸手では当該不動産は貸借対照表上、金銭債権等として計上される以上、賃貸等不動産には該当しない。なお、借手について、当該不動産が賃貸等不動産の定義を満たす場合には、賃貸等不動産に該当する。

※ 「棚卸資産の評価に関する会計基準」では、市場価格の変動により利益を得るトレーディング目的で保有する棚卸資産は時価をもって貸借対照表価額とする旨が規定されている。したがって、不動産（通常は取得原価で評価）であっても、トレーディング目的で保有する棚卸資産に該当するものは時価評価される。

### 3. 賃貸等不動産として使用される部分とそうでない部分がある場合

不動産の中には、物品の製造や販売、サービスの提供、経営管理に使用されている部分と賃貸等不動産として使用される部分から構成される場合がある。この場合、賃貸等不動産として使用される部分については、賃貸等不動産に含める。なお、賃貸等不動産として使用される部分の割合が小さいと考えられる場合は、賃貸等不動産に含めないことができる。

図のケース1（通常の場合）は、会社保有のビルのうち「本社ビルとして利用している部分」については時価情報を注記せず、「他社に賃貸している部分」については時価情報を注記する（賃貸等不動産として扱う）。

図のケース2（賃貸部分の割合が小さい場合）は、会社保有のビルのうち「本社ビルとして利用している部分」と、細い一部分である「賃貸部分」から構成される。この場合、賃貸部分については時価情報を注記しないことが認められる（賃貸等不動産として扱わないことが認められる）。

### 4. 賃貸等不動産に関する注記事項

賃貸等不動産を保有している場合は、次の事項を注記する。ただし、賃貸等不動産の総額に重要性が乏しい場合は注記を省略することができる。また、管理状況等に応じて、注記事項を用途別、地域別等に区分して開示することができる。

1. 賃貸等不動産の概要
2. 賃貸等不動産の貸借対照表計上額及び期中における主な変動
3. 賃貸等不動産の当期末における時価及びその算定方法
4. 賃貸等不動産に関する損益

#### 注記例

当社は関東地域において、賃貸用のオフィスビルを有している。X1年3月期における当該賃貸等不動産に関する賃貸損益は120百万円である。また、当該賃貸等不動産の貸借対照表計上額、当期増減額及び時価は、次のとおりである。

| 貸借対照表計上額 |  |  | 当期末の時価 |
|---|---:|---:|---:|
| 前期末残高 | 当期増減額 | 当期末残高 |  |
| 3,050百万円（取得価額） | 240百万円 | 3,290百万円（取得価額） | 3,550百万円（時価） |

注1）当期増減額の内、主な増加額は不動産取得（560百万円）であり、また主な減少額は不動産売却（310百万円）である。

注2）当期末の時価は、主として「不動産鑑定評価基準」に基づいて自社で算定した金額である。
