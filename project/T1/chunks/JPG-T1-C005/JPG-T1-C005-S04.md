# 第3章 貸借対照表・損益計算書総論
## 4. 静態論会計と動態論会計

短答：B　論文：C

貸借対照表の本質をどのように捉えるかという貸借対照表観は、「静態論」と「動態論」の2つがある。

### (1) 静態論の考え方

17〜20世紀初頭の企業会計の主たる目的は債権者の保護にあった。これは、当時の企業は経済的基盤が脆弱で、企業の倒産により債権者が損失を被ることが多かったためである。この状況下において、企業会計に求められていたのは、企業の債務弁済能力（どれだけ債務を返済する力があるか）を表示することであり、貸借対照表はある時点においてどれだけの財産・債務を有しているかという財産計算を行うために作成されると捉えていた。

このように貸借対照表を捉える考え方を「静態論」という。

### (2) 静態論における貸借対照表

静態論における貸借対照表（静的貸借対照表）は、以下の特徴を有している。

| 項目 | 内容 |
|---|---|
| 計上される項目 | 決算日において実地調査を行い、処分可能な資産と企業の負担する債務をすべて計上する。資産は換金能力のあるものに限定し、評価額は売却時価による。負債は法的に支払わなければならない法的確定債務に限定し、評価額は法的弁済額による。 |
| 計上されない項目 | 繰延資産や引当金は貸借対照表に計上できない。 |
| 貸借対照表・損益計算書 | 実地調査に基づき、その時点の財産と債務を認識し、貸借対照表を作成するため、貸借対照表は棚卸法により作成され、期間利益の計算は財産法により行われる。 |
| 重視する点 | 貸借対照表により債務弁済能力を表示すること（財産計算をすること）。 |

通常の貸借対照表では、現金100、建物800（取得原価）、繰延資産100を資産に計上し、借入金600、修繕引当金100、資本金300を負債・資本に計上する。静態論の貸借対照表では、建物を700（売却時価）として計上し、現金100、借入金600、資本金200を示す。

修繕するか否かは企業が決定できる。お金がなければ修繕しなくてもよく、この場合にお金を払う必要はない。修繕引当金は法的確定債務ではないので計上されない。また、繰延資産は財産価値がない（売れない）ので計上されない。企業が今倒産しても200の余剰があることがわかり、債権者は安心する。この200は「解体価値」とも呼ばれ、企業が今倒産したら200の価値があるといえる。

### (3) 動態論の考え方

20世紀に入り、企業の経済的基盤は安定してきたため、企業の倒産ではなく、企業の継続性を前提とするようになった。また、企業の将来性を期待して、企業に投資する資金提供者が増加した。この資金提供者は、企業が将来どれだけ利益を獲得できるかという情報を求めていた。

この状況下において企業会計に求められていたのは、投資者に対して企業の収益力を表示することで投資者を保護することにあるため、期間損益計算が重視されるようになった。

つまり、会計目的が従来の貸借対照表による財産計算から損益計算書による期間損益の表示に移ると、貸借対照表は適正な期間損益を算定するために作成される（損益計算書が「主」、貸借対照表は「従」）。

このように貸借対照表を捉える考え方を「動態論」という。

### (4) 動態論における貸借対照表

動態論における貸借対照表（動的貸借対照表）は、以下の特徴を有している。

| 項目 | 内容 |
|---|---|
| 計上される項目 | 期間損益計算を適正に行うという見地から、貸借対照表に計上するべき資産、負債が決定される。換金能力を有しない繰延資産や債務性のない引当金であっても、期間損益計算を適正に行う上で必要な項目は貸借対照表に計上する。 |
| 貸借対照表・損益計算書 | 帳簿記録に基づき、損益計算書に含まれなかった項目を収集して貸借対照表を作成するため、貸借対照表は誘導法により作成され、期間損益の計算は損益法により行われる。 |
| 重視する点 | 損益計算書により適正な期間損益計算を行うこと。 |
| 貸借対照表の役割 | 収入・支出計算と収益・費用計算との間の期間的なズレから生じる収支の未解決項目を収容し、次期へ繰り越す役割。 |
|  | 当期と次期の損益計算を結び付ける「連結環」としての役割。 |

図の例では、設立時に現金200を資本金として受け入れ、株式交付費15を支出する。期中には商品を90で購入し、商品2つを売価100で販売する。決算時には株式交付費償却5を計上する。損益計算書には株式交付費償却5と販売益40を集計し、利益35を表示する。期末貸借対照表には、現金95、売掛金100（収益・未収入）、商品30（支出・未費用）、株式交付費10（支出・未費用）、資本金200、利益35を計上する。

商品について、支出30であるが費用は0であるように、収入・支出と収益・費用の対応が未完了の項目がある。これらを貸借対照表に収容し、次期以降の収益に対応させるため、繰延資産であっても貸借対照表に計上される。当期の損益に関係するもののみを損益計算書に集計する。

#### 「収支の未解決項目」のイメージ

損益計算では収益の計上時点と費用の計上時点、収支計算では収入時点と支出時点があり、通常、それぞれの時点はずれる。

| 収益・収入の関係 | 項目 |
|---|---|
| 収益：○、収入：× | 売掛金 |
| 収益：×、収入：○ | 前受金 |

このように、収益と収入、または費用と支出のどちらかが完了していない状態を「収支の未解決」と呼ぶ。このような項目を集める場所こそが貸借対照表であると考える。

#### 「連結環」のイメージ

収支の未解決項目の中には、次期の損益計算に関連する項目も存在する。株式交付費15のうち、当期の費用5を当期の損益計算書に計上し、残りの株式交付費10を当期の貸借対照表に繰り越す。次期にはこの10のうち5を費用として次期の損益計算書に計上する。このように、貸借対照表は当期と次期の損益計算を結びつけるものである。

#### 動的貸借対照表の構成要素

動的貸借対照表は収支の未解決項目を収集するものであり、構成要素は次のようになる。

| 資産の部 | 資本・負債の部 |
|---|---|
| 現金 | 資本金 |
| 支出・未収入項目（貸付金等） | 収入・未支出項目（借入金等） |
| 支出・未費用項目（商品・建物等） | 費用・未支出項目（未払費用・引当金等） |
| 収益・未収入項目（未収収益等） | 収入・未収益項目（前受収益等） |

### 静態論会計と動態論会計の相違点

|  | 静態論会計 | 動態論会計 |
|---|---|---|
| 時代背景 | 17〜20世紀初頭にかけて、企業規模は小さく倒産が相次いだ。 | 20世紀初頭から現在にかけて、企業が大規模化し倒産が減る一方で、投資者が出現した。 |
| 会計の目的 | 債権者保護（貸借対照表をより重視）→企業の債務弁済能力を開示する、財産計算を行う。 | 投資者保護（損益計算書をより重視）→適正な期間損益計算を行うことで、企業の収益力を開示する。 |
| 貸借対照表の本質 | 企業の債務弁済能力を表示するもの。 | 収支の未解決項目を収容するもの。 |
| 期間利益の算定方法 | 財産法（実地調査を前提） | 損益法（帳簿記録を前提） |
| 貸借対照表の作成方法 | 棚卸法（実地調査を前提） | 誘導法（帳簿記録を前提） |
| 資産性と負債性 | 資産：換金可能なもの。負債：法的確定債務。 | 適正な期間損益計算のために必要な項目は資産、負債として計上される。 |
| 資産の評価基準 | 売却時価 | 貨幣性資産：回収可能価額。費用性資産：取得原価。 |
