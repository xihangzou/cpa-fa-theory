# 第3章 貸借対照表・損益計算書総論
## 3. 貸借対照表の作成方法

短答：B　論文：C

貸借対照表の作成方法は、「棚卸法」と「誘導法」がある。

### (1) 棚卸法（財産目録法）

|  | 内容 |
|---|---|
| 定義 | 資産及び負債について実地調査を行って、財産目録を作成し、この資料に基づいて貸借対照表を作成する方法 |
| 特徴 | 資産・負債は、物理的に識別可能な項目及び法律上の債権・債務に限られる（繰延資産や債務性のない引当金の計上は否定される）。 |
|  | 貸借対照表は、必ずしも損益計算書の作成を前提とせずに、独立に作成できる。 |
|  | 棚卸法によって作成された二時点の貸借対照表の比較により期間損益を計算する方法が財産法であるため、棚卸法と財産法は関連性を有する。 |

棚卸法では、期首と期末に実地調査を行って貸借対照表を作成し、二時点の純資産の差額から財産法による期間利益50を計算する。

### (2) 誘導法

|  | 内容 |
|---|---|
| 定義 | 帳簿記録を基礎にして、その帳簿記録から当期の損益計算に算入されなかった項目により、貸借対照表を作成する方法 |
| 特徴 | 繰延資産や債務性のない引当金についても計上される。 |
|  | 貸借対照表の作成の過程で損益計算書の作成も可能となる。 |
|  | 帳簿記録から収益・費用を抜き出して損益計算を実施するのが損益法であり、期間損益計算に無関係の項目を収容して貸借対照表を作成するのが誘導法であるため、誘導法と損益法は関連性を有する。 |

誘導法では、期首貸借対照表を出発点として帳簿記録から、①期間損益に関連するものを抜き出して損益計算書を作成し、②期間損益に組み込まなかった項目を収集して期末貸借対照表を作成する。損益計算書は損益法により、貸借対照表は誘導法により作成される。
