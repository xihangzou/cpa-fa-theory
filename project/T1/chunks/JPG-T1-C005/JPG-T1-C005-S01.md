### 1. 資本循環

短答：C　論文：D

企業は、まず株主からの出資や借入等によって、業務遂行に必要な資本（貨幣）を獲得する（資本の調達）。次に調達した資本を各種の生産手段や労働力の購入に充てる（資本の投下）。これによって生産された生産物を外部に販売して貨幣を回収する（資本の回収）。つまり、企業の経済活動は、①資本の調達→②資本の投下→③資本の回収という一連の資本循環過程に他ならない。

資本循環の流れは、資本と負債から貨幣を調達し、貨幣を商品や土地に投下し、商品を販売して売掛金を経て貨幣を回収する流れとして示される。

ここで、継続企業の前提の下、資本循環過程を一定期間に区切って会計報告する必要があるが、財務会計は「財政状態と経営成績を明らかにする」ことを主要な目的としているため、財務諸表もこの観点から作成される必要がある。以下、貸借対照表・損益計算書を用いて、資本循環過程を具体的に見ていく。

#### ① 資本の調達

X1年期首に株主から300万円の出資を受け、さらに銀行から200万円借り入れて、合計500万円の資金を調達したとすると、この時点での貸借対照表は以下のようになる。

| X1年期首貸借対照表 | 金額（万円） |
|---|---:|
| 現金（資産） | 500 |
| 借入金（負債） | 200 |
| 資本金（資本） | 300 |

#### ② 資本の投下

この企業は商業（商品を仕入れて売ること）を営むとすると、まず商品を仕入れる。ここで、X1年期中に、400万円で商品を仕入れ、100万円で土地を購入した場合、貸借対照表は以下のようになる。

| X1年期中貸借対照表 | 金額（万円） |
|---|---:|
| 商品（資産） | 400 |
| 土地（資産） | 100 |
| 借入金（負債） | 200 |
| 資本金（資本） | 300 |

#### ③ 資本の回収

X1年期末に、400万円の商品うち、250万円分を売価300万円で掛売したとすると、これを経営成績の観点からすると、収益は300万円、費用は250万円となるため、損益計算書は以下のようになる。

| X1年度損益計算書 | 金額（万円） |
|---|---:|
| 売上原価（費用） | 250 |
| 利益 | 50 |
| 売上（収益） | 300 |

また、X1年度末時点の貸借対照表は以下のようになる。

| X1年度末貸借対照表 | 金額（万円） |
|---|---:|
| 売掛金（資産） | 300 |
| 商品（資産） | 150 |
| 土地（資産） | 100 |
| 借入金（負債） | 200 |
| 資本金（資本） | 300 |
| 利益（資本） | 50 |

上記から現行制度上、資本循環を主に損益計算書と貸借対照表という形で描写している。

図では、資本の調達から資本の投下を経て、投下された資本の一部が費用となり、収益と対応して利益を生み、回収済みの投下資本と未回収の投下資本が期末貸借対照表に残る関係が示されている。期末貸借対照表には、売掛金300、商品150、土地100、負債200、資本金300、利益50が対応する。
