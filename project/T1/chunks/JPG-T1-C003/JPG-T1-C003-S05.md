# 第2章 一般原則
## 第5節 明瞭性の原則

「企業会計原則 第一 四」には、以下のように規定されている。

> 企業会計は、財務諸表によって、利害関係者に対し必要な会計事実を明瞭に表示し、企業の状況に関する判断を誤らせないようにしなければならない。

### 1. 「明瞭性の原則」の意味内容

出題ランク：短答 B、論文 C

明瞭性の原則とは、企業の状況に関する利害関係者の判断を誤らせないようにするため、①利害関係者の意思決定に重要な影響を及ぼす項目については詳細情報を開示する一方で、②財務諸表の理解や比較を容易にするため財務諸表の形式の統一を要請する原則である（表示方法に関する原則）。

簡潔にいえば、①重要性の高いことは詳細に表示する（詳細性）一方で、②財務諸表を見やすくわかりやすくするように形式の統一化を図る（概観性）という2つの側面を有する。詳細性を重視しすぎて会計的事実を重要性の高低にかかわらずすべて表示すると、財務諸表は見づらくわかりづらくなり、概観性が得られない。詳細性と概観性のバランスをとり、明瞭な表示を要求する原則が明瞭性の原則である。

### 2. 明瞭性の原則の適用例

現行制度における主な適用例は次のとおりである。

#### (1) 損益計算書・貸借対照表の形式（概観性に関する論点）

出題ランク：短答 C、論文 C

損益計算書・貸借対照表の表示方法には、「報告式」と「勘定式」という2つの形式がある。経営者が好きなように表示すると不明瞭になるため、形式を統一する。

- 報告式：はじめに売上高、流動資産を記載し、上から下へ表示する様式。
- 勘定式：紙面を左右に二分し、貸方に収益・負債・純資産項目、借方に費用・資産項目を記載する様式。

#### (2) 附属明細表の作成（詳細性に関する論点）

出題ランク：短答 B、論文 C

附属明細表とは、財務諸表の重要な科目について貸借対照表や損益計算書の記載内容を補足するため、①一定の項目の期末残高の内訳ないし明細、②当該項目の期中における増減状況を表示した書類（財務諸表を構成する書類の一つ）をいう。会社計算規則では「附属明細書」と呼ばれる。四半期財務諸表及び四半期連結財務諸表では開示対象ではない。

| 財務諸表等規則 | 連結財務諸表規則 | 会社計算規則（117条） |
|---|---|---|
| 有価証券明細表、有形固定資産等明細表、社債明細表、借入金等明細表、引当金明細表、資産除去債務明細表 | 社債明細表、借入金等明細表、資産除去債務明細表 | 有形固定資産及び無形固定資産の明細、引当金の明細、販売費及び一般管理費の明細 |

連結財務諸表を作成している場合、個別財務諸表上の「社債明細表」「借入金等明細表」「資産除去債務明細表」は作成を要しない。連結財務諸表規則の3項目は、法的に支払義務を負っている項目を開示する。

引当金明細表の開示例は次のとおりである。

| 区分 | 前期末残高 | 当期増加額 | 当期減少額（目的使用） | 当期減少額（その他） | 期末残高 | 摘要 |
|---|---:|---:|---:|---:|---:|---|
| 貸倒引当金 | 560 | 500 | 480 |  | 580 |  |
| 製品保証引当金 | 750 | 770 | 720 |  | 800 |  |

引当金の期中の増減情報は貸借対照表や損益計算書だけでは十分に把握できないが、投資者の企業分析に必要となる場合があるため、より詳細に開示する。

注記とは、財務諸表利用者が企業の状況についてより適切な判断ができるよう、重要な項目について補足的な説明を記載するものである。貸借対照表や損益計算書では把握できない重要な情報を記載し、附属明細表のような金額の増減とは異なる情報を提供する。

#### (3) 会計方針の注記

##### ① 会計方針の注記とその内容

出題ランク：短答 B、論文 C

会計方針とは、財務諸表の作成にあたって採用した会計処理の原則及び手続をいう。財務諸表には重要な会計方針を注記する。ただし重要性の乏しいものは注記を省略できる。例は次のとおりである。

1. 有価証券の評価基準及び評価方法
2. 棚卸資産の評価基準及び評価方法（先入先出法、平均法など）
3. 固定資産の減価償却の方法（定額法、定率法など）
4. 繰延資産の処理方法
5. 外貨建の資産及び負債の本邦通貨への換算基準
6. 引当金の計上基準
7. 収益及び費用の計上基準

会計基準等の定めが明らかで、当該会計基準等において代替的な会計処理の原則及び手続が認められていない場合には、会計方針に関する注記を省略できる。

有価証券の評価方法には、取得原価を算定するために採用した方法（移動平均法、総平均法等）と、その他有価証券の時価評価における評価差額の取扱いが含まれる。繰延資産の処理方法には、株式交付費・社債発行費等を支出時に全額費用処理する場合が含まれ、繰延資産に計上する場合は償却期間及び償却方法を記載する。外貨建資産・負債の換算基準については、基準に定めのない事項、又は基準の適用が適当でない場合に採用した他の合理的な換算基準等を記載する。引当金の計上基準には各引当金の計上理由、計算の基礎その他の設定根拠を記載する。収益・費用の計上基準にはファイナンス・リース取引等、財務諸表について適正な判断に必要な事項を記載する。

その他、支払利息を資産の取得原価に算入する会計処理の内容等、財務諸表について適正な判断に必要と認められる基本事項も開示対象となる。

##### ② 会計方針の注記の記載場所

出題ランク：短答 B、論文 C

| 制度 | 記載場所 |
|---|---|
| 金融商品取引法会計 | 会計方針はキャッシュ・フロー計算書の次に記載する。連結財務諸表でも同じ。 |
| 会社法会計 | 会計方針は個別注記表に記載する。連結計算書類でも同じ。 |

##### ③ 会計方針の注記の開示目的

出題ランク：短答 B、論文 C

一つの会計事実について複数の会計方針が認められている場合、いずれを採用するかにより財務諸表の数値は異なる。そのため、会計数値の算定方法等の財務諸表作成の基礎を明らかにする必要がある。

重要な会計方針に関する注記の開示目的は、財務諸表を作成するための基礎となる事項を財務諸表利用者が理解できるように、採用した会計処理の原則及び手続の概要を示すことである。特定の会計事象等に関する会計基準等の定めが明らかでない場合にも、重要性があれば会計方針の注記を行う。例えば投資者には減価償却費の算定根拠を知りたいというニーズがある。

#### (4) 後発事象の注記

##### ① 後発事象の注記とその内容

出題ランク：短答 B、論文 C

後発事象とは、貸借対照表日後、財務諸表提出会社の翌事業年度以降の財政状態及び経営成績及びキャッシュ・フローの状況に影響を及ぼすものをいう。重要な後発事象が発生したときは、当該事項を注記しなければならない。

重要な後発事象の例は、火災・出水等による重大な損害の発生、多額の増資又は減資及び多額の社債の発行又は繰上償還、会社の合併・重要な営業の譲渡又は譲受、重要な係争事件の発生又は解決、主要な取引先の倒産である。

貸借対照表日後3か月以内に財務諸表を開示する場合、期末日後に生じた事象で当期の財務諸表に反映されていない事象を後発事象という。当期の財務諸表に反映できるのは当期首から当期末に生じた事象のみである。

##### ② 重要な後発事象の注記の必要性

出題ランク：短答 C、論文 C

後発事象は当期の財務諸表には直接反映されないが、財務諸表利用者の意思決定に大きな影響を及ぼす。重要な後発事象を注記することで、企業の将来の財政状態及び経営成績を理解するための補足情報を提供できる。財務諸表は決算日における情報を示すにとどまり、公表時には適時性を欠くことがあるため、注記により決算日後から財務諸表作成日までのタイムラグを埋める。

### 補足　修正後発事象と開示後発事象

出題ランク：短答 B、論文 C

| 区分 | 内容 | 例 |
|---|---|---|
| 修正後発事象 | 決算日現在において既に存在していた状況証拠が、決算日から当該年度の財務諸表を作成する日までに確実になった場合。当年度の財務諸表を修正する必要がある。 | 得意先に対する売上債権の貸倒引当金を積み増す場合 |
| 開示後発事象 | 決算日後に全く新しい事象が発生した場合。当年度の財務諸表に注記する必要がある。 | 決算日後の災害により機械設備が損害を受けた場合 |

#### (5) その他重要事項の注記

##### ① 追加情報

出題ランク：短答 A、論文 C

追加情報とは、「財務諸表等規則（表示や注記についてのルール）」に定められている注記のほか、利害関係人が会社の財政状態、経営成績、キャッシュ・フローの状況について適正な判断を行うために必要と認められる情報をいう。追加情報については注記しなければならない。

##### ② 継続企業

出題ランク：短答 A、論文 C

貸借対照表日において、継続企業の前提に重要な疑義を生じさせる事象又は状況が存在し、当該事象又は状況を解消し又は改善するための対応をしてもなお、継続企業の前提に関する重要な不確実性が認められるときは、次の事項を注記する。ただし、貸借対照表日後に重要な不確実性が認められなくなった場合は注記しない。

1. 当該事象又は状況が存在する旨及びその内容
2. 当該事象又は状況を解消し、又は改善するための対応策
3. 当該重要な不確実性が認められる旨及びその理由
4. 当該重要な不確実性の影響を財務諸表に反映しているか否かの別

貸借対照表日後にこのような状況が発生した場合は、重要な後発事象に該当する。

### 補足　注記の順序

出題ランク：短答 C、論文 C

会計方針、会計方針の変更及び継続企業の前提に関する注記について、次の規定がある。

1. 会計方針の注記は、キャッシュ・フロー計算書の次に記載しなければならない。
2. 会計方針の変更に関する注記は、会計方針の注記の次に記載しなければならない。
3. 継続企業の前提に関する注記は、上記の規定にかかわらず、キャッシュ・フロー計算書の次に記載しなければならない。

したがって、①のみの場合はキャッシュ・フロー計算書、会計方針の注記、その他の注記の順となる。①及び②がある場合は、キャッシュ・フロー計算書、会計方針の注記、会計方針の変更の注記、その他の注記の順となる。①及び③がある場合は、キャッシュ・フロー計算書、継続企業の前提の注記、会計方針の注記、その他の注記の順となる。
