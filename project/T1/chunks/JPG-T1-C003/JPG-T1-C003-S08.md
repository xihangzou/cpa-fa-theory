# 第2章 一般原則
## 第8節 単一性の原則

「企業会計原則 第一 七」には、以下のように規定されている。

> 株主総会提出のため、信用目的のため、租税目的のため等種々の目的のために異なる形式の財務諸表を作成する必要がある場合、それらの内容は、信頼しうる会計記録に基づいて作成されたものであって、政策の考慮のために事実の真実な表示をゆがめてはならない。

### 1. 単一性の原則

出題ランク：短答 B、論文 C

単一性の原則とは、二重帳簿を禁止し、財務諸表の形式的多元性を認めつつ、実質的一元性を要求する原則である。

財務諸表を提出先により異なる形式で作成する場合（例えば、会社法と金融商品取引法では貸借対照表・損益計算書の形式が異なる）であっても、その記載内容は信頼しうる一組の会計帳簿に基づいていなければならない。これを「実質一元・形式多元」という。

例えば、株主総会に提出する財務諸表や銀行融資などの信用目的で作成する財務諸表では、企業はできるだけ多くの利益を計上したいと望む。一方、税務申告目的の財務諸表では課税所得を圧縮して税金を節約するため、利益を少なく計上する動機を有する。このような矛盾する要請に応えるため二重帳簿を作成せざるを得ないとしても、二重帳簿の作成は認められない。

それぞれの財務諸表は、作成目的が異なっていても会計帳簿から誘導的に作成されるものであり、その実質的内容は同一でなければならない。

流れは、会計事実 → 一組の会計帳簿（実質一元、二重帳簿の禁止） → 誘導法 → 財務諸表（形式多元）である。形式多元の作成目的には、株主総会提出目的、信用目的、税務申告目的、その他の目的がある。
