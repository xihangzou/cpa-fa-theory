# 第2章 一般原則
## 第2節 真実性の原則

「企業会計原則 第一 一」には、以下のように規定されている。

> 企業会計は、企業の財政状態及び経営成績に関して、真実な報告を提供するものでなければならない。

### 1. 真実性の原則の位置付け

出題ランク：短答 B、論文 C

真実性の原則とは、企業会計は企業の財政状態及び経営成績に関して、真実な報告を提供しなければならないことを要請する原則をいう。

真実性の原則は、企業会計の究極目標を示したものであり、企業会計のすべての原則を統括する企業会計の最高規範である。他の原則は真実性の原則を支えているという関係があり、他の原則が遵守されることで真実な報告が確保される。

### 2. 「真実性」の意味内容

出題ランク：短答 B、論文 C

真実性の原則がいうところの真実とは絶対的な真実でなく、「相対的な真実」を意味する。真実の内容が相対的にならざるを得ない理由は次のとおりである。

| 理由 | 内容 |
|---|---|
| 会計の目的の依存性 | 真実の意味は会計の目的に依存する。会計の目的は時代や場所によって異なるため、真実性の原則の「真実」も相対的に変化する。 |
| 期間損益計算の暫定性 | 継続企業を前提とした期間損益計算では、経営者の見積りや判断が不可避的に介入する。例えば売上債権に対する貸倒引当金の金額は見積計算となるため、これに基づく会計数値は暫定的なものとなる。 |
| 代替的な会計処理の容認 | 同一の会計事実について複数の代替的会計処理が容認されており、いずれを選択するかによって計算結果は異なる。 |

固定資産を購入した場合、事業活動の継続を前提とすれば、資産の取得原価を将来にわたり配分する必要がある。しかし、何年間で配分するかは経営者が個々に見積るため、費用計算には経営者の見積りや判断が介入せざるを得ない。
