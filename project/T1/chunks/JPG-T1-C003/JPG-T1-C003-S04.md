# 第2章 一般原則
## 第4節 資本取引・損益取引区分の原則

「企業会計原則 第一 三」には、以下のように規定されている。

> 資本取引と損益取引とを明瞭に区分し、特に資本剰余金と利益剰余金とを混同してはならない。

### 1. 「資本取引・損益取引区分の原則」の意味内容

出題ランク：短答 B、論文 C

この原則は、①資本取引と損益取引の区分、②資本剰余金と利益剰余金の区分の2つを要請する。

### 2. 資本取引と損益取引の区分

#### (1) 資本取引と損益取引の相違

出題ランク：短答 B、論文 B

資本取引とは、純資産を直接的に増減させる取引で、企業活動の成果とは無関係の取引をいう。一方、損益取引とは、企業活動の成果と関連する取引をいう。両者とも結果的に企業の純資産を増減させる。

資本取引の例は、期中に増資を行い株式を30発行する取引（借方現金30、貸方純資産30）と、期中に10の配当を実施する取引（借方純資産10、貸方現金10）である。期首の資産100・負債50・純資産50は、増資後に資産120・負債50・純資産70となるが、企業活動の成果とは無関係である。

損益取引の例は、現金で商品を20仕入れる取引（借方商品20、貸方現金20）と、商品を40で販売する取引（借方現金40、貸方商品20・販売益20）である。期首の資産100・負債50・純資産50は、販売後に資産120・負債50・純資産70となり、販売益20が損益計算書の期間利益20となる。

資本取引は、①純資産を直接増減させる取引であり、②その性質上、企業活動の成果とは無関係である。損益取引は、いったん収益・費用として損益計算書に計上され、①その結果として純資産を間接的に増減させる取引であり、②その性質上、企業活動の成果に関連する。

#### (2) 資本取引と損益取引を区分する理由

出題ランク：短答 B、論文 C

区分が要請される理由は、財務会計の情報提供機能から説明できる。意思決定情報として最も重要視されるのは期間損益であるため、財務会計では期間損益を適正に算定することが重要である。期間損益計算は、一会計期間における企業活動の成果による純資産の増減を計算するものなので、純資産を増減させる取引であっても企業活動の成果とは関係しない資本取引は除き、損益取引のみを構成要素として期間損益を計算しなければならない。

期間損益を適正に算定し、投資者に有用な意思決定情報を提供するため、資本取引と損益取引は区別される。企業会計原則が「新株発行による株式払込剰余金から新株発行費用（株式交付費）を控除することは許されない」と規定するのも、両者を区別すべき旨を示すものである。区分しなければ、株式発行の貸方を収益30として処理でき、利益計算が不適正となる。

### 3. 資本剰余金と利益剰余金の区分

#### (1) 資本剰余金と利益剰余金の意義

出題ランク：短答 B、論文 C

資本剰余金とは、資本取引から生じた元本たる資本のうち資本金以外のものであり、資本準備金とその他資本剰余金に分類される。利益剰余金とは、損益取引から生じた企業内に留保された利益であり、利益準備金とその他利益剰余金に分類される。

#### (2) 資本剰余金と利益剰余金を区分する理由

出題ランク：短答 B、論文 C

貸借対照表の表示上、区分が要請される理由は、財務会計の利害調整機能（株主と債権者）から説明できる。会社財産が配当により株主に分配されることで、利払い不能や債務不履行リスクが過度に高まることは防止する必要がある。

会計上、基本的に元本である払込資本を分配不能、留保利益を分配可能として、それぞれ区分して表示することで、過度に会社財産が流出することを防止し、株主と債権者の利害調整を図る。したがって、払込資本である資本剰余金と留保利益である利益剰余金は混同してはならない。

貸借対照表上、純資産の部に資本剰余金と利益剰余金を区分して表示するからこそ、分配可能部分と分配不能部分を明確にできる。両者を純資産として一括表示すると、どこまでが分配可能か不明瞭となる。

利害調整機能以外にも、分配不能部分を明確にすることで一定の会社財産が企業内に留保され、企業の健全な運営を維持できる。また、払込資本と留保利益を区分することで元本とそれを運用して獲得した成果を明確化し、投資者に有用な情報を提供できる（情報提供機能）。

現行制度上、会社法との調整を図り、資本剰余金のうちその他資本剰余金は分配可能、利益剰余金のうち利益準備金は分配不能として扱われる。

|  | 資本剰余金 | 利益剰余金 |
|---|---|---|
| 会計理論上 | すべて分配不能とするべき | すべて分配可能とするべき |
| 現行制度上 | 資本準備金は分配不能、その他資本剰余金は分配可能 | 利益準備金は分配不能、その他利益剰余金は分配可能 |

会計理論上のあるべき取扱いと現行制度上の取扱いは一致していない。
