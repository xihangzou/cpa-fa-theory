# 第2章 一般原則
## 第3節 正規の簿記の原則

「企業会計原則 第一 二」には、以下のように規定されている。

> 企業会計は、すべての取引につき、正規の簿記の原則に従って、正確な会計帳簿を作成しなければならない。

### 1. 「正規の簿記の原則」の意味内容

出題ランク：短答 B、論文 C

正規の簿記の原則とは、第一に会計帳簿を一定の要件（網羅性、検証可能性、秩序性）に従って正確に作成すること、第二に会計帳簿と財務諸表との間において有機的な関連性を保持すべきことを要求している原則である。

#### (1) 会計帳簿の作成要件

出題ランク：短答 B、論文 C

会計帳簿を正確に作成するための要件は次の3点である。

| 要件 | 内容 |
|---|---|
| 記録の網羅性 | 企業内容の開示にあたり、企業の経営成績、財政状態及びキャッシュ・フローの状況に影響を与える全ての取引がもれなく記録される。 |
| 記録の検証可能性 | 会計記録が取引事実を立証しうる証拠資料に基づく。証拠がないのに記録してはならない。例えば領収書に基づく会計記録は、取引事実を立証するのに十分な情報を提供する。 |
| 記録の秩序性 | 仕訳帳と元帳、主要簿と補助簿等の会計記録が体系的で、秩序正しい相互関連性を保っている。 |

記録の秩序性は、仕訳帳の仕訳が総勘定元帳へ転記され、両者が相互に関連する関係として示される。仕訳帳の例は、（借）現金100（貸）売上100、（借）貸付金500（貸）現金500であり、総勘定元帳には前期繰越1,000、貸付金500、売上100等が記録される。

#### (2) 会計帳簿と財務諸表の間との有機的な関連性

出題ランク：短答 B、論文 C

会計帳簿と財務諸表との間の有機的な関連性とは、財務諸表が会計帳簿から誘導的に作成されることを示している。会計帳簿と関係のない情報に基づき、財務諸表を作成することは否定される。

したがって、正規の簿記の原則の下では、会計帳簿及び損益計算書とは無関係に、毎決算期における財産の実地調査により貸借対照表を作成する「棚卸法」は否定される。

取引の発生から、正確な会計帳簿（記録の網羅性・検証可能性・秩序性）、仕訳帳、元帳を経て、財務諸表が作成される。会計帳簿間にも相互関連性があり、会計帳簿と財務諸表にも相互関連性がある。

### 2. 「正規の簿記の原則」と簿外資産・簿外負債の関係

出題ランク：短答 B、論文 C

正規の簿記の原則はすべての取引の正確な記録を要求するため、簿外資産や簿外負債は原則として存在してはならない。しかし、「重要性の原則」の適用によって、簿外資産や簿外負債が認められる場合もある。

消耗品、消耗工具器具備品その他の貯蔵品等のうち、重要性の乏しいものについては、その買入時又は払出時に費用として処理する方法を採用することができる。

利害関係者が企業の経営成績や財政状態を判断する上で重要性の乏しいものについては、厳密な会計処理によらず、他の簡便な会計処理によることも、正規の簿記の原則に従った処理として認められる。

### 補足　貸借対照表完全性の原則と正規の簿記の原則

出題ランク：短答 C、論文 C

貸借対照表完全性の原則とは、貸借対照表日におけるすべての資産、負債及び資本を記載することを要請するものである。企業会計原則は、貸借対照表は企業の財政状態を明らかにするため、貸借対照表日におけるすべての資産、負債及び資本を記載し、株主、債権者その他の利害関係者にこれを正しく表示するものでなければならないとする。ただし、正規の簿記の原則に従って処理された場合に生じた簿外資産及び簿外負債は、貸借対照表の記載外におくことができる。

正規の簿記の原則は、すべての取引を網羅的に正しく記録することを要請するため、貸借対照表完全性の原則と密接に結びついている。正しく会計処理すれば簿外資産・簿外負債は存在せず、すべての資産・負債が貸借対照表に計上される。本来は貸借対照表完全性の原則を厳密に捉えれば簿外資産・簿外負債は認められないが、重要性の原則に従って処理された場合に生じたものは同原則に反しない。

### 3. 「正規の簿記の原則」と複式簿記の関係

出題ランク：短答 C、論文 D

正規の簿記として、必ずしも複式簿記が予定されているわけではなく、単式簿記によることも認められる。ただし、記録の網羅性、検証可能性、秩序性を満たすものとしては、複式簿記が最も適している。

単式簿記のイメージとして現金出納帳を挙げると、4/1のA社への売上10,000を入金、4/2の水道光熱費2,300を出金として記録する。現金の出入りは把握するが、その原因である売上や水道光熱費の変動を必ずしも把握する必要はなく、現金という一面で捉える。単式簿記であっても、財務諸表の作成に必要な帳簿（預金出納帳や固定資産台帳等）をすべて作成すれば、正確な会計帳簿を作成することは可能である。
