### 1. 一般原則の体系

出題ランク：短答 C、論文 D

企業会計原則は、「一般原則」「損益計算書原則」「貸借対照表原則」によって構成される。これらは並列的な関係ではなく、一般原則が損益計算書原則及び貸借対照表原則よりも上位に位置する。

一般原則は、企業会計の全般にかかわる基本的なルール、あるいは損益計算書と貸借対照表の双方に共通するルールを示した規定であり、次の原則から成り立っている。

- 真実性の原則
- 正規の簿記の原則
- 資本取引・損益取引区分の原則
- 明瞭性の原則
- 継続性の原則
- 保守主義の原則
- 単一性の原則
- 重要性の原則（括弧書き）

関係は、一般原則が上位にあり、損益計算書原則及び貸借対照表原則が下位にある。一般原則の中には上記8原則が位置づけられる。

### 2. 一般原則の全体像

出題ランク：短答 C、論文 D

一般原則の全体像は以下のとおりである。

| 位置づけ | 原則 | 内容 |
|---|---|---|
| 最高規範 | 真実性の原則 | 財務諸表は真実の内容を提供する |
| 下から支える6原則 | 正規の簿記の原則 | 会計帳簿は正確に作成し、財務諸表は会計帳簿から作成する |
|  | 資本取引・損益取引区分の原則 | 資本と利益は区別する |
|  | 明瞭性の原則 | 財務諸表はわかりやすく、また内容を詳細に開示する |
|  | 継続性の原則 | 処理方法や表示方法は継続的に適用する |
|  | 保守主義の原則 | 慎重な判断に基づいた会計処理を採用する |
|  | 単一性の原則 | 実質一元・形式多元 |

重要性の原則は、会計処理面では正規の簿記の原則等と関連し、表示面では明瞭性の原則と関連する。重要なことは厳密に、重要でないことは簡便に扱う。
