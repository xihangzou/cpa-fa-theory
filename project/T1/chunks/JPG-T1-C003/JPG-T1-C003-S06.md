# 第2章 一般原則
## 第6節 継続性の原則

「企業会計原則 第一 五」には、以下のように規定されている。

> 企業会計は、その処理の原則及び手続を毎期継続して適用し、みだりにこれを変更してはならない。

「みだりに」とは「正当な理由なく」を意味する。

### 1. 「継続性の原則」の意味内容と必要性

出題ランク：短答 B、論文 C

継続性の原則とは、いったん採用した会計方針は、正当な理由により変更を行う場合を除き、財務諸表を作成する各時期を通じて継続して適用しなければならないとする原則である。

多種多様な企業の実態を適正に表示するため、同一の会計事実に対して複数の会計方針が認められ、各企業が実情に応じて選択できる。しかし選択適用を無条件に認めると、恣意的な会計処理によって利益操作を行う可能性がある。よって、企業の利益操作を防止するために継続性の原則が必要となる。

利益操作とは、利益の数値を意図的に変えることである。会計処理を自由に変更できると、利益の数値を好きなように変えられる。例えば、100円、120円、140円の商品を当期に3つ仕入れて2つ販売した場合、これまで総平均法を採用していた企業が先入先出法に変更すると、総平均法では（100円＋120円＋140円）×2/3＝240円（売上原価）であるのに対し、先入先出法では100円＋120円＝220円（売上原価）となり、費用を20円小さくできる。

### 補足　継続性の原則と比較可能性の確保

出題ランク：短答 C、論文 C

継続性の原則の必要性は、利益操作の防止のみならず、会計数値の期間比較可能性の確保からも説明できる。会計処理等を変更すると、前期と当期の財務諸表で適用している会計処理等が異なるため、期間比較可能性が損なわれる。

近年、会計処理等を変更した場合に遡及処理を行い、前期の財務諸表を新たな会計処理等で作成し直す会計基準が公表されたため、継続適用しなくても期間比較可能性を確保できるともいえる。ただし、会計基準等に経過的な取扱いが定められている場合など、遡及処理ができない場合がある。また、任意に変更できると、前期時点で開示された財務諸表と当期の比較情報として開示する前期財務諸表が異なる方法に基づくことになる。この意味で、継続性の原則は期間比較可能性の確保に一定の役割を果たす。

### 2. 継続性の原則の前提

出題ランク：短答 B、論文 C

企業会計上、継続性が問題とされるのは、一つの会計事実に対して二つ以上の、一般に公正妥当と認められる会計方針の選択適用が認められる場合である。複数の会計方針が認められているからこそ選択の問題が生じ、継続性を確保する必要がある。会計処理が一つしか定められていない場合、その会計処理を継続して適用するのは当然である。

継続性の原則の適用範囲となるのは、ある一般に公正妥当と認められる会計方針から、他の一般に公正妥当と認められる会計方針へ変更する場合である。この場合、会計方針の変更に正当な理由があるか検討する。

| 変更 | 取扱い | 例 |
|---|---|---|
| 認められない方法 → 認められない方法 | 企業会計原則違反 | 減価償却の方法を売上高比例法から売上原価比例法へ変更 |
| 認められた方法 → 認められない方法 | 企業会計原則違反 | 減価償却の方法を定額法から売上高比例法へ変更 |
| 認められない方法 → 認められた方法 | 当然の変更 | 減価償却の方法を売上高比例法から定額法へ変更 |
| 認められた方法 → 認められた方法 | 継続性の原則の適用範囲内。正当な理由があるか検討する | 減価償却の方法を定額法から定率法へ変更 |

認められた方法から認められない方法への変更、認められない方法から認められない方法への変更は、そもそも企業会計原則違反で許されない。認められない方法から認められた方法への変更は当然の変更であり、継続性の原則の問題とはならない。

### 3. 会計方針の変更が認められる場合

出題ランク：短答 B、論文 C

会計方針の変更が認められるのは、正当な理由がある場合に限られる。
