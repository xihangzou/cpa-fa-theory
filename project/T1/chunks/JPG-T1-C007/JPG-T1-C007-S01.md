# 第4章 損益会計
## 第7節 損益計算書の各項目とその表示

### 1. 損益計算書に計上される項目

損益計算書に計上される各項目について、順にみていくことにする。

#### (1) 売上高

出題ランク：短答C、論文C

売上高の表示について、以下のように規定されている。

- 二以上の種類の事業を営む場合における売上高及び売上原価に関する記載は、事業の種類ごとに区分することができる。
- 売上高の記載については、製品売上高と商品売上高は区分して記載しなければならない。ただし、区分することが困難な場合は、この限りでない。
- 関係会社に対する売上高が売上高の総額の100分の20を超える場合には、その金額を注記しなければならない。

#### (2) 売上原価

出題ランク：短答C、論文C

売上原価とは、売上高に対応する商品等の仕入原価又は製造原価をいう。この売上原価の表示は、「商業を営む場合」と「製造工業を営む場合」とで異なる。

商業を営む場合の売上原価は、商品期首たな卸高に当期商品仕入高を加え、その合計から商品期末たな卸高を控除して表示する。

|---|---:|
| Ⅱ 売上原価 |  |
| 1 商品期首たな卸高 | ××× |
| 2 当期商品仕入高 | ××× |
| 合計 | ××× |
| 3 商品期末たな卸高 | ××× |

製造工業を営む場合の売上原価は、製品期首たな卸高に当期製品製造原価を加え、その合計から製品期末たな卸高を控除して表示する。

| 製造工業を営む場合 | 金額 |
|---|---:|
| Ⅱ 売上原価 |  |
| 1 製品期首たな卸高 | ××× |
| 2 当期製品製造原価 | ××× |
| 合計 | ××× |
| 3 製品期末たな卸高 | ××× |

なお、連結損益計算書では、売上原価は「売上原価を示す名称を付した科目」をもって掲記しなければならない。

#### (3) 販売費及び一般管理費

出題ランク：短答C、論文C

販売費及び一般管理費とは、販売及び一般管理業務に関して発生した費用をいう。

販売費及び一般管理費としては、販売手数料、運搬費、広告宣伝費、販売及び一般管理業務に従事する従業員の給与手当や賞与、販売及び一般管理部門に関する交通費などが挙げられる。

販売費及び一般管理費も売上原価も売上高から控除することで、営業利益を算定する点で共通するが、売上原価は売上高と個別的、直接的に対応しているのに対し、販売費及び一般管理費は売上高と期間的、間接的に対応しているという相違点がある。

#### (4) 営業外収益・営業外費用

出題ランク：短答C、論文C

営業外収益・営業外費用とは、主目的たる営業活動から生じる収益・費用ではないが、毎期経常的に発生する収益・費用であり、その主たるものは「財務活動（金融活動）」により生じた収益・費用から構成される。

営業外収益に属する収益は、受取利息、有価証券利息、受取配当金、有価証券売却益、仕入割引等が挙げられ、営業外費用に属する費用は、支払利息、社債利息、社債発行費償却、有価証券売却損等が挙げられる。

##### 補足　財務活動（金融活動）とは

出題ランク：短答C、論文C

財務活動とは主たる営業活動以外の活動をいい、一般的に「資金調達活動（借入、社債の発行等）」や「外部投資活動（預金、株式投資等）」を指す。前者による損益には支払利息、社債利息等が挙げられ、後者による損益には受取利息、受取配当金、有価証券売却損益等が挙げられる。

#### (5) 特別利益・特別損失

出題ランク：短答C、論文C

特別利益・特別損失とは、当期の活動とは直接関連せず、毎期経常的に発生しない損益項目（臨時損益項目）をいう。例えば固定資産売却損益、災害による損失等が挙げられる。

なお、「企業会計原則」によれば、特別損益に属する項目であっても、金額の僅少なもの又は毎期経常的に発生するものは、経常損益計算に含めることができると規定されている。

#### (6) 法人税等

出題ランク：短答C、論文C

「財務諸表等規則」によれば、法人税等に関連する表示について、以下のように規定されている。

税引前当期純利益金額又は税引前当期純損失金額の次に、次の各号に掲げる項目の金額を、その内容を示す名称を付した科目をもって記載しなければならない。

1. 当該事業年度に係る法人税、住民税及び事業税
2. 法人税等調整額

### 2. 損益計算書の表示・作成

損益計算書は、①総額主義の原則、②費用収益の対応表示、③区分表示の原則により表示、作成する。以下の論点は、明瞭性の原則の「概観性」の論点と関連している。

#### (1) 総額主義の原則

出題ランク：短答B、論文C

「企業会計原則」には、以下のように規定されている。

> 費用及び収益は、総額によって記載することを原則とし、費用の項目と収益の項目とを直接に相殺することによってその全部又は一部を損益計算書から除去してはならない。

総額主義は、損益計算書において取引規模及び取引の源泉を明示し、さらに企業の収益性を明らかにする必要性から規定されている。

これに対して、収益と費用を直接に相殺して差額のみを表示する方法を「純額主義」という。この場合、例えば売上高と売上原価があらかじめ相殺され、損益計算書には相殺後の売上総利益のみが記載される。

しかし、純額表示が行われると、企業の売買取引の規模や、売上高に占める売上原価の割合（収益性）を把握できないため、現行制度上、原則として総額主義が採用されている。

総額主義の例外として、為替差損益（差損と差益を相殺して表示）や、有価証券・固定資産の売却損益が挙げられる。

#### (2) 費用収益の対応表示

出題ランク：短答C、論文C

この論点については、本章の「費用収益対応の原則による形式的な意義」を参照してほしい。

#### (3) 区分表示の原則

出題ランク：短答C、論文C

「企業会計原則」には、以下のように規定されている。

> 損益計算書には、営業損益計算、経常損益計算及び純損益計算の区分を設けなければならない。

現行制度上、損益計算書は、利益計算を「①営業損益計算」「②経常損益計算」「③純損益計算」という3つに区分することで、利益を段階的に計算・表示している。

| 区分 | 内容 |
|---|---|
| 営業損益計算 | 企業の営業活動から生ずる費用及び収益を記載して、営業利益を計算する。一会計期間に属する売上高と売上原価とを記載して売上総利益を計算し、これから販売費及び一般管理費を控除して、営業利益を表示する。 |
| 経常損益計算 | 営業損益計算の結果を受けて、利息、有価証券売却損益その他営業活動以外の原因から生ずる損益であって特別損益に属しないものを記載し、経常利益を計算する。 |
| 純損益計算 | 経常損益計算の結果を受けて、固定資産売却損益等の特別損益を記載し、当期純利益を計算する。 |
