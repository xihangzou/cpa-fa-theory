# 第19章 法人税、住民税及び事業税等に関する会計基準

## 第2節 当事業年度の所得等に対する法人税、住民税及び事業税等

### 1. 当事業年度の所得等に対する法人税、住民税及び事業税等の会計処理

出題ランク：短答B、論文C

当事業年度の所得等に対する法人税、住民税及び事業税等については、法令に従い算定した額（税務上の欠損金の繰戻しにより還付を請求する法人税額及び地方法人税額を含む。）を損益に計上する。

所得等に対する法人税、地方法人税、住民税及び事業税（所得割）のほかに、住民税（均等割）及び事業税（付加価値割及び資本割）を含む。

### 2. 当事業年度の所得等に対する法人税、住民税及び事業税等の表示

#### (1) 損益計算書上の表示

出題ランク：短答B、論文C

法人税、地方法人税、住民税及び事業税（所得割）は、損益計算書の税引前当期純利益（又は損失）の次に、法人税、住民税及び事業税などその内容を示す科目をもって表示する（※1）。

事業税（付加価値割及び資本割）は、原則として、損益計算書の販売費及び一般管理費として表示する（※1）。ただし、合理的な配分方法に基づきその一部を売上原価として表示することができる（※2）。

※1 法人税、地方法人税、住民税及び事業税（所得割）は利益に関連する金額（所得）を課税標準としている以上、税引前当期純利益からの控除項目としている。一方、事業税（付加価値割及び資本割）は利益に関連する金額（所得）を課税標準としていない以上、通常の営業費用として取り扱う。

※2 製造業において、固定資産税等の租税公課を間接経費として製造原価に配分している場合があり、このような企業では事業税（付加価値割及び資本割）も間接経費として製造原価に配分する場合がありうるため、売上原価としての表示も認められている。ただし、実務上は大半の企業が販売費及び一般管理費として処理している。

#### 補足：住民税（均等割）の取扱い

住民税には、所得割、均等割があるが、このうち、均等割は法人の規模（資本金等の額、従業員数）に応じて支払うものであり、利益に関連した金額（所得）に応じて変動する税金ではない。

このため、本来は販売費及び一般管理費として扱うべきだが、住民税の均等割は一般的に重要性が低く、実務上も「法人税、住民税及び事業税」として取り扱うことが定着化している点に鑑みて、現行制度上、「法人税、住民税及び事業税」に含めて処理及び表示をしている。

#### (2) 貸借対照表上の表示

出題ランク：短答B、論文C

法人税、住民税及び事業税等のうち納付されていない税額は、貸借対照表の流動負債の区分に、「未払法人税等」などその内容を示す科目をもって表示する。

法人税、住民税及び事業税等の税額が、中間申告により納付された税額を下回る場合等により還付されるとき、当該還付税額のうち受領されていない税額は、貸借対照表の流動資産の区分に、「未収還付法人税等」などその内容を示す科目をもって表示する。

例えば、法人税等の中間申告（前期に支払った法人税額の半分を期中に納付する）で納付した金額が1,000であった場合、年度の納付額が1,200の場合（ケース1）と年度の納付額が600の場合（ケース2）における貸借対照表上の表示は以下のようになる。

| 区分 | ケース1 | ケース2 |
|---|---:|---:|
| 資産の部（流動資産） |  | 未収還付法人税等 400 |
| 負債の部（流動負債） | 未払法人税等 200 |  |
