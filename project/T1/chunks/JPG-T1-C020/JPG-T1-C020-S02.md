# 第13章 会計基準等

## 第2節 国際財務報告基準（IFRS）の特徴等

### 1. 国際的な会計基準の設定主体とその特徴

#### (1) 用語の定義

出題ランク：短答B、論文C

国際的な会計基準に関する主な用語は、次のとおりである。

| 用語 | 意味 |
|---|---|
| IFRS | 国際財務報告基準（International Financial Reporting Standards）。読み方は、アイファース、イフアース、アイエフアールエスなど。 |
| IASB | 国際会計基準審議会（International Accounting Standards Board）。 |
| FASB | 米国財務会計基準審議会（Financial Accounting Standards Board）。 |
| ASBJ（日本） | 企業会計基準委員会（Accounting Standards Board of Japan）。 |
| コンバージェンス（収束） | IFRSをそのまま適用するのではなく、わが国の会計基準をIFRSに近づけること。IFRSと完全に同一の会計基準にするのではなく、実質的に統一化することをいう。 |
| アドプション（採用） | IFRSをそのまま適用すること。 |
| エンドースメント | IASBにより公表された会計基準等について、わが国で受け入れ可能か否かを判断した上で、必要に応じて、一部の会計基準等について「削除又は修正」して採択すること。 |

#### (2) 原則主義と規則主義

出題ランク：短答C、論文B

IFRSは「原則主義（プリンシプル・ベース）」という考え方を適用している点に特徴がある。一方、わが国の会計基準や米国会計基準は「規則主義（細則主義）」に基づく会計基準である。

|  | 内容 |
|---|---|
| 原則主義 | 会計基準の設定にあたり、企業が会計処理の方法を判断するときの考え方や枠組みを主に示す方法。 |
| 規則主義 | どのような会計処理を行うべきかを会計基準において詳細かつ具体的に定め、この規則に基づき会計処理や表示の判断を下す方法。 |

例えば、ある会社が子会社に該当するかの判断について、規則主義に基づくわが国では、「一定の条件の下で40％以上の議決権を有している」などの要件を満たした場合に子会社と判定する（数値基準が適用される）。これに対し、原則主義に基づくIFRSでは、議決権保有割合にかかわらず、実質的な支配関係の有無に基づき支配の存在の有無を判断する。

#### 原則主義と規則主義の長所と短所

|  | 規則主義（細則主義） | 原則主義（プリンシプル・ベース） |
|---|---|---|
| 適用 | 日本基準及び米国会計基準 | IFRS |
| 長所 | 適用すべき会計処理方法等を客観的に判断できるため恣意性の介入を抑えられる。また、明確な判断基準に基づき処理を決定できるため、企業間の比較可能性が高まる。 | 企業自らが採用する会計基準の妥当性を判断し、これを利害関係者に説明する必要があるため、企業の実態を表現しやすくなる。 |
| 短所 | 会計基準の網をくぐることで、基準の趣旨や実態とは乖離した会計処理が行われる可能性がある。 | 企業の状況や経営者の判断によっては計算結果が異なるので、企業間の比較可能性が害される。 |

規則主義の短所の例として、リース資産のオンバランスを回避するため、契約上、リース料やリース期間を意図的に操作し、現在価値基準や経済的耐用年数基準に抵触しないようにすることが挙げられる。

### 2. わが国におけるIFRSの任意適用

出題ランク：短答B、論文C

#### 任意適用の時期

2010年3月31日以後に終了する連結会計年度から、指定国際会計基準による連結財務諸表を作成することができる。

#### 任意適用が認められる企業（特定会社）

次の要件をすべて満たす特定会社は、指定国際会計基準により連結財務諸表を作成することができる。

1. 有価証券報告書において、連結財務諸表の適正性を確保するための特段の取組みに係る記載を行っていること。
2. 指定国際会計基準に関する十分な知識を有する役員または使用人を置いており、指定国際会計基準に基づいて連結財務諸表を適正に作成することができる体制を整備していること。

#### 任意適用の対象となる財務諸表

日本基準による連結財務諸表に代えて、指定国際会計基準によって連結財務諸表を作成することができる。また、日本基準による個別財務諸表のほか、指定国際会計基準によって個別財務諸表を作成することもできる。

指定国際会計基準とは、IASBが公表したIFRSのうち、金融庁長官が認めたものである。現時点ではIASBにより公表された会計基準等のすべてを認めているため、結果として指定国際会計基準は、IASBにより公表された会計基準等と同一といえる。

従来、任意適用には、上記の要件に加えて「上場会社であること」及び「国際的な財務活動・事業活動を行っていること」を満たす必要があった。しかし、よりIFRSの任意適用会社を増加させるため、平成25年10月28日にこれらの要件が削除され、任意適用の要件が緩和されている。

### 3. IFRSへのコンバージェンス／アドプションに関する考え方

#### (1) 連結先行と連単分離

補講（論文）、出題ランク：短答C、論文C

今後、IFRSの適用作業を進める上では、連結基準と個別基準との関係を明確に整理する必要があり、その大きな方向性として「連結先行」と「連単分離」という2つが考えられている。

| 考え方 | 内容 |
|---|---|
| 連結先行 | 連結財務諸表について先行してIFRSを適用（もしくは調和化を図り）、その後、個別財務諸表にIFRSを適用するか（もしくは調和化を図るか）を検討する考え方。 |
| 連単分離 | 連結財務諸表についてのみIFRSを適用（もしくは調和化を図り）、個別財務諸表については自国の会計基準を適用し続ける考え方。 |

「包括利益会計基準」は、まさしく連結先行の考え方に基づいた措置といえる。

連結先行と連単分離のいずれも、連結についてはIFRSを適用（もしくはコンバージェンス）する一方、個別についてはIFRSを適用（もしくはコンバージェンス）しない方向性を示す。その理由は、連結と個別の位置付け（役割）が異なるためである。

| 対象 | IFRS適用の方向性と理由 |
|---|---|
| 連結 | 連結財務諸表には情報提供機能が求められる。国際的にスタンダードなIFRSとの調和化により、財務報告の情報提供機能がより発揮されやすくなる。また、IFRSを連結財務諸表の作成に採用する国や地域は非常に多いため、諸外国の連結財務諸表との比較可能性が高まり、IFRSの適用には積極的な方向性が示される。 |
| 個別 | 個別財務諸表には利害調整機能が求められ、会社法における分配可能額の算定や税法上の課税所得の算定にも用いられる。個別財務諸表までIFRSを適用すると会社法や税法との整合性が図れず、これを避けるため会社法や税法まで改正すれば、日本全体に多大なコストを負わせる可能性がある。そのため、IFRSの適用には消極的な方向性が示される。 |

今後わが国の会計基準が実際にどの方向に進んでいくかについては、今後の議論次第といえる。

#### (2) 連単分離への批判点

補講（論文）、出題ランク：短答C、論文C

個別財務諸表基準性の原則では、個別財務諸表を基礎として連結財務諸表を作成することを求めている。しかし、連単分離を前提とした場合、いったん連結財務諸表に適用される会計基準を個別財務諸表に適用した上で合算の対象とするため、個別財務諸表基準性の原則の趣旨に合致しないとの批判がある。
