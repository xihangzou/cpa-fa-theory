# 第13章 会計基準等

## 第1節 我が国における基準設定主体

短答式本試験における出題実績では、「2. 国際財務報告基準（IFRS）の特徴等」が17Ⅰ・22Ⅰ、「3. 修正国際基準」が22Ⅱに出題されている。論文式本試験における出題実績の記載はない。

### 1. わが国における会計基準の設定主体

出題ランク：短答C、論文C

わが国の会計基準の設定主体には、「企業会計審議会」と「企業会計基準委員会（ASBJ）」の2つがある。

#### (1) 企業会計審議会

企業会計審議会は、内閣府・金融担当大臣の諮問機関（パブリックセクター）である。当審議会が設定した基準や意見書のうち、現行制度上適用されている代表的なものは、次のとおりである。

|  |  |
|---|---|
| 企業会計原則 | 外貨建取引等会計処理基準 |
| 連続意見書 | 税効果会計に係る会計基準 |
| 原価計算基準 | 連結キャッシュ・フロー計算書等の作成基準 |
| 研究開発費等に係る会計基準 | 固定資産の減損に係る会計基準 |

現在、企業会計審議会は、企業会計制度の企画・整備や監査基準に関する審議などを行っている。

#### (2) 企業会計基準委員会（ASBJ）

2001年7月に「財団法人 財務会計基準機構（プライベートセクター）」が設立され、同機構内に企業会計基準委員会が発足した。これに伴い、企業会計審議会に代わり、企業会計基準委員会において会計基準等の開発が行われている。

この組織は、政府から独立した主体（プライベートセクター）で会計基準を議論すべきであるという強い社会的認識から、経団連、日本公認会計士協会など民間10団体を設立母体として設立された民間組織である。

企業会計基準委員会が開発・公表している会計基準には、次のようなものがある。

|  |  |
|---|---|
| 自己株式及び準備金の額の減少等に関する会計基準 | リース取引に関する会計基準 |
| 貸借対照表の純資産の部の表示に関する会計基準 | 企業結合に関する会計基準 |
| 株主資本等変動計算書に関する会計基準 | 連結財務諸表に関する会計基準 |
| 金融商品に関する会計基準 | 四半期財務諸表に関する会計基準 |

企業会計基準委員会が公表した会計基準は、企業会計審議会が公表した会計基準に優先して適用される。例えば、今後、企業会計基準委員会から「固定資産の減損に関する会計基準」が公表された場合には、それが優先的に適用され、企業会計審議会が公表している「固定資産の減損に係る会計基準」は適用できなくなる。

ただし、企業会計基準委員会が未だに公表していない会計基準（外貨建取引など）については、企業会計審議会が公表している会計基準に従って会計処理や表示を行う。
