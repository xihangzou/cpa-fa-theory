# 第4章 損益会計
## 第6節 利益の特質及び当期業績主義／包括主義

### 1. 2つの利益の特質

期間利益が備えるべき特質には、分配可能性と尺度性がある。

|  | 分配可能性 | 尺度性 |
|---|---|---|
| 意義 | 算定された利益に資金的裏付けが確保されていること | 算定された利益が企業の営業活動の良否の判断尺度となること。利益情報により企業業績を正しく把握できること |
| 求められる理由 | 過度な配当で企業が維持すべき資本が社外流出しないよう、株主と債権者の利害を調整する必要があるため | 投資家の意思決定に有用な会計情報とするには、期間利益によって企業の業績を的確に把握できる必要があるため |
| 特質を備えた利益 | 分配可能利益 | 業績表示利益 |
| 収益・費用の範囲 | 特別損益項目も利益計算に含める | 正常な経営成績を歪める特別損益項目は利益計算に含めない |

尺度性の例として、本社ビルの火災による火災損失は当期にたまたま発生した項目で、当期の業績とは無関係である。このような特別損失を利益計算に含めると、利益が当期の業績を適切に示さなくなる。

損益計算書に当てはめると、経常利益1,000は業績表示利益を示す。特別損失△200を考慮しないと、損失が生じているのに1,000が分配可能となり、200だけ資本が社外流出する可能性がある。そのため、特別損益を考慮した当期純利益800は分配可能利益を示す。基本的には純利益の金額分だけ現金が流入する。

### 2. 当期業績主義と包括主義

損益計算書が明示すべき経営成績（利益）について、当期業績主義と包括主義という考え方がある。

|  | 当期業績主義 | 包括主義 |
|---|---|---|
| 明示すべき経営成績 | 正常的（経常的）収益力 | 一会計期間に生じた全ての収益・費用の差額で表される純利益 |
| 損益計算書の作成方法 | 主たる営業活動と付随活動から継続的・反復的に発生する経常損益項目だけで作成し、特別損益項目は計上しない | 経常損益項目だけでなく特別損益項目も加減して作成する |
| 重視する利益の特質 | 尺度性（業績表示利益） | 分配可能性（分配可能利益） |

当期業績主義では、営業利益、営業外収益、営業外費用、経常利益（業績表示利益）を示す。包括主義では、これらに特別利益・特別損失を加減し、当期純利益（分配可能利益）を示す。両方の利益情報に優劣はつけ難いため、正常的収益力と分配可能利益の両方を提供する包括主義の損益計算書が優れていると考えるのが一般的である。

#### 短期的な収益力と長期的な収益力

当期業績主義は経常損益項目だけを記載するため、毎期獲得できる企業の短期的な収益力を示す。包括主義は、固定資産売却損益など数期間に1度しか生じない特別損益項目も含むため、長期的に見た収益力を示すことができる。

#### 当期業績主義・包括主義と一致の原則の関係

当期業績主義では特別損益を利益計算に含めないので、全存続期間の総収入から総支出を差し引いた全体利益と、経常損益だけからなる期間利益の合計は一致せず、一致の原則は成立しない。包括主義では特別損益も加減して利益を計算するため、全体利益と、特別損益を含む全ての損益からなる期間利益の合計が一致し、一致の原則が成立する。

#### 当期業績主義・包括主義の欠点

当期業績主義では、経常的な損益と特別損益を別個に計算できるため、経営者が経常的な費用を恣意的に特別損失として処理し、損益計算書に計上しないことで利益を多く見せる利益操作が可能となる。例えば経常的な費用100を本来の当期業績主義損益計算書で経常費用として計上すれば経常利益は50だが、特別損失として処理して経常費用を0とすれば経常利益を150と表示できる。

包括主義では、経常的な費用の計上区分を特別損失に恣意的に変更しても損益計算書に計上されることは変わらず、当期純利益は50となるため、この利益操作はできない。ただし、非経常的な項目を損益計算書に含めると、利害関係者が収益力の判断を誤るおそれがある。
