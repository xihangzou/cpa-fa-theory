### 1. 繰延資産の意義と資産計上の根拠

出題ランク：短答A、論文C

繰延資産とは、①すでに対価の支払いが完了し又は支払義務が確定し、②これに対応する役務の提供を受けたにもかかわらず、③その効果が将来にわたって発現するものと期待される費用をいう。

繰延資産の例として株式交付費が挙げられるが、当該項目は以下のとおり繰延資産の定義を満たしている。

#### 株式交付費

1. 株式を交付する際にすでに支出は済んでいる。
2. 支出をすることで、株式を交付できたという役務の提供を受けている。
3. 株式を交付し、調達資金で新たな事業を展開すれば、将来の収益にも貢献する。

#### 通常の資産と繰延資産

- 通常の資産：未だ消費していない財貨、役務が貸借対照表に計上される（消耗品、前払費用、機械など）。
- 繰延資産：すでに消費した役務が貸借対照表に計上される。

「企業会計原則」によれば、「将来の期間に影響する特定の費用（繰延資産）は、次期以後の期間に配分して処理するため、経過的に貸借対照表の資産の部に計上することができる」と規定されている。

#### 繰延資産の会計処理のまとめ

|  | 処理 |
|---|---|
| 原則 | 支出時に費用処理（資産計上しない） |
| 容認 | 資産計上 |

上記から、繰延資産には資産性が認められるといえる。ここで、繰延資産について、資産計上が認められる論拠は、以下の通りである。

ある支出が行われ、役務の提供を受けたにもかかわらず、支出又は役務の有する効果が、当期のみならず次期以降にも及ぶ場合、支出額の全額を支出した期間の費用とすると、収益・費用の対応計算上合理的とはいえない。そこで収益と費用の適切な対応を図るため、経過的に貸借対照表に資産として計上するのである。

### 2. 繰延資産の特徴

出題ランク：短答B、論文C

繰延資産の特徴をまとめると、以下の点が挙げられる。

| 項目 | 内容 |
|---|---|
| 資産の分類 | 費用性資産（将来の費用となる資産） |
| 財産価値の有無 | 財産価値はない（他人に売却できない） |
| 役務の提供 | すでに役務の提供を受けている |

### 3. 繰延資産と長期前払費用の異同

出題ランク：短答C、論文C

繰延資産と長期前払費用には、以下のような共通点と相違点がある。

|  | 繰延資産 | 長期前払費用 |
|---|---|---|
| 共通点 | ①一般的には、期間が一年間を超えて費用化する実体のない費用性資産である。<br>②役務に対する対価であり、支出は既になされている。 |  |
| 相違点 | ①既に役務の提供を受けている。<br>②個別的な財産価値がない。 | ①いまだ役務の提供を受けていない。<br>②個別的な財産価値がある。 |

### 4. 繰延資産の貸借対照表における表示

出題ランク：短答B、論文C

- 資産は、「流動資産」「固定資産」及び「繰延資産」に分類し、更に、固定資産に属する資産は、有形固定資産、無形固定資産及び投資その他の資産に分類して記載しなければならない。
- 各繰延資産に対する償却累計額は、当該繰延資産の金額から直接控除し、その控除残高を各繰延資産の金額として表示しなければならない（未償却残高のみを計上 → 無形固定資産と同様）。

繰延資産の計上額は未償却残高のみが計上されるが、これは無形固定資産同様、繰延資産は取替更新を前提としないためである。

### 5. 繰延資産の取扱いに関するこれまでの経緯

出題ランク：短答A、論文C

従来、繰延資産の具体的な会計処理は、実務上、旧商法施行規則に従って取り扱われてきた。

こうした中、平成18年5月1日に施行された会社計算規則では、「繰延資産として計上することが適当であると認められるものが繰延資産に属する」と規定されているだけで、旧商法施行規則のように繰延資産として計上することができる項目は列挙されていない。

また、繰延資産の償却方法についても、「償却すべき資産については、事業年度の末日において、相当の償却をしなければならない」とされ、具体的な償却方法や償却期間の定めはない。この点について、「会社計算規則の用語の解釈及び規定の適用に関しては、一般に公正妥当と認められる企業会計の基準その他の企業会計の慣行をしん酌しなければならない」とされている。

このような会社法の改正に伴い、会計において繰延資産に関する基準を整備する必要が高まったため、平成18年6月6日に「繰延資産の会計処理に関する当面の取扱い（以下、当面の取扱い）」が企業会計基準委員会から公表されている。

#### 従来と会社法改正後の関係

|  | 従来 | 会社法改正後（現在） |
|---|---|---|
| 会社法（旧商法） | 旧商法施行規則にて、繰延資産の会計処理について規定していた。 | 会社計算規則において、繰延資産の規定なし（会計に準拠して処理する）。 |
| 会計 | 繰延資産について規定なし（会社法に準拠して処理）。 | 会計上、繰延資産の規定はなかったため、新たに規定する必要性があった。「繰延資産の会計処理に関する当面の取扱い」を公表し、繰延資産の処理を会計上定めた。 |

従来は、旧商法施行規則が繰延資産の会計処理を規定し、会計は会社法に準拠して処理していた。会社法改正後は、会社計算規則に具体的な規定がないため、会計上「当面の取扱い」を公表して繰延資産の処理を定めている。

ここで、「繰延資産の部に計上した額」は剰余金の分配可能額から控除される（会社計算規則第158条第1号）ことなども考慮し、繰延資産項目は、原則として旧商法施行規則で「限定列挙」されていた項目とする。この結果、当面の取扱いでは、以下の5項目を繰延資産として取り扱っている（限定列挙：たとえば繰延資産の定義を満たしていても、以下の①〜⑤の項目に該当しなければ繰延資産として資産計上はできない）。

1. 株式交付費
2. 社債発行費等（新株予約権発行費を含む）
3. 創立費
4. 開業費
5. 開発費
