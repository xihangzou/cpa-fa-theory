# 第20章 一株当たり当期純利益に関する会計基準

## 第1節 一株当たり情報に関する基本事項

物理349の出題実績表では、短答式本試験について「一株当たり情報に関する基本事項」は22Ⅱに1回、「一株当たり当期純利益の算定」は22Ⅰに1回、「潜在株式調整後一株当たり当期純利益の基本的な考え方」は22Ⅱに1回の出題実績がある。「ワラントが存在する場合」「転換証券が存在する場合」「その他の論点」には短答式本試験の出題印がない。論文式本試験（17〜22）には、6項目いずれも出題印がない。

### 1. 目的

出題ランク：短答C、論文C

一株当たり当期純利益及び潜在株式調整後一株当たり当期純利益の算定及び開示の目的は、普通株主に関する一会計期間における企業の成果を示し、投資家の的確な投資判断に資する情報を提供することにある。

### 2. 本会計基準と会計処理との関係

出題ランク：短答C、論文C

本会計基準は、あくまで一株当たり当期純利益及び潜在株式調整後一株当たり当期純利益の算定方法を定めたものであり、損益計算書における当期純利益の算定等、会計処理に影響を与えるものではない。

### 3. 開示方法

出題ランク：短答C、論文C

一株当たり情報は、注記事項として投資者に開示される。個別財務諸表、連結財務諸表及び四半期個別財務諸表、四半期連結財務諸表いずれの財務諸表においても注記される。

### 4. 用語の定義

出題ランク：短答C、論文C

本会計基準における用語の定義を示すと、以下のとおりである。

| 用語 | 定義 |
|---|---|
| 普通株式 | 株主としての権利内容に制限のない、標準となる株式 |
| 普通株主 | 普通株式を有する者 |
| 配当優先株式 | 普通株式よりも配当請求権（剰余金の配当を受ける権利）が優先的に認められる株式 |
| 優先配当 | 配当優先株式における優先的な利益配当であって、本会計基準では留保利益から行われるもの |
| 潜在株式 | その保有者が普通株式を取得することができる権利若しくは普通株式への転換請求権又はこれらに準じる権利が付された証券又は契約をいい、例えばワラント、転換証券が含まれる |
| ワラント | その保有者が普通株式を取得することのできる権利又はこれに準じる権利をいい、例えば新株予約権が含まれる |
| 転換証券 | 普通株式への転換請求権若しくはこれに準じる権利が付された金融負債（転換負債）又は普通株式以外の株式（転換株式）をいい、例えば一括法で処理されている新株予約権付社債（転換負債の例）、一定の取得請求権付株式（転換株式の例）が含まれる |
