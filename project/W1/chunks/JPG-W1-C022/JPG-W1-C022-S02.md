# 第20章 一株当たり当期純利益に関する会計基準
## 2. 一株当たり当期純利益の算定

### 物理ページ 194（⑳-1）

2. 一株当たり当期純利益の算定

□□□ 問題2　重要度C

一株当たり当期純利益については，損益計算書上の当期純利益を普通株式の期中平均株式数で除して算定する。

□□□ 問題3　重要度C

連結財務諸表上，一株当たり当期純利益は，当期純利益から普通株主に帰属しない金額を控除した額を期中平均株式数で除して算定する。

□□□ 問題4　重要度C　R4 過去問題

一株当たり当期純利益は注記対象となるが，損益計算書上，当期純損失が生じている場合には，一株当たり当期純損失は注記対象とはならない。

□□□ 問題5　重要度C　R4 過去問題

一株当たり当期純利益の計算において必要となる普通株式の期中平均株式数は，期中平均発行済株式数となる。

□□□ 問題6　重要度C

連結財務諸表において一株当たり当期純利益を算定する際には，普通株式の期中平均株式数の算定における自己株式数は，子会社及び関連会社が保有する親会社等の発行する普通株式を含める。

□□□ 問題7　重要度C

潜在株式については実際に権利が行使されたときに，普通株式数に含める。

### 物理ページ 195（⑳-2）

□□□ 問題2　誤り　「一株当たり当期純利益に関する会計基準」12

一株当たり当期純利益は，普通株式に係る当期純利益を普通株式の期中平均株式数で除して算定する。

追加でチェック！

分母については「普通株式の期中平均株式数」を用いる。

□□□ 問題3　誤り　「一株当たり当期純利益に関する会計基準」12

連結財務諸表上，一株当たり当期純利益は，親会社株主に帰属する当期純利益から普通株主に帰属しない金額を控除した額を期中平均株式数で除して算定する。

追加でチェック！

・個別財務諸表上，普通株式に係る当期純利益は，損益計算書上の当期純利益から，普通株主に帰属しない金額を控除して算定する。
・普通株主に帰属しない金額には，優先配当額などが含まれる。

□□□ 問題4　誤り　「一株当たり当期純利益に関する会計基準」12

一株当たり当期純損失であっても注記対象となる。

□□□ 問題5　誤り　「一株当たり当期純利益に関する会計基準」17

普通株式の期中平均株式数は，普通株式の期中平均発行済株式数から期中平均自己株式数を控除して算定する。

□□□ 問題6　誤り　「一株当たり当期純利益に関する会計基準」17

連結財務諸表において一株当たり当期純利益を算定する際には，普通株式の期中平均株式数の算定における自己株式数は，子会社及び関連会社が保有する親会社等の発行する普通株式のうち，親会社等の持分に相当する株式数を含める。
