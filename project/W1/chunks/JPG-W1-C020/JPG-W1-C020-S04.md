# 第18章 時価の算定に関する会計基準
## 4. 時価の算定

### 物理ページ 186（⑱-3）

4. 時価の算定

■□□ 問題8　重要度B

時価の算定にあたっては，状況に応じて，十分なデータが利用できる評価技法を用いる。評価技法を用いるにあたっては，関連性のある観察できないインプットの利用を最大限にする。

□□□ 問題9　重要度C

時価を算定する際には，単一の評価技法を用いる必要があり，複数の評価技法を用いてはならない。

■□□ 問題10　重要度B

時価の算定に用いる評価技法は，毎期継続して適用する。また，当該評価技法又はその適用を変更する場合は，会計方針の変更として処理する。

■□□ 問題11　重要度B

時価の算定に用いるインプットは，レベル1のインプット，レベル2のインプット，レベル3のインプットに分類され，レベル3のインプットが最も優先順位が高く，レベル1のインプットが最も優先順位が低い。

□□□ 問題12　重要度C

レベル1のインプットとは，時価の算定日において，企業が入手できる活発な市場における同一の資産又は負債に関する相場価格であり，調整されているものをいう。

□□□ 問題13　重要度C

レベル2のインプットとは，資産又は負債について観察できないインプットをいい，当該インプットは，関連性のある観察可能なインプットが入手できない場合に用いる。

### 物理ページ 187（⑱-4）

■□□ 問題8　誤り　「時価の算定に関する会計基準」8

評価技法を用いるにあたっては，関連性のある観察可能なインプットを最大限利用し，観察できないインプットの利用を最小限にする。

□□□ 問題9　誤り　「時価の算定に関する会計基準」9，36

時価の算定にあたっては，単一の評価技法が適切となる場合もあるが，複数の評価技法が適切となる場合もある。このため，時価を算定する際に，複数の評価技法を用いることもある。

追加でチェック！

時価の算定にあたって複数の評価技法を用いる場合には，複数の評価技法に基づく結果を踏まえた合理的な範囲を考慮して，時価を最もよく表す結果を決定する。

■□□ 問題10　誤り　「時価の算定に関する会計基準」10

前文は正しいが，評価技法又はその適用を変更する場合は，会計上の見積りの変更として処理する。

■□□ 問題11　誤り　「時価の算定に関する会計基準」11

前文は正しいが，レベル1のインプットが最も優先順位が高く，レベル3のインプットが最も優先順位が低い。

□□□ 問題12　誤り　「時価の算定に関する会計基準」11（1）

レベル1のインプットとは，時価の算定日において，企業が入手できる活発な市場における同一の資産又は負債に関する相場価格であり，調整されていないものをいう。

追加でチェック！

レベル1のインプットにおける相場価格は，時価の最適な根拠を提供するものであり，当該価格が利用できる場合には，原則として，当該価格を調整せずに時価の算定に使用する。

□□□ 問題13　誤り　「時価の算定に関する会計基準」11（2），（3）

本肢は，レベル3のインプットの内容である。レベル2のインプットは，資産又は負債について直接又は間接的に観察可能なインプットのうち，レベル1のインプット以外のインプットをいう。

### 物理ページ 188（⑱-5）

□□□ 問題14　重要度C

インプットを用いて算定した時価は，その算定において重要な影響を与えるインプットが属するレベルに応じて，レベル1の時価，レベル2の時価又はレベル3の時価に分類する。また，時価を算定するために異なるレベルに区分される複数のインプットを用いており，これらのインプットに，時価の算定に重要な影響を与えるインプットが複数含まれる場合，これら重要な影響を与えるインプットが属するレベルのうち，時価の算定における優先順位が最も高いレベルに当該時価を分類する。

□□□ 問題15　重要度C

資産又は負債の取引の数量又は頻度が当該資産又は負債に係る通常の市場における活動に比して著しく低下していると判断した場合，取引価格又は相場価格は時価とは認められない。

□□□ 問題16　重要度C

負債又は払込資本を増加させる金融商品（例えば，企業結合の対価として発行される株式）については，時価の算定日に市場参加者に移転されるものと仮定して，時価を算定する。

□□□ 問題17　重要度C

負債の不履行リスクとは企業が債務を履行しないリスクをいうが，負債の時価の算定にあたっては，この負債の不履行リスクの影響を反映してはならない。

### 物理ページ 189（⑱-6）

□□□ 問題14　誤り　「時価の算定に関する会計基準」12

前文は正しいが，時価を算定するために異なるレベルに区分される複数のインプットを用いており，これらのインプットに，時価の算定に重要な影響を与えるインプットが複数含まれる場合，これら重要な影響を与えるインプットが属するレベルのうち，時価の算定における優先順位が最も低いレベルに当該時価を分類する。

□□□ 問題15　誤り　「時価の算定に関する会計基準」13

本肢の場合，取引価格又は相場価格が時価を表しているかどうかについて評価する。よって，当該取引価格又は相場価格が時価を表していると判断される場合もある。

□□□ 問題16　正しい　「時価の算定に関する会計基準」14

□□□ 問題17　誤り　「時価の算定に関する会計基準」15

負債の時価の算定にあたっては，負債の不履行リスクの影響を反映する。
