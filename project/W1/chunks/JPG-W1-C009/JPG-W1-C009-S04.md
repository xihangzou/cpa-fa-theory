# 第8章 固定資産
## 4. 正規の減価償却以外の費用配分

### 問題20（重要度C）

減耗性資産には減耗償却が適用されるが、具体的には償却した金額の分だけ棚卸資産に振替え、最終的に売上原価に振り替えられる。この方法は手続的に生産高比例法と類似しており、正規の減価償却といえる。

#### 解答（「連続意見書 第三」第一 六2）

誤り。

減耗性資産の費用配分は、手続的には生産高比例法と同じであるが、減価償却とは異なる別個の費用配分方法である。

（追加でチェック！）

減耗性資産とは、採取するにつれて漸次減耗し枯渇する天然資源をいう。減耗性資産は、全体として生産に役立つのではなく、採取に応じてその実体が部分的に製品化するという特徴がある。

### 問題21（重要度A、H25過去問、H30過去問類題）

取替法とは、軌条、信号機、送電線等のように同種の物品が多数集合して一全体を構成し、老朽物品の部分的取替を繰り返すことにより全体が維持される固定資産について、部分的取替に要する費用を資本的支出として処理する方法である。

#### 解答（「連続意見書 第三」第一 七）

誤り。

取替法は、部分的取替に要する取替費用を収益的支出として処理する方法である。

（追加でチェック！）

取替法は正規の減価償却方法ではない点にも留意する。

### 問題22（重要度B）

取替法では、新規取得資産への支出を費用化するため、資産の帳簿価額は常に原始取得原価で維持される。このため、物価変動期においても同一物価水準で収益と費用を対応させることができる。

#### 解答（「連続意見書 第三」第一 七）

正しい。

（追加でチェック！）

新規取得資産への支出を費用化することから、取替法は固定資産に「後入先出法」の考え方を適用したものとみなすことができる。
