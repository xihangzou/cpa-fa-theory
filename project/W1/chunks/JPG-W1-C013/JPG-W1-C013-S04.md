4. 第3章 財 務 諸 表 の 構 成 要 素

□□□ 問題 51 重要度 C

財務報告の 目的を達成するため,現 行のディスクロージャー制度においては,貸 借対照表,損 益計算書,キ ャ

ッシュフロー計算書等の財務諸表が開示 されている。 これ らは企業の所有者が提供 した資金をもとに,企 業が実

行 した投資の特定時点のポジションと,そ の投資から得 られた特定期間の成果を反映 している。

■□□ 問題 52 重要度 B   H31 過去問類題

概念 フレームワー クでは,投 資のポジションと成果を示すために,貸 借対照表や損益計算書に関する構成要素

として,資 産,負 債,純 資産,包 括利益,純 利益,収 益,費 用の 7項 目が定義 されている。

□□□ 問題 53 重要度 B

わが国の討議資料『財務会計の概念フレームワーク』は,資 産負債アプローチを重視 しているため,当 期純利

益概念を排除して包括利益概念を採用 している。
