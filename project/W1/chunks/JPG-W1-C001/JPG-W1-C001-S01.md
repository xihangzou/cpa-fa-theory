# 序章（問題集の使用・学習案内）
## はじめに ～短答対策問題集 序章について～

短答対策問題集の序章で取り扱う内容の概要は、次のとおりである。序章に記載されている内容は、今後の短答対策をする上で非常に重要である。

序章の目的は、財務・理論の短答対策について、次の事項を明確に示すことである。

- 重点的にやるべきことは何か
- 合格レベルはどの水準なのか
- 今の自分の状況では何からやるべきなのか

図が示す関係は、直近14回分の過去問の多角的分析と財務会計論・理論の科目の特徴を踏まえて、明確な学習の指針を示し、それを合格（GOAL）への最短ルートにつなげるというものである。これを示すことが序章の目的である。

- GOAL（合格）
  - 最短ルート
    - 明確な学習の指針
      - 直近14回分の過去問の多角的分析、財務会計論・理論の科目の特徴

これらを明確にすることで、迷わずに合格に向けてまっすぐに進むことができる。序章が示すのは、合格に向かう最短ルートと明確な学習の指針である。

序章で扱う大まかな内容は、以下の4つである。

1. 財務・理論における短答式試験の概要
2. 6つの視点からの過去問分析により、実際の出題傾向を知る
3. 分野別の学習戦略
4. 財務・理論の短答式試験の具体的な対策方法（受講生の状況別）、本問題集の使い方・特徴など

序章の内容を把握して今後自分のやるべきことが明確になれば、あとはそれを実行に移すだけである。それが合格レベルに達するための最短のルートである。
